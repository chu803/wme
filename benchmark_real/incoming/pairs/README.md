## 需要什么（修正后的取数要求）
「无水印」版必须是**同一张图、只改动水印区域**：
- 用**原地修复类**工具：美图秀秀「消除笔」/ 醒图「消除」/ Photoshop「内容识别填充」；
  **只涂抹右下角水印文字**，不要用「重新生成/扩图/高清修复」类功能。
- **自检标准**：两张图应**只有右下角一小块不同**（约占全图 0.5%–2%），
  其余像素逐字节相同。若整张图都变了，说明工具重新生成了整图 → 不可用。
- ⚠ 不要用本工作台产出 clean 版（自己测自己，数据无意义）。
