目录结构

工作流
------
1. 把真实 AI 图放到 images/ 下（任意文件名）；用 `scripts/collect_real_assets.py scan`
   自动登记到 manifest.json（填写元数据：ai_source / style / original_size）。

3. `scripts/run_real_benchmark.py` 跑门禁：每个预设 × 每张真值图 → recall/precision/IoU/FP，

4. `scripts/real_benchmark_decision.py` 做引擎对决：每张图同时跑 OpenCV + LaMa，

### 6. 检测器修复：全幅平铺 → 全帧区域（2026-10-18，用户选「改检测器」）
- **实现**（`core/detector.py::_consolidate_fullframe` + config 四个杠杆）：
  同类区域（`grid_watermark` / `translucent`）已铺满全幅时（联合包围盒宽高**均** ≥
  `DETECT_FULLFRAME_SPREAD_RATIO` 且数量 ≥ `MIN_REGIONS`），追加一个 bbox=(0,0,W,H)、
  `full_frame=True` 的**全帧 region**。
- **关键取舍**：**只扩 region、不填 mask** —— 门禁的区域级匹配因此能认作「铺满全幅」，
  掩码仍只含真实水印像素，产品侧不会整图重绘毁图。需要 mask 也铺满时置
  `DETECT_FULLFRAME_FILL_MASK=True`（供 mask_recall 实验，代价是整图重绘）。
- **按预设限定**：仅 `ai_grid` / `ai_tiled` / `ai_faint_tiled` 开启；`general` 恒关（防误伤普通照片）。
- **A/B 实测**（21 张真值图，同一组检测参数，仅切 fullframe 开关）：
  | 水印类 | OFF | ON |
  |---|---|---|
  | grid_watermark | 0/4 = 0.00 | **3/4 = 0.75** |
  | translucent | 0/4 = 0.00 | **4/4 = 1.00** |
  | overlay | 0/3 = 0.00 | 1/3 = 0.33 |
  | gradient | 0/4 = 0.00 | 1/4 = 0.25 |
  （overlay/gradient 的部分匹配是**跨类全幅几何匹配**：全帧区域与任何全图真值 IoU=1.0，
  与 kind 无关——属已知口径 caveat，非本修复缺陷。）
- **零回归**：`general` 在 53 张真值图上逐位不变
  （0.5960 / 0.9057 / 0.3217 / 0.0129 / 0.6638 / 0.0801）；既有 90 例探测器/预设守卫全绿。

### 7. LOGO 缺口归因（2026-10-18，含一次**真值自纠**）
P1 的 4 处 `logo_watermark` 真值（logo_A/B/C + mixed_b）为 0/4。

> **⚠ 真值自纠（2026-10-18）**：首轮目视标注来自缩小预览，`logo_B` / `logo_C` / `mixed_b`
> 三处 bbox **偏小/偏移**（把大回纹 / 线框立方体只框了一角）。已修正为：
> B `[1955,1395,375,345]`（3.1%）、C `[530,320,850,1060]`（21.5%）、
> mixed_b `[860,580,460,650]`（7.1%）。修正后复核 **LOGO 召回仍 0/4** ⇒ 缺口结论不变，
> 但因果归类按修正后数据重写（旧版把 C 记为 44.6%、B 记为 1.1%，均已作废）。

真因（修正后）：
1. **logo_A（圆环 33%）/ logo_C（线框立方体 21.5%）**：`area > 15%` 覆盖率闸上限；
   抬 `max_area` 到 0.50 仍被 **15% 安全闸**裁掉（总入口实测 logo_regions 仍 0，日志
   「34.2% > 15% 已裁剪」）⇒ 这是「宁可漏检、不可滥杀」的**产品安全策略**，放宽需显式授权。
2. **logo_B（右下嵌套回纹 3.1%）**：在闸内，但轮廓 `solidity≈0.49 < 0.85` ⇒ 被**实心率判据**拒绝。
3. **mixed_b（中央圆环 7.1%）**：在闸内，同样未产生合格轮廓（检测到的 66×33 区域是伪影）。
⇒ **B / mixed_b 是真正的低对比/空心细线缺口**；A / C 是安全闸取舍。

**反证（实测）**：
- 网格扫描（solidity 0.35–0.85 × max_area 0.15–0.50）：降 solidity 救不了 B/C（恒 0/1），
  却让干净图误报爆炸（抽象流体 50–100%、咖啡杯 37–136%）⇒ 全局降 solidity 不可行。
- 断口桥接（膨胀 1–3 次 × 闭运算 5/7）：B/C 仍 0/1 ⇒ 不是「断口」而是**低对比/破碎**。
- 空洞比（`RETR_CCOMP`）：`hole_ratio` 不能区分「空心水印」与「实心角标」——既有 ai_logo_*
  里也大量出现 hole_ratio 0.91 的候选（字母封闭区）⇒ 不可用作放行判据。
- 抬 max_area 直通总入口：logo_A 区域仍为 0（被覆盖率闸裁剪）⇒ **调参修复被闸抵消**。

**低阈值几何通路可行性探针（2026-10-18）**：低阈 Canny（10,30 / 20,50 / 30,80 / 50,150）+
`approxPolyDP`（4–8 顶点、凸、aspect≤4、面积 0.1%–15%）在 B/C 真值上 **0 命中**；
同判据在 12 张干净图上产生 **17–34 个候选**（≈1.4–2.8/图）⇒ **简单几何判据不可行**。
可行方案需更严的「规则多边形 + 笔画细度」判据 + 独立预设 + 严格 FP 门禁，属较大特性。

**本轮决策**：不提交任何「抬 max_area / 降 solidity」的假修复（均被闸或 FP 否决）；
先修正真值（本轮已做），细线通路作为独立特性待后续立项。

### 9. corner mask_recall 归因（2026-10-18）——refine 杠杆被**否决**
- **缺口拆解**（53 图，general）：区域框覆盖 **0.8199**、最终掩码 **0.5960**、框内填充 **0.7269**。
  ⇒ 40.4% 缺口 = **18.0% 检测/过滤损耗** + **22.4% 框内 refine 损耗**（refine 是更大的一块）。
- **refine 杠杆 A/B**（K_SCALE × PAD，53 图，OCR 与基线同口径）：

  | K | PAD | mask_recall | mask_iou | precision | mask_cov | cov_ratio |
  |---|---|---|---|---|---|---|
  | 0.65 | 1 | 0.5960 | 0.3217 | 0.0801 | 0.0129 | 2.30（基线）|
  | 0.65 | 2 | **0.6378** | 0.3228 | 0.0784 | 0.0150 | 2.66 |
  | 0.50 | 1 | 0.6212 | 0.3124 | 0.0791 | 0.0145 | 2.61 |
  | 0.45 | 1 | 0.6332 | 0.3116 | 0.0780 | 0.0156 | 2.83 |

- **否决理由（关键）**：PAD=2 虽把 mask_recall 抬 +7.0%，但 `config` 阶段 106 的**端到端**标定
  已证明 pad=2 的 **removal 不升**（edge 0.2417→0.2407、grid 0.5053→0.5026、
  faint_tiled 0.0015→**−0.0174**），而 **overdraw 全面上升**（4.61→5.00 / 5.94→6.21 / 1.25→1.45）
  ⇒ 它只是把真值**矩形里的背景**也涂了，并没有多去掉水印。K↓ 同样损 mask_iou（0.3217→0.3116）。
- **口径教训**：`mask_recall` 用 **bbox 真值**时，会**奖励「涂满真值矩形」**（含背景），
  不等于「去掉了多少水印」。refine 层的真正仲裁者是**端到端 removal / overdraw**
  （阶段 106 已标定），不是 mask_recall。⇒ **本项不改**。
- **剩余可行动缺口 = 检测那一侧**（18.0%）：框本身没盖住真值。典型 c15(0.00)、
  ai_logo_09(0.31)、2/3/4(0.51–0.54)、ai_logo_06/08(0.53–0.58)。
  这是「角标检测器没找到 / 没框到」的问题，下一步应在检测侧归因
  （ROI 覆盖率 / MSER / OCR 命中 / 面积过滤）。

### 15. 底板检测可行性：**no-go**（2026-10-18）
为突破 corner 去痕 37.4% 的上限，探了两条路，**均不可行**：

1. **轮廓路径**：底板轮廓的 `solidity` 实测 **0.31–0.43**，远低于 LOGO 通路的 0.85

   10 张里只有 **1 张 IoU 0.88、1 张 0.43**，其余 ≤0.29 ⇒ 不是「换个阈值」能修的。
2. **均匀性/方差路径**：底板是 alpha 混合（内部对比度理论上压到 ~41%），但**白字的高对比
   主导了区域内 std**；实测 `in_std/out_std = 0.83–2.49`（并不 <1）、
   `mean_shift = −52 ~ +22`（符号不一致）⇒ 方差/均值信号**不可分离**。

- **结论**：底板检测需要**专用方法**（估计 alpha 混合的背景模型，或训练分割器），
  不是本轮可完成的调参/轮廓工作。已登记，避免后人重复踩。
- 现状：corner 去痕 37.4% 受此上限约束，**暂不提升**；要动须先立项「底板/背板分割」。
