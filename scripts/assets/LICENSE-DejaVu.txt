大小：704128 字节
SHA-256：b184b89e3c1075f22f6b71575b6fc20d4972b3cfd3b23322ca6fd596dcaef167
取自：matplotlib 3.11.2 随包分发的同一份**未修改**字体（未改名 ⇒ 不触发下方改名条款）。
用途：scripts/make_demo_assets.py 用它渲染四类合成水印。字体决定像素，像素决定
      覆盖率 / 召回 / ΔPSNR —— 不固定字体就等于每台机器量的不是同一个东西。
      阶段 369 实测：换成 Linux 上的 DejaVu 后，256px 角标用例从「默认路径完全
      检不出（掩码 0 px）」变成检出 2813 px ⇒ 一条负断言凭空翻红。

sdist / wheel 不含本文件：MANIFEST.in 把 scripts/ 与 docs/ 一并 prune —— 它是
**开发期量具**，不是交付物。要复现基准数字请从 git 仓库检出后运行。
