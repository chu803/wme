### 摸清的事实（都是这次读代码/跑工具得到的）

1. **入库链路**：`collect_real_assets.py add <path> --style <s> --copy`（或 `scan`）→
   `build_real_ground_truth.py list/validate`；清单 schema = `{id, filename, path, ai_source,
   watermark_style_hint, original_size, sha256, added_at, source}`；
   真值 schema = `{image_id, watermarks[{bbox:[x,y,w,h], style}], labeled_at, labeled_by}`。
2. **`STYLE_ENUM`**（`build_real_ground_truth.py`）= corner_logo / edge_text / grid_watermark /
   logo_watermark / gradient_watermark / translucent / ocr_text / overlay / mixed / unknown。
3. **⚠ `auto` 子命令是循环论证**：它把**检测器自己的输出**写成真值
   （`labeled_by="auto:<preset>"`）⇒ 拿它评检测器，recall/precision 结构性偏高**且不报错**；
   现有 60 条标注全是 `manual:measured`（合规）。⇒ 预检把任何 `auto:` 标注判为**不可升级**。
4. **升级 `committed` 被 5 处守卫钉住**：config 派生 `WATERMARK_TYPE_COMMITTED` /
   `test_watermark_scope95.py::test_committed_face_is_exactly_corner_logo` 与
   `::test_real_dataset_scope_reports_commitment_face` / README 验证状态列 /
   README 承诺类数量 / UI 文案（标签集合必须恰好等于承诺面，由 config 注入）。
   ⇒ 清单（7 步）本身也加了守卫，防止「照清单做完仍然红」。
5. **预检实测**：`ai_logo` 30 图 / **60 标注** / 全 `manual:measured` ⇒ 已承诺；
   其余四类真值图数 **0** ⇒ 不可升级（缺 3 张）；承诺类缺真值：无 ⇒ `EXIT=0`。
   ⇒ **代码侧无未解阻塞**，升级 100% 卡在「没有真实图」。
