## 阶段 67 · 缩放 × 二次转码级联的鲁棒性审计（完成）

**动机**：阶段 49~66 的结论全在 640² 无损合成图上，阶段 63 只补了「同分辨率」的 JPEG。
真实链路是**缩放 + 有损再编码**两级叠加，而缩放会改变水印的**绝对像素尺寸**——正是
`DETECT_MIN_AREA_REF=640` 锚点最敏感的维度。

**口径**（沿用阶段 63 教训）：真值只由未受扰动的一对（base vs marked 原生 640²）求；
缩放同步施加到真值掩码（最近邻）；编码只作用于被测输入。

**发现**：
1. **完全空掩码（静默漏检）**：320² JPEG 角标、256² 网格召回 **0**（界面只显示「未检测到水印」）；
2. 部分崩塌：召回掉至 11~52%（`photo+WebP75+角标` 最典型）。

**归因（关键）**：逐策略调用显示失败在**策略内部**——同图 PNG 下 logo 策略返回 3390px/1 区域，
JPEG 下**全策略归零**；不是阶段 57 修的共享面积门限。这解释了它为何长期未被发现（门禁全在
640² 无损图）。

**否证的假设**：『黑屏时仍有候选证据、干净图毫无候选』→ 实测候选覆盖率分别 1.31~2.44% 与
0.78~2.26%，**完全重叠**，不能作触发条件。

**方案四臂选型**：现状 73.8%（最差 0%、黑屏 4）/ 规范化替换 85.2%（但制造新崩塌 100%→14%）/
**并集 91.5%（最差 52%、黑屏 0）** / 线性插值并集 89.7% → 取**并集 + INTER_CUBIC**。

**实施**：`DETECT_LOWRES_RESCUE` + `DETECT_LOWRES_RESCUE_SIDE=640`；长边 <640 时把输入提升
到 640 完整检测一次，与主结果并集（递归深度锁 1；在覆盖率安全闸之前合并）。仅 <640 生效 →
**≥640 口径逐位不变**。

**零回归双确认**：门禁聚合（误报 0.79%、精确率 51.3%、召回 82.3%、IoU 49.4%、ΔPSNR +12.60 dB）
与 `detector_diag.py` 均与阶段 66 基线**逐位一致**。

**关键冲突与裁决（本阶段最重要）**：兜底会把**原生小图**的高频噪点按倍率²放大 →
干净图四预设平均误报 256² textured **0.80% → 7.98%**（默认预设 general 亦 0.0%→4.66%），
且倍率标定显示**任何 >1.0 的倍率都突破阶段 57 的 2% 红线**（1.25× 即 2.87%）。
按铁律「宁可漏检，不可滥杀」（误解修复不可逆、漏检只是可见瑕疵）→ **默认关闭**，
作为**部署级放行闸**（与阶段 61 的 `POSTPROCESS_TEXTURE_ALLOW`/`POSTPROCESS_POISSON_ALLOW` 同范式）。

**收益（受影响档位 = 长边 <640 的 81 个单元，已排除极淡平铺）**：
平均召回 **81.2% → 94.3%**、最差单元 **0% → 52%**、黑屏 **4 → 0**、召回 ≥90% 的单元 **50 → 66**。

## 阶段 68 · 质量门禁纳入「交付链」口径（完成）

**动机（一个已记录却始终没落地的缺口）**：经验第 6 条「质量评估口径必须等于用户实际交付
链路」此前只靠 6 例单测守着。核实 `quality_gate.py` 的逐引擎循环，确认只有
`out = inpaint(...)` 一行——**从未调用后处理**。这正是阶段 60 三个缺陷（边缘融合把原图水印
像素混回掩码边界 / 全图统计色彩还原 / 掩码内锐化）能长期隐藏的原因：最严重时角标用例
**掩码区** PSNR 38.4 → 11.5 dB，而门禁全绿。

**实施**：
- 交付链臂：`postprocess(out, original_rgb=marked, mask=pred, superres=False,
  real_superres=False)`——**显式关超分**，否则 `config.user_overrides.json` 会让成品变成
  1280²、与 base 不可比（阶段 60 踩过此坑）；异常/尺寸不符记为 None 而不阻断门禁；
- 新口径 `_psnr_region`：只统计**掩码区**的 PSNR（全图按面积加权会被未改动区域稀释，
  回答不了「擦干净了没」——阶段 65 的裁决依据）；`masked_drop = 裸 − 交付`；
- 新红线 `DELIVERY_MASKED_MAX_DROP = 0.01 dB`；交付链全图 ΔPSNR 进聚合 + 基线漂移监控；
- **红线只锁掩码区**：全图 ΔPSNR 下降来自刻意保留的内容区锐化，设成红线会逼后人关掉它。

**实测（640 全量）**：掩码区 **12/12 持平或小幅提升**（最差 −0.01 dB，即改善 0.01 dB）；
全图 ΔPSNR **+12.60 → +11.44 dB**（−1.16 dB 全来自内容区锐化的观感取舍）；既有聚合值
（误报 0.79% / 精确率 51.3% / 召回 82.3% / IoU 49.4% / ΔPSNR +12.60）**逐位不变**
——本阶段只加测量、不改检测与修复行为。
