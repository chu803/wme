## 阶段 57 · 端到端质量门禁 + 分辨率鲁棒性收敛（完成）

**动机**：49~56 的成果只有手工脚本与文档维系，`tests/test_benchmark.py` 只用假数据校验
聚合逻辑；真实端到端质量没有任何自动化护栏。

**做了什么**：
1. 新增 `scripts/quality_gate.py`：检测+修复端到端门禁。① 绝对红线（干净误报≤2%、精确率
   ≥35%、IoU≥35%、corner_logo/edge_text ΔPSNR>0）；② 基线漂移（对
   `docs/assets/quality_baseline.json` 比对，容差内只拦变坏）；判定纯函数 `evaluate()`。
   全量基线 640 口径：误报 0.83%、精确率 47.7%、IoU 46.0%、召回 82.3%、ΔPSNR +9.76 dB。
2. **门禁首跑即在 320² 触红（4.14%）→ 抓出分辨率依赖缺陷**：尺寸扫描显示干净误报率随
   输入变小单调飙升（textured 896² 0.39% → 256² 16.97%）。策略隔离定位元凶是半透明通路，
   preset 拆分确认 tiled/grid 通路同样受影响（ai_faint_tiled 256² textured 达 29.98%）。
3. **根因**：min_area = 占比 × 整图面积 的纯相对门限随面积平方缩水（256² translucent 13px、
   tiled 3px），绝对像素尺寸的纹理噪点成群通过。修复：`config.DETECT_MIN_AREA_REF`(640) +
   `core/detector._min_area_px_floor` 接入 translucent/tiled/grid/logo 四通路。
4. **结果**：textured 256² 16.97%→**0.80%**、320² 11.37%→**1.96%**、448² 4.09%→**1.30%**；
   **640 逐位不变**（detector_diag 全量 + 门禁基线比对双确认）；小图 corner_logo/grid 精确率
   不降反升（256² textured corner 22.6%→100%、grid 4.8%→35.0%），grid 召回 95%+。
5. 门禁新增 `--sweep` 尺寸扫描护栏（textured/photo × {256,320,448,640}，红线 2%，实测 1.96%）。
6. 新增 `tests/test_quality_gate.py` **15 例**（判定语义锁死 + 尺寸红线 + 绝对下限语义 +
   集成冒烟），全过。
7. 全量回归 **486 passed + 6 skipped，零失败**（累计 492 例）。
8. 临时探针 probe_size_fpr / probe_strategy_fpr / probe_preset_fpr 已删除。

**交付物**：`docs/57-端到端质量门禁与分辨率鲁棒性收敛设计.md`、`docs/assets/quality_baseline.json`、
README（§2.5 新增 + §6 边界 + §7 第 8 项 + 计数 492/57）、TODO（P1.12）、MEMORY（阶段→57、

## 阶段 58 · 网格通路高分辨率召回归零修复（完成）

**动机**：阶段 57 记录的遗留边界"网格 ≥896² 召回归零"，复查判断为真实缺陷——真实平台
网格叠加层是绝对像素绘制（不随画布缩放），AI 图 1024²+ 正是此类输入，网格通路曾静默失效。

**根因（镜像问题）**：grid 通路 min_area 是纯相对量，随面积平方**增长**——896² 门限
40px > 网格点 ~28px，真网格被"太小"整体滤空。逐级打印确认：`is_grid`（ACF 周期判据）
在 1280² 仍为 True、折叠模板正常，失效点就是最后的面积过滤。（阶段 57 是相对量随面积
缩水→小图误报；阶段 58 是随面积放大→大图滤真，同一公式的两个方向。）

**修复**：grid 通路 min_area = `min(int(area*ratio*0.25), _min_area_px_floor(ratio, relax=0.25))`
（640 等效上限 20px）。<640 维持纯相对（小图行为/单元测试不变），≥640 恒 ≤20px，
绝对尺寸网格点全程可过。与阶段 57 散斑通路"下限"互为镜像。

**结果**：896/1024/1280 grid 召回从 ~0 恢复至 gradient/photo 97.8~99.9%、textured
76.5~88.7%（信息论水平）；**640 口径与阶段 54 发布值逐位一致**（38.6/33.3/42.7%）；
高分辨率干净误报 <2%（768² textured 平均 1.60%、1024² 0.95%）。

**交付**：`docs/58-网格通路高分辨率召回归零修复设计.md`、`tests/test_grid_resolution.py`
**9 例**（896/1024 召回≥90%、640 零回归、360² 小图碎片守护、1024 干净误报<2%、夹紧语义），
全过；README §2.6 + §6 边界改已解决 + 计数 501/58、TODO P1.13、MEMORY（阶段→58、镜像
经验已并入经验4）、本日志。临时探针 probe_grid_debug 已删。

**方法论沉淀（并入 MEMORY 经验4）**：相对阈值既会"随尺寸缩水→小图误报"，也会"随尺寸放大
→大图滤真"；散斑口径要钳**下限**、被结构判据确认的网格口径要钳**上限**，锚点都是 640 等效值。

## 阶段 59 · 预设推荐器纹理/照片底图准确率收敛（完成）

**动机**：预设推荐器是自动模式的"入口"（决定用哪个预设去检测，即阶段 49~58 成果在真实
UI 流程里的可达性），但只在纯色合成自检过。用 benchmark 底图实测暴露 3 个系统性缺陷：
① `_marks_at` 百分位阈值在纹理/照片底图上恒定选 46.75% 像素（阶段 49 消灭的反模式在
推荐器里复活）→ grid 被推成 general → 网格召回 0；
② 底部小字字形（44×18）被误判为角标 LOGO → 文字水印被推给无 edge 策略的 ai_logo → 召回 25.8%；
③ 全局渐变优先级最高，吞掉渐变底上的角标/文字信号。

**修复**（3 新 config 常量：`RECOMMEND_MARKS_ABS_MIN`=3、`RECOMMEND_MARKS_SIGMA_K`=4.5、
`RECOMMEND_LOGO_MIN_SIDE_FRACTION`=0.04）：
- `_marks_at` 重写为稳健门限：marks=(residual≥绝对下限) ∧ (score>median+k·1.4826·MAD)；
  干净 textured/photo 覆盖率 46.75%→~0.1%，grid 点阵 0.6~1.1%（分离 6~12×）；
- 角标最小实体边长 ≥4% 图宽（字形 2.8% 被排除，品牌角标 11% 保留）；
- 决策顺序重排：logo→平铺→网格→文字→签名→全局渐变→兜底。

**结果**（textured/photo）：grid→ai_grid 召回 88.7/99.2%、corner→ai_logo 100%、
edge_text→ai_signature 98.2%（与 ai_text_heavy 同启用 edge 策略，功能正确）、clean→general。
既有推荐器测试 37 例零回归；新增 `tests/test_preset_recommend_accuracy.py` 11 例全过；
**全量 506 passed + 6 skipped（累计 512 例）**。探针已删。

**交付**：`docs/59-预设推荐器纹理照片底图准确率收敛设计.md`、README（§2.7 + §6 边界 +
计数 512/59）、TODO P1.14、MEMORY（阶段→59、经验五、边界）、本日志。

## 阶段 60 · 后处理默认链「去水印保真」审计与修复（完成）

**动机**：质量门禁/benchmark 测裸 inpaint，UI 交付的却是后处理增强链（色彩还原+边缘融合+
锐化）成品——默认链从未被 GT 审计。

**审计发现**（逐环节归因，全部有数据）：
- 旧 edge_blend 把原图按 alpha 混回掩码边界带（掩码内侧原图=水印像素）→ corner_logo 掩码区
  PSNR 38.4→11.5、no-ref −0.06→−1.88（单独该步 12.3 dB）；
- 旧 color_match 全图外部统计+std 重缩放 → 渐变底 −18 dB；改局部环带(4~16px)均值对齐后
  稀疏/条带掩码（网格点/文字行）仍错位 −7 dB；
- sharpen 全程施加 → gradient grid/edge 掩码区 −6~7 dB（放大 inpaint 平滑面残留）。

**修复**：
- edge_blend：只用 result 自盒式模糊柔化掩码内边界带，绝不引入原图；无内部核的薄/小掩码
  跳过（文字行/网格点不再被抹糊）；
- color_match：语义修正为局部环带均值对齐（去 std 重缩放），且默认关闭
  （POSTPROCESS_COLOR_MATCH=False）——去水印不该动修复区颜色，opt-in 保留；
- sharpen：只作用掩码外（掩码内保留 inpaint 原始结果）。

**结果**：默认链掩码区 PSNR **零退化**（12 用例最差 Δ=0.0，多例 +0.2~+0.9）；ctx 小幅损失
来自内容区锐化（观感取舍，合成噪点图偏悲观）。修复前默认链曾让 corner_logo −26.9 dB。
新增 `tests/test_postprocess_fidelity.py` 6 例；既有 test_postprocess 零回归。

**交付**：`docs/60-后处理默认链去水印保真审计与修复设计.md`、README（§2.8 + §6 + 计数
518/60）、TODO P1.15、MEMORY（阶段→60、经验六）、本日志；探针已删。

## 阶段 61 · 可选增强真值审计与部署级放行闸（完成）

**动机**：阶段 60 把可选增强（纹理重建/Poisson/伪影抑制/轻量超分，默认关）列为待审项。

**审计发现**：
- **纹理细节重建是死代码**：detail 只在掩码外保留、注入权重只在掩码内非零 → 乘积恒 0，
  全 12 用例 Δ=0.00 精确印证——该功能自阶段 21 起从未生效，旧单测只断言"不报错+形状"。
- 修好（cv2.inpaint 把外部细节延拓进掩码区）后实测**净负收益**：gradient corner_logo
  −12.6 dB、textured corner_logo −3.3 dB（外来高频无法还原真实纹理 + 可能带入掩膜外
  残留水印高频）。
- **Poisson 融合极端不稳定**：−26.4 ~ +15.9 dB；试过"干净背景作 dst"仍无效（机制本身问题）。
- 伪影抑制 +0.0~+0.4、轻量超分 ≈0，中性保留。
- 无参考质量分对"统计自洽但内容错误"的劣化不敏感——自动回退网拦不住上述两项。

**处置**：纹理重建与 Poisson 加**部署级放行闸**（`POSTPROCESS_TEXTURE_ALLOW` /
`POSTPROCESS_POISSON_ALLOW`，默认 False）；新增 `_revert_if_worse` 自动回退网（best-effort，
`POSTPROCESS_AUTO_REVERT` 默认开）接入可选增强四步；纹理重建加外围纹理不足跳过
（`POSTPROCESS_TEXTURE_MIN_DETAIL`=1.5）。共 5 个新 config 常量。

**验证**：修复后两危险项全用例 Δ=+0.00（闸门生效）；`tests/test_optional_enhance_gate.py`
**8 例**全过（纹理不再死代码 / 平滑跳过 / 双闸门 / 自动回退正反例 / 默认开）；
既有后处理测试零回归；**全量 520 passed + 6 skipped（累计 526 例）**。

**交付**：`docs/61-可选增强真值审计与部署级放行闸设计.md`、README（§2.9 + §6 + 计数
526/61）、TODO P1.16、MEMORY（阶段→61、经验七）、本日志；探针已删。P0 真实图验证不变。

**方法论沉淀（经验七）**：死代码会伪装成已验证功能——对任何"增强"先测"有没有改变结果、
变了是更好还是更坏"；启发式质量分只能做 best-effort，安全兜底要用确定性闸门。
