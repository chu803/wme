- **根因（grep 全库证实孤立）**：`scripts/cpu_load.py` 是**唯一**用 `ctypes.windll`/`ctypes.WinDLL` 的文件；`tests/test_cpu_load_probe.py` 有 **7 个用例**调它却**无 win32 守卫** ⇒ Linux（CI ubuntu）上 `ctypes.windll` 不存在 → `AttributeError` 假失败。这是「仓库空→**首次 Linux CI**」暴露的 Windows 专有假设。
- **修复**：加 `_IS_WINDOWS` + `_win_only` skipif，只守卫那 7 个 Windows 用例；保留 3 个纯逻辑用例（verdict/doc/不可靠样本）全平台跑。本地 Win 复跑 **10 passed**（守卫不误伤 Windows）；Linux 将 7 skip + 3 pass ⇒ rc=0。
- **教训（固化）**：CI 等价验证不能只跑 pytest 子集，还须考虑**目标 CI 平台（Linux）vs 开发平台（Windows）**差异；Windows-only ctypes 代码的测试必须加平台守卫，否则首次 Linux CI 全红。
