- `test_L0_legacy_unique_name_posix_does_not_strip_backslash`：

  对 Windows wheel 成立；但 **manylinux 的 opencv 5.0.0.93 wheel 带 libavif**，runner 上真写出 `.avif`
  ⇒ `assert saved.endswith(".png")` 翻红。修法：显式模拟 `.avif` 编码失败（只拦 .avif，PNG 保持真实），
  删掉原来 `try/except cv2.error → pytest.skip` 的挡箭牌。
- 归类：**第五类环境假设 = 同一版本号 wheel 在不同 OS 上带的编码器/后端可以不同**
  （前四类：OS 二进制、路径语义、时区/CRLF、字体）。
- 通用判据：凡"本环境没有 X"的注释，先问一句"哪个 OS / 哪个轮子没有？"
