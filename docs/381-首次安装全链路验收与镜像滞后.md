## 发现的问题一：国内镜像滞后，旧建议会装到带缺陷的版本

实测（2026-11-05）：

- 官方 PyPI：`1.0.4 / 1.0.5 / 1.0.6` 都在；
- 清华镜像：最新只有 **1.0.3**；
- 阿里镜像：最新只有 **1.0.3**。

而 1.0.3 **不含**阶段 379/380 的两个修复（装完「一键修复」回不来结果）。
README 原文建议「整包换镜像」，等于**把用户导向带缺陷的旧版**——必须改。

同时实测官方源直连很慢：numpy 12.6 MB 用了 **6 分 23 秒**（约 36 kB/s），
opencv 的 43.8 MB 按此速度还要 20 分钟。

**改法（已实测有效）**：两步装——本体走官方源、依赖走镜像：

```bash
pip install --no-deps -i https://pypi.org/simple/ wme-watermark-eraser
pip install -i https://mirrors.aliyun.com/pypi/simple/ wme-watermark-eraser
```

第二条命令发现本体已装好 ⇒ **只补依赖、不降级**（pip 报 `Requirement already satisfied`）。
已在第二个全新 venv 上完整复现这两步。

README 的「3 分钟上手」与 §3.3 都改成了这条建议，并明确「不要整包换镜像」。

## 发现的问题二（已知、不改）：PDF 是可选依赖

本版选择：**保持可选**（安装体积小），但把安装命令写进 README。
