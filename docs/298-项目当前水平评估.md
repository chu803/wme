## 竞品定位（未受控横评，显式标注）
- **IOPaint**（开源领头 ~23k★，**2025-08 已归档停更**）：本地离线✅、免手涂❌（需手动涂抹）、仅图片、无 PDF/视频。
- **HitPaw 桌面**：本地✅、选区+多模式、图+视频、$12.99/月买断。
- **云端 SaaS**（Media.io 等）：上传/积分制、便利但非离线、隐私弱。
- **本作护城河**：免手涂自动 + 图/PDF/视频全源 + 本地离线 + 合规（仅去本人生成内容）+ 可复跑工程质量（2504 用例/45 模块审计）。「维护中的本地自动去水印工具」是空位机会。

## 诚实边界（披露，非隐藏）
- **本机 managed venv 未装 numpy/gradio 等全套依赖**，未能在此真跑全量 `pip install .` 拉起 Gradio；`publish.yml` 在 GitHub 官方环境会替你补验。
- **GPU（RTX 5060 / Blackwell cu128）未实测**，Python 本机仍是 CPU 版 torch；full 管线 8.585s 与 detect 0.776s 均为 CPU 口径。
- **权重不入包**：`big-lama.pt` 首跑由 `download_model.py` 下载。
- 当前 none-blocked 建设性前沿已确认穷尽（续审链/全量回归/打包/CI/Docker/发布管线均落地）；继续自主推进只会产出边际审计或逆向阶段 95 的承诺面扩张，二者都是项目反对的 busywork。真正向前推进卡在：数据（precision/覆盖）、机器（GPU/真 docker build）、发布决策（PyPI/API 鉴权）——需用户给其一。
