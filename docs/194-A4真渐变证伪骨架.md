## 1. 关键发现（决定证伪口径）

| 项 | 事实 | 对证伪的影响 |
|---|---|---|
| `DETECT_GRADIENT_ENABLED` 默认 **False**（`config.py:1487`） | 默认 `detect_watermark_mask` **根本不跑渐变通道** | 若用默认值跑真图，会得到**假阴性零触发**被误读为「证伪成功」——这是 118 当年最可能的失准来源之一 |
| `detect_gradient_watermark` 判据（`core/detector.py:2166`） | `plane_mag > 12.0` 且 `explained > DETECT_GRADIENT_MIN_EXPLAINED` 且 `res_std < 32.0` | 真实 12% 不透明度的平滑渐变，灰度平面幅度**可能不足以过 `plane_mag>12`** ⇒ 真渐变仍可能零触发（需实测） |
| 合成 0→255 强渐变（本阶段自测） | `enable_gradient=True` 下**能识别**（覆盖 100%、区域数=1） | 证明通道逻辑本身能工作；118 的「0/0/0」更可能是「图不对」或「默认关」，而非「通道全坏」 |

**结论性口径**：证伪必须显式 `enable_gradient=True`（绕过默认 False），只回答「渐变通道打开后，
真渐变图能否被识别」这一干净问题。本脚本已强制开启。

## 2. 交付物

| 文件 | 作用 |
|---|---|
| `scripts/a4_gradient_proof.py` | 对一组图显式 `enable_gradient=True` 跑检测，统计 `KIND_GRADIENT` 命中数与整图覆盖率，输出每图一行 + 汇总 + 判定建议；`--json` 落盘；退出码 0=有触发 / 1=零触发 |
| `tests/test_a4_gradient_proof.py` | 3 例确定性自测（不依赖真实图）：① 合成强线性渐变 → 命中；② 纯噪声 → 不误报；③ 同一渐变图 `force_gradient=False` 会假阴性零触发（反向钉死脚本必须强制开启的陷阱） |

**自测结果**：3 例全绿；合成强渐变图 CLI 端到端「✅命中 覆盖=100.0%」，退出码 0。

## 3. 实验设计（你出图后即可闭环）

1. **出图**：用 `docs/117` §3.4 **v2 修正版提示词**（强否定约束：绝不出现文字/LOGO/图案）+ §3.5 **金标增强**（每类带 `_clean` 无水印版，供相减导出 bbox）+ §4 场景清单里 `ai_gradient` 的 3~5 个场景（沙漠暮色 / 深海潜水 / 霓虹街道 / 极地冰川 / 抽象色彩流动）。
2. **收编**：`python scripts/collect_real_assets.py add <路径> --ai-source other --style gradient_watermark --copy`
3. **预检**：`python scripts/real_asset_preflight.py`（来源与结构预检）
4. **证伪**：`python scripts/a4_gradient_proof.py --dir <出图目录>` ← 本阶段脚本
5. **判定**（脚本自动给出）：
   - **触发数 == 0** → 检测器对真渐变恒零触发。证据支持二选一：
     - ① **修通路**：放宽 `detect_gradient_watermark` 的 `is_gradient` 判据（plane_mag / explained / res_std 阈值，或换低频特征）；
     - ② **降级宣传**：README 不再把 `ai_gradient` 列为「支持类型」，保留于 `KNOWN_SYNTHETIC_GAP` 显式钉死缺口（与当前 `WATERMARK_TYPE_COMMITTED={ai_logo}` 口径一致）。
   - **触发数 > 0** → 通路能识别真渐变，但还需测「修复质量」（mask 是否整图、修复后是否留痕、与 `ai_gradient` 预设的修复链路是否打通）。
