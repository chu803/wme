## 一、方法（可复跑的判据）

在真浏览器里对**当前页签所有可见文本节点**做 WCAG 对比度计算：

- 取 `getComputedStyle(el).color` 作为前景；
- 沿 DOM 向上找第一个 `alpha >= 0.99` 的 `background-color` 作为背景（忽略半透明背景，记为已知近似）；
- 相对亮度按 WCAG 公式；正文要求 **≥4.5:1**，大字号（≥24px，或 ≥18.66px 且 bold）要求 **≥3:1**；
- 报告低于阈值的元素（对比度、文本片段、字号）。

## 三、修法

Gradio 自带的空状态提示在 `.image-container .empty.wrap` 里，深色主题给的是
`rgb(107,114,128)`（在 `rgb(30,41,59)` 上 3.03:1）。主题里把它提到 `#9ca3af`：

```css
.gradio-container .image-container .empty.wrap,
.gradio-container .image-container .empty.wrap * { color: #9ca3af !important; }
```

实测该处对比度约 **5.6:1**，整页复扫 **0 违规**。
