## 1. 动机：阶段 82 只关掉了「大头」，剩下的是最像水印的那部分

阶段 82 的自然光影守卫按「**边缘是否锐利**」放行：人工叠加边缘锐利 → 保留；
自然光影过渡平滑 → 抑制。这条路有效（真实精确率 1.29% → 3.08%），但留下一个结构性缺口：

> **真实照片上的锐利自然纹理**——树叶、枝干、草地、织物纹理、砖墙、护栏——
> 边缘**本身就锐利**，因此整片纹理照样通过守卫。

它们成了残余误报的大头：约 40% 的真实 FP 幸存，**每图约 60 个区域**，且多为「实心大块」
（视觉上就是一大片被误认为水印的树叶）。

继续调「锐度」是没用的——这些区域的锐度与真水印一样高。需要**另一个正交特征**。

## 2. 方法：梯度稠密度（结构 vs 处处高频）

「边缘锐利度」量的是**梯度有多强**；缺口在于纹理的梯度也很强。新的判别量是
**梯度有多稠密**：

```
density = #{ p : gmag(p) > 0.5 × mean(gmag) } / #p         域 = 候选像素 ∪ 膨胀 2px
```

| | 残差场的梯度分布 | density |
|---|---|---|
| **人工水印**（结构化图形） | 笔画/色块内部**平坦**，梯度集中在轮廓 → 少数像素很高、多数像素接近 0 | **低** |
| **自然纹理**（处处高频） | 灰度在域内处处起伏，梯度分布"摊平" | **高** |

### 2.1 为什么这个判据比「梯度均值」好：它是比值

`density` 是**同一统计量内部的比值**（`gmag` 与其自身的均值比较），因此：

- **与残差振幅解耦**：残差整体放大 N 倍 → `gmag` 与 `mean(gmag)` 同倍放大 →
  「谁超过 0.5×均值」这个集合**逐一不变** → 判定逐位相同（有专门的不变性测试锁定）；
- **与图像尺度解耦**：不依赖任何绝对像素量；
- **不需要 `scale` 参数**：这是它与自然光影守卫（`edge_sharp ≥ 94×scale`）的结构性差异，
  签名里刻意没有 `scale`（有测试断言签名）。

若改用「梯度均值/绝对锐度」，就必须再标定一套随分辨率缩放的阈值——而阶段 82 已经证明
（经验 32）改统计定义会连带推翻所有依赖它的阈值。

### 2.2 与自然光影守卫的关系：正交 + 串联

| | 问的问题 | 放行条件 |
|---|---|---|
| 自然光影守卫（82） | 「平不平滑？」 | `edge_sharp ≥ 94×scale` **OR** `ratio ≥ 8.0` |
| **纹理稠密守卫（84）** | 「稠不稠密？」 | `density ≤ 0.65` |

两者是**串联**（都必须通过），不是二选一——一个候选可以「锐利但稠密」（树叶边缘）
或「平滑但稀疏」（渐变天空），需要两道都过。测试断言了两者的执行顺序（顺序即语义）。

在 `detect_translucent` 中，本守卫接在自然光影守卫之后、连通域过滤之前——
保证掩码与区域列表始终一致（阶段 82 的教训：改几何的步骤输入必须是「确认存活」的集合）。

## 3. 标定：双口径扫描 + 安全窗

### 3.1 特征分离度（连通域级——守卫实际作用的层级）

在守卫的**真实调用点**记录每个候选连通域的 `density`，按「是否与真值框相交」分组：

| 组 | n | p50 | p75 | p90 | p95 | max |
|---|---|---|---|---|---|---|
| 与真值相交 | 145 | 0.551 | 0.600 | 0.705 | 0.753 | 0.770 |
| 不相交 | 9935 | 0.696 | 0.740 | 0.772 | 0.790 | 0.886 |

> **为什么必须用连通域级、而不是合并后的区域级**：守卫作用在**连通域**上，
> 而召回/精确率是**区域级**指标，中间还隔着碎片聚合（82）与覆盖率闸。
> 用区域级特征去标定连通域阈值，层级错配会导致「离线看得很准、接线后效果不同」。

- **安全窗 = (0.62, 0.69)**：

## 5. 门禁更新：红线升级 + 标定表单一来源

### 5.1 精度红线 0.025 → 0.034

新红线**同时编码两个守卫**：

| 注入 | 实测精确率 | vs 红线 0.034 |
|---|---|---|
| 全开（现状） | 0.0388 | ✅ 通过 |
| 关 `WME_DETECT_TRANSLUCENT_TEXTURE_GUARD` | 0.0308 | ❌ 破红线 |
| 关 `WME_DETECT_TRANSLUCENT_NATURAL_GUARD` | 0.0224 | ❌ 破红线 |

即**任一守卫被回退都会触发红灯**——这正是「红线 = 结论的编码」应有的形态。

### 5.2 标定表抽为单一来源

原先标定值散在测试文件里（`_STAGE_A4_GENERAL` / `_STAGE_82_GENERAL`），
阶段 84 起抽到 `scripts/real_gate.REAL_REDLINE_CALIBRATION`，测试直接读它：

```python
REAL_REDLINE_CALIBRATION = {
    "recall":    (0.717, 0.9333),   # 方向 A 首轮 → 阶段 82（碎片聚合）
    "precision": (0.0308, 0.0388),  # 阶段 82 → 阶段 84（纹理稠密守卫）
}
```

并新增一条**决策强制点**：`REAL_CRASH_GUARD_METRICS`（当前只有 `mean_iou`）——
任何红线指标必须**要么登记标定区间、要么显式登记为「崩溃护栏」**，
否则测试失败。目的是让「新增一条红线」变成必须回答「它编码了哪个结论？」的决策点，
而不是随手填一个数。

## 7. 测试构造踩过的两个坑（值得记录）

**坑 1：2px 周期棋盘格是 Sobel 算子的零空间。**
第一版用 `((y+x) % 2) * amp` 造「处处高频」纹理，结果 `gmag` 恒为 0
（相邻列取值互补，Sobel 加权和相消）→ 纹理块根本没被抑制，且两个阈值下结果完全相同。
**症状极具误导性**：看起来像「阈值没生效」，实际是构造本身没有梯度。
→ 改用有种子均匀噪声（density≈0.82）。

**坑 2：8-连通下角点相邻的两个块会被合并成一个连通域。**
阈值单调性测试造了三个块，其中两个恰好共角点 (112,112) → 被 `connectedComponents`
合成一个组件 → 台阶从 4 个变成 3 个。
**症状**：单调性成立但台阶数不对——若只断言「单调不减」就会漏掉这个构造错误。
→ 块之间必须留间隙；并额外断言**台阶数**（`len(set(counts)) == 4`），
让构造错误无法伪装成通过。

两个坑的共同教训（并入经验 39）：**用合成构造验证统计判据时，必须先证明构造本身
在目标统计量上「有信号」**——否则测试会在「判据没生效」与「构造无信号」之间无法区分。

## 8. 通用经验（并入 MEMORY）

**39. 合成构造必须先自证「在目标统计量上有信号」。** 用人工构造验证统计判据时，
构造可能落在算子的**零空间**（如 2px 棋盘格对 Sobel）或发生意料之外的形态合并
（8-连通角点相邻）。症状是「判据看起来没生效」，极易被误判为阈值问题。
→ 断言里加入「构造有效性」自校验（如台阶数、密度落点），让构造错误无法伪装成通过。

**40. 新判据要与既有判据正交，而不是更强。** 阶段 82 的缺口无法靠调「锐度」阈值解决——
锐利纹理与锐利水印在该特征上不可分。出路是换一个**问不同问题**的特征
（「平不平滑」→「稠不稠密」），并明确两者是**串联**关系。凡发现「同一特征上调参
已到极限、剩下的错误与该特征高度相关」时，应停止调参，寻找正交特征。

**41. 比值型判据优先于绝对量型判据。** `density` 是「同量纲内部比值」，因此对振幅、
尺度、分辨率全部天然免疫，不需要 `scale` 参数，也不需要为每个分辨率重新标定。
代价是它对「分布形状」敏感（这正是它要测量的东西）。**在能表达同一语义时，
优先选比值型**——阶段 82 的 ratio 通路与阶段 84 的 density 是同一思路的两次应用。

**42. 「安全窗中心」优于「指标 argmax」。** 在 30 张图上扫描出最优阈值并采用，
是把评测集噪声当成信号（过拟合）。正确做法是先划出**不产生任何逐图退化**的安全窗，
再取窗中心——结论对数据集扰动不敏感，且余量可量化（本例两侧各约 0.03）。

**43. 标定值必须集中登记，且「新增红线」要成为强制决策点。** 标定值散落在测试文件里时，
新增阶段容易只改红线忘了改标定。抽为单一来源（`REAL_REDLINE_CALIBRATION`）后，
再加一条「红线必须要么登记标定、要么显式登记为崩溃护栏」的断言，
把「随手填个数」变成必须回答「这条线编码了哪个结论？」的决策。

## 9. 剩余边界

- **合成侧几乎不受影响**：本守卫针对真实分布，合成门禁仅 ±0.5pp 波动（有意为之——
  它不该改变合成结论，事实也没有）。
- **未接入 tiled 通路**：与阶段 82 同样只挂基础半透明通路。tiled 的候选分布
  受激进门限（k=2.2）影响，其 `density` 语义不同（未标定，无证据支持挂上去）。
- **未覆盖「纹理全覆盖水印」**：若水印本身是高频纹理（而非图形/文字），density 会高，
  可能被误杀。当前数据集不含此类样本，**未验证**。
- **F3（corner_logo 白底圆角框）仍未动**：本阶段只解决 F1 残余。
- **真实性收益的第 5 次累积**：精确率仍在 3.9% 量级（绝对水平低），
  距离「可用于生产」尚有距离；下一次收益需换维度（纹理水印 / 背景一致性 / 语义先验）。
