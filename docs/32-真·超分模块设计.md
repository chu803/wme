# 阶段 32 · 真·超分模块（AI 模型 + torch 真实放大）设计文档

> 落地阶段 29 标注的「后续独立模块」：用真实 AI 模型 + torch 做超分辨率放大，
> 替代（或增强）阶段 29 的「同分辨率轻量超分」（cv2 细节重建）。

---

## 1. 背景与目标

阶段 29 的「轻量超分」本质是同分辨率的 cv2 细节重建（注入原图高频 + unsharp），
**不改变画布尺寸**。对「想真正提高输出分辨率」的用户而言，它没有放大能力。

阶段 32 引入**真·超分**：依赖 torch + 预训练模型（ESRGAN / Real-ESRGAN 风格），
把修复结果**真实放大**（默认 4×，可选 2×），显著提升成品分辨率。

核心约束：**lazy-import + 优雅降级**——缺 torch / 缺权重时工厂返回 `None`，
`postprocess_service` 自动回退到阶段 29 轻量超分，保证项目**无 torch 也能完整
测试与运行**（向后兼容、torch-free-testable）。真实超分与轻量超分**互斥**（不叠加），
避免细节过锐 / 双重放大。

---

## 2. 架构

### 2.1 后端（`core/superres.py`，core 层，零 gradio）

- `SuperResBackend`（基类）：定义 `upscale(arr, scale) -> (out, used_real, note)`；
  数组↔tensor 转换与边界校验在基类；子类实现 `_infer`。无法产出放大图时返回
  `(None, False, note)` 供调用方回退。
- `_TorchESRGANBackend`（纯 torch RRDB 风格生成器，无需 basicsr）：
  - 真实 `nn.Module`（卷积头 → 残差块 → `nn.Upsample` 双三次上采样 → 输出）。
  - **lazy import torch**：仅在首次推理时导入，导入期绝不 import torch。
  - 提供并成功加载 `.pth` 权重 → `used_real=True`（真·训练模型推理）；
    缺权重 → 退化为「双三次上采样 + 恒等卷积」的真实 torch 推理管线（放大生效，
    但非学习式），`note` 明确说明并提示配置 `REAL_SUPERRES_MODEL_PATH`。
- `_RealESRGANBackend`（lazy import `realesrgan` + `basicsr`，官方 RRDB x4 权重）：
  缺包即不可用（工厂返回 None）。`used_real` 恒为真。
- `get_superres_backend(kind, model_path, model_dir) -> SuperResBackend | None`：
  - `kind="auto"` → 依次尝试 `realesrgan` → `esrgan` → None。
  - `kind="esrgan"` 先探测 `import torch`，无 torch 直接返回 None（保持契约）。
- `superres_upscale(arr, backend, scale) -> (out|None, used_real, note)`：
  backend 为 None 时返回 `(None, False, note)`，供调用方判断回退。

### 2.2 调用方（`services/postprocess_service.py`）

`postprocess()` 新增 `real_superres` / `real_scale` / `real_backend` /
`real_model_path` / `real_model_dir` 参数。处理顺序末尾的「超分」步骤改为：

```
if real_superres 且具备原图+掩码:
    backend = get_superres_backend(...)
    out_sr, used, note = superres_upscale(out, backend, scale)
    if out_sr is None:        # 真实后端不可用 → 回退轻量超分（若其开关开启）
        if 轻量超分开启: out = _superres(...)
    else:
        out = out_sr          # 真实放大（改变尺寸）
elif 轻量超分开启:
    out = _superres(...)      # 阶段 29 同分辨率路径
```

真实超分放在所有几何/锐化步骤之后、最后锐化之前；真实放大改变画布尺寸，
后续步骤（锐化）按像素处理，不依赖尺寸。

`evaluate_improvement()` 在比较「优化前/后」质量分前，显式把 `improved_result`
resize 回 `raw_result` 尺寸，保证同等像素基准对比（质量分反映清晰度而非分辨率差异）。

## 4. 向后兼容与边界

- **默认值全关**：`REAL_SUPERRES_ENABLED=False`，未传参时行为与阶段 29/18 完全一致。
- **无 torch 环境（当前沙箱）**：后端工厂返回 None → `postprocess` 回退轻量超分，
  全程不改变尺寸、不报错。CLI / UI / 测试均无 torch 依赖。
- **真实放大改变尺寸**：输出文件与「原图」尺寸不同；增强对比视图（`make_compare_array`）
  已支持异尺寸拼接（按高度对齐缩放），热图（`make_diff_heatmap`）同样支持异尺寸。
- **质量分对比**：真实放大主要提升分辨率而非 SSIM；`evaluate_improvement` 已尺寸归一，
  质量分反映清晰度差异，不会因尺寸不同失真。
- **权重管理**：配置 `REAL_SUPERRES_MODEL_PATH` 指向自定义 ESRGAN `.pth` 即可启用
  学习式推理；Real-ESRGAN 后端需另行安装 `realesrgan` + `basicsr`。
