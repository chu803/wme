# 386 · 把实测出来的杠杆放到用户够得着的地方（2026-11-05）

## 背景

阶段 385 量到：承诺类（角标 LOGO）在真实图上**检出 86.3%、完全擦净 62.7%**；
残留的主因是**掩码覆盖不足**（半透明板块只咬住实心笔画）——
把「掩码膨胀」调到 12~24 px，完全擦净率能到 **70%~75%**（框外变化 0.83% → 1.3%~2.1%）。

但**默认膨胀不能动**：阶段 386 的前置实验（`WME_MASK_DILATE_DEFAULT=12` 跑全量门禁）
让 5 条守卫变红——默认膨胀是**按类标定**的（网格类用 0 更好；膨胀会让改动溢出
水印区，撞上"只动水印区"的误伤红线）。

⇒ 用户能自己拉的旋钮存在，但**没人告诉它能拉、拉多少**。

## 改法

「掩码膨胀」滑块的说明（zh/en）补上实测指引：

> 把水印区撑大，吞噬半透明羽化边缘。角标 LOGO 擦不净时可调到 12~24
> （真实图实测：完全擦净率 60%→75%，代价是周边多改一点像素）

守卫 `tests/test_dilate_hint386.py`（2 条）：指引必须含可用的取值区间与实测数字，
且原有用途说明不能被替换掉（防止这段话被后来的改写悄悄抹掉）。

## 边界

- 指引来自**角标类**的真实图实测；其它水印类型不适用（网格类用大膨胀反而更差，
  门禁已钉住）。
- 数字来自 OpenCV 引擎（本机无 LaMa 权重）；装了权重的用户擦净率应当更高，
  具体未测。
- 本轮只改文案与守卫，**不动任何默认参数**。
