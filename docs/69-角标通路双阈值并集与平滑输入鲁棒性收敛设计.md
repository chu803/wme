# 阶段 69 · 角标通路「双阈值并集」与平滑输入鲁棒性收敛设计

> 目标：闭合阶段 67 记录的遗留边界——`photo + WebP75 + 角标` 在重采样后 16~29% 的部分漏检。
> 交付：`DETECT_LOGO_CANNY_ADAPT`（自适应补充通路）+ `_canny_adaptive_pair`（噪声锚定阈值）、
> `tests/test_logo_adaptive_canny.py`（13 例）。

---

## 1. 动机：不是信息论极限，而是**判据的输入敏感**

阶段 67 把 `photo + WebP75 + 角标` 在重采样后 16~29% 的部分漏检记为「已记录边界」。但同尺寸
下 **JPEG75 为 100%**——两者都是有损编码，差异只能来自编码特性，而非信息量不足。据此判断
这是**可修的判据缺陷**而非能力边界。

## 2. 机制定位：固定 Canny 阈值遭遇「梯度被整体压低」

`detect_logo_watermark` 用固定 Canny 双阈值 **(50, 150)** 取轮廓，再做面积/实心率/长宽比过滤。
Canny 的两个阈值比较的是**梯度幅度绝对值**，而 WebP 的平滑（以及重采样插值）会整体压低梯度：

| 尺度 | 编码 | 梯度 中位/MAD/P95 | 轮廓数 | 通过形状过滤 | 召回 |
|---|---|---|---|---|---|
| 640 | png | 15.6 / 5.9 / 32 | 1 | 1 | 100% |
| 640 | jpeg75 | 14.8 / 5.8 / 31 | 1 | 1 | 100% |
| 640 | webp75 | 11.3 / 5.7 / 32 | 1 | 1 | 100% |
| **480** | png | 18.4 / 7.1 / 38 | 1 | 1 | 100% |
| **480** | jpeg75 | 18.4 / 7.1 / 39 | 1 | 1 | 100% |
| **480** | **webp75** | **14.0 / 7.6 / 38** | **2** | **0** | **0%** |
| 960 | webp75 | 8.5 / 4.0 / 23 | 1 | 1 | 100% |

失败形态是**轮廓碎裂**：阈值偏高 → 弱边缘不被纳入 → 闭合轮廓断成 2 块 → 每块要么低于面积
下限、要么实心率不足 → 全部滤除。（同图 PNG/JPEG 的梯度中位数高 4.4，轮廓完整。）

## 3. 阈值扫描：低端存在**能力边界**

| 阈值对 | 480² 召回（png/jpeg75/webp75） | 干净误报（textured/photo） |
|---|---|---|
| 50/150（现状） | 100 / 100 / **0** | 0.00 / 0.00 |
| 40/120 | 100 / 100 / **0** | 0.00 / 0.00 |
| **30/90** | 100 / 100 / **100** | 0.40 / 0.00 |
| 20/60 | **0 / 0 / 0** | 0.05 / 0.49 |
| 12/36 | 0 / 0 / 0 | 0.00 / 0.00 |

即：阈值并非「越低越好」——降到 20/60 以下时，相邻结构被连成一片、轮廓形状失真，
**真轮廓反而不通过实心率/长宽比过滤**。因此自适应的下限必须封在 **30**（能力边界，写进配置注释）。

## 4. 方案裁决：为什么是「并集」而不是「替换」

先试「把固定阈值换成自适应阈值」。自适应规则（噪声锚定，只降不升）：

```
lo = clip(round(med + K·MAD), 30, 50)     # K = 2.0
hi = 3 × lo                               # 恒 ≤ 150
```

实测结果**一半修好、一半打破**：

| 用例 | 固定 50/150 | 自适应（替换式） |
|---|---|---|
| 480² photo/webp75 角标 | 0% | **100%（30/90）** |
| 640² textured/webp75 角标 | 100% | **0%（32/96）** |
| 480² textured/webp75 角标 | 100% | 100%（41/123） |

替换式在 640² textured/WebP 上制造了**新崩塌**——该组合在固定阈值下本可检出，阈值降到 32/96
后真轮廓不再通过形状过滤。这与阶段 67 的结论完全一致：**并集恒优于替换**。

**最终方案：固定阈值主通路 ∪ 自适应补充通路。**

- 并集**严格包含**主通路（⊇），因此**对原本通过的用例零影响**——不是「大概率不退化」，而是
  构造上不可能退化；
- 额外开销可控：高梯度图像算出的 `lo` 会被上限钳到 50 → `_canny_adaptive_pair` 返回 `None`
  → **跳过第二次取轮廓，零开销且行为与阶段 68 完全一致**。

## 5. 实施

`core/detector.py`：

```python
def _canny_adaptive_pair(gray) -> Optional[Tuple[int, int]]:
    mag = |Sobel|; med = median(mag); mad = median(|mag − med|)
    lo = clip(round(med + K·mad), DETECT_LOGO_ADAPT_LO_MIN, DETECT_LOGO_CANNY_LO)
    if lo >= DETECT_LOGO_CANNY_LO:      # 梯度充足 → 不需要补充通路
        return None
    return lo, min(DETECT_LOGO_CANNY_HI, 3 * lo)
```

`detect_logo_watermark` 把原内联的「取轮廓 → 面积/实心率/长宽比过滤」抽成内部函数 `_extract`，
对两套阈值各调用一次；补充通路的区域按 **bbox IoU > 0.5 去重**（同一轮廓在低阈值下会再次出现），
掩码取并集（`fillPoly` 逐轮廓填入）。

配置新增 3 个常量（均有裁决依据的注释）：`DETECT_LOGO_CANNY_ADAPT`（默认 True）、
`DETECT_LOGO_ADAPT_SIGMA_K`（2.0）、`DETECT_LOGO_ADAPT_LO_MIN`（30）；
另把原先硬编码的 `50/150` 抽为 `DETECT_LOGO_CANNY_LO/HI`。

## 7. 边界（诚实声明）

- 自适应下限 30 是**能力边界**：更低阈值会让轮廓形状失真而更难通过过滤（§3 实测）；
- 本阶段只覆盖「角标/实体 LOGO」通路（`detect_logo_watermark`）；边缘小字与网格通路使用各自
  的判据，未受影响；
- 标定基于合成图；真实照片上的梯度分布不同，补充通路的触发频率可能更高（`K`/下限可配置）。

## 8. 经验沉淀（已并入 MEMORY 第 14 条）

14. **「已记录边界」要区分「信息论极限」与「判据缺陷」（阶段 69）**：同一个失败组合，若**同尺寸
    换一种编码就能成功**（WebP 0% vs JPEG 100%），那基本是判据缺陷而非能力边界。修法上，
    再次验证了阶段 67 的结论——**并集恒优于替换**：替换式会让另一组原本通过的用例崩塌
    （640² textured/WebP 100%→0%），而并集在构造上不可能退化（⊇ 主通路），
    且可通过「高梯度图像自动退回主阈值」把附加开销压到零（返回 None 直接跳过）。
