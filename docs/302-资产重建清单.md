## 2. 运行时产物目录（gitignore，丢了不影响代码，可重建）

- cache/（history/thumbs/uploads）：**history 是用户处理历史，丢失不可恢复**；
   thumbs/uploads 为中间产物。⇒ 重要历史建议定期备份 cache/history。
- outputs/、exports/、logs/：处理输出与日志，纯产物，丢失无损失。
- config.user_overrides.json：本机偏好覆盖（gitignore），丢失恢复默认。

## 3. benchmark_real/images/ 等数据资产

- 已在 git（2026-10-05 授权入库，280MB）⇒ checkout 随代码恢复，无需重造。
- 用户侧新增的真实水印图若放在仓库外（如 D:\照片存储），按 P0 采集清单另行保管。

## 4. 一键重建顺序（新机器/事故后）

1. git clone / 已有仓库：git checkout -- .（恢复全部代码与入库数据）。
2. 按下表下载 big-lama.pt 到 models/。
3. python main.py 首启会自动建 cache/outputs/exports/logs 目录。
4. 跑门禁确认：python scripts/real_gate.py --strict-scope（需 GPU + 权重就位）。
