# 392 · 角标 LOGO「板块整块填充」：完全擦净 84.4% → 97.9%（2026-11-06）

## 起点：残差失败的根因（阶段 391）

11 张未擦净样本里 **9 张是"修复前清晰可见、却没擦掉"**；打印检测器输出后发现：
被识别成 `corner_logo` **板块**的图，掩码覆盖板块 65%、擦得掉；
只识别出 `logo_watermark` **字形碎片**的图，掩码只盖住板块的 **5%~14%**
（半透明板块只被咬住实心笔画）⇒ 膨胀只能放大碎片，**补不上板块内部的空隙**。

## 上界实验：三种掩码口径（43 张真实标注角标图）

| 口径 | 完全擦净（NCC<0.30） | NCC 中位 | 框外足迹中位 |
| --- | --- | --- | --- |
| A 现状：只用检测器掩码 | 83.7% | 0.142 | 1.75% |
| **B 只用规范化足迹（实心板块）** | **93.0%** | 0.145 | **0.37%** |
| C 检测掩码 ∪ 足迹 | 97.7% | 0.149 | 2.18% |

⇒ **B 比现状更好**：擦得更净，框外足迹还更低（碎片状掩码会把修复区摊得又散又脏）。
C 虽然最干净，但修复区被撑大（足迹 2.18%）——按项目铁律「宁可漏检，不可滥杀」，
不取"最干净"，取**修复范围最小的那档**。

## 做法

- `config.DETECT_AI_LOGO_PLATE_FILL`（默认开，可 `WME_DETECT_AI_LOGO_PLATE_FILL=0` 关掉）；
- `core/detector.py` 新增：
  - `_ai_logo_plate_box(h, w)`：规范化足迹（340x128 @2048²，随短边缩放、贴右下角）；
  - `_ai_logo_plate_signal(rgb)`：角标模板信号（与角标信号门禁**同一判据**）；
  - `detect_watermark_mask(..., effective_preset=...)`：当**实际预设是 ai_logo**
    且**信号命中**时，把足迹填成实心板块（掩码 + 一个 `corner_logo` 区域）。
- `services/auto_pipeline.py` 把**实际使用的预设**（显式选择或推荐结果）传给检测器
  —— 否则自动推荐到 ai_logo 时不会触发。
- 信号没命中就**不填**（宁可漏检不可滥杀）；信号门禁在自然图上 0 误命中。

## 效果（真实图，50 张，默认路径）

| 指标 | 阶段 388（1.0.11） | 阶段 392 |
| --- | --- | --- |
| 检出率 | 90% | **94%** |
| 完全擦净率（已检出） | 84.4% | **97.9%** |
| 修复后 NCC 中位 | 0.155 | 0.161 |
| 框外修复足迹中位 | 1.88% | 2.09% |

**视觉复核**（`.scratch/plate_visual.png`，左=原图 右=修复后）：角标文字与徽标**确实消失**，
代价是该处留下 OpenCV 修复的糊斑——装上 LaMa 权重后明显改善（阶段 55 的取舍仍在）。

## 守卫与门禁

- 新增 `tests/test_ai_logo_plate_fill392.py`（6 条）：开关默认开且可关、足迹几何、
  只对 ai_logo 生效、**信号闸真走检测器全链路**（信号 0 ⇒ 板块全 0；信号 1 ⇒ 全 255）、
  管线确实传了实际预设。
- ⚠ **提交前回归修复**：第一版填充块的第二个 `try` 无条件重算足迹，把信号闸整个绕过
  （旧守卫只断言自己写的替身 ⇒ 假绿）。已改为「信号 > 0 才填」的单次判定，
  新守卫先跑出 RED（"信号为 0 仍擦了右下角"）再修，证明真能抓 bug（LESSONS #366）。
- 闸修好后**重测**：auto 路径数字不变（推荐器与信号同判据）；forced ai_logo
  检出 96.2% → **90.2%**（无信号图不再被假检出）、完全擦净 **97.8%**、框外 **2.48%**，
  三条红线仍绿。
- 既有门禁复跑：`clean_bench_probe` **0/15 误发**（干净图不受影响）、
  `corner_signal_gate` 绿（路由不变、自然图零误命中）。
- 红线门禁 `corner_removal_gate` 的阈值（检出 ≥75%、完全擦净 ≥65%、框外 ≤3%）
  仍有余量。

## 边界

- 只覆盖**角标 LOGO**（承诺类）；其它水印类型不变。
- 足迹是**固定几何**（贴右下角、340x128 缩放）——对豆包系角标成立；
  别的生成器若把角标放在别处，需要另测。
- "框外足迹"量的是**重绘范围**不是"内容被改坏"（没有无水印原图做参照）。
- 未装 LaMa 权重时是 OpenCV 修复 ⇒ 角标位置会留糊斑（本机实测如此）。
