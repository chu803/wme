## 2. C2 · 红线重标（原则：红线 = 回归地板，不是产品承诺）

**原则**：红线编码「不许从实测退步」（实测 × 约 0.8），产品承诺由
`config.WATERMARK_TYPE_COMMITTED` + README 能力表承担；缺口由**优秀线/文档**保持可见。
（「红线不得松于实测一半」不变式全部保持。）

| 指标 | 旧（伪造期标定） | 真实实测 | **新红线** | 依据 |
|---|---|---|---|---|
| **mask_recall**（头条） | —（未算） | **0.5619** | **≥0.45** | 注入实测 0.3535（关板块通路）→ 红线须在其上 |
| recall（区域） | 0.98 | 0.8000 | **≥0.64** | 实测×0.8 |
| precision | 0.092 | 0.0690 | **≥0.050** | 仍高于三个守卫失效实测（0.0224/0.0308/0.0392）⇒ 守卫被回退仍报警 |
| mean_iou | 0.55 | 0.5347 | **≥0.35**（崩溃护栏，≈实测×0.65） | 满足「≥实测/2」不变式 |
| mask_iou / mask_coverage / coverage_ratio | 崩溃护栏 | 0.2975 / 0.0291 / 2.80 | **保持 0.10 / 0.045 / 4.35** | 现值远在护栏内 |

`REAL_REDLINE_CALIBRATION` 重写为「(失败注入实测, 当前真实实测)」：
`mask_recall (0.3535, 0.5619)` / `recall (0.0, 0.8000)` / `precision (0.0392, 0.0690)`。

**分层设计随重标而明确**（`docs/173` 同款）：红线 **0.64** 宽于漂移地板
`1.0×(1−10%)=0.90` ⇒ **日常回退由漂移先拦、红线只在整段塌陷时兜底**。
