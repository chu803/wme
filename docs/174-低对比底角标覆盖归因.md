# 阶段 174 · 低对比底角标覆盖（残留 4 张）归因

> 承接 173：`mask_recall` 已从 0.354 提到 **0.562**，但 4 张仍低
> （06 花田 0.39 / 07 玻璃 0.27 / 08 抽象 0.03 / 09 打字机 0.23）。
> 本阶段**只做归因**（结论是「不是调参能解的」），**未改代码**。

## 1. 观测：白牌判据在这 4 张上的形态

| 图 | 牌内 Vmean | Vp90 | **Smean** | V≥140 的牌覆盖 / 最大连通块 |
|---|---|---|---|---|
| 06 花田 | **126** | 219 | 38 | 0.36 / 0.25 |
| 07 玻璃 | 166 | 250 | **109** | 0.27 / 0.18 |
| 08 抽象 | 193 | 246 | **110** | 0.19 / 0.07 |
| 09 打字机 | **85** | 199 | 56 | 0.22 / 0.12 |
| （对照）04 霓虹 | 86 | 208 | 47 | 0.22 / 0.06（**却能工作** 0.85） |

两张的牌**明显带色**（Smean 109 / 110）⇒ 被 `S ≤ 80` 排除；
两张的牌**中低明度**（Vmean 126 / 85）⇒ 被 `V ≥ 140` 排除。
但对照行说明：**同样的低覆盖比（0.22 / 0.06）在霓虹上却能工作** ⇒ 覆盖比不是充分解释。

## 2. 决定性实验：放宽白牌判据 **无效**

在 10 张全量上扫两个门限：

| 配置 | mask_recall（micro） | 备注 |
|---|---|---|
| `V_MIN=140`（现状） | **0.562** | |
| `V_MIN=120` | 0.562 | |
| `V_MIN=100` | 0.563 | |
| `V_MIN=85` | 0.563 | ⇒ **门限完全不是约束** |
| `S_MAX=80`（现状） | **0.562** | |
| `S_MAX=110` | 0.536 | snow 0.72→0.37（**变差**） |
| `S_MAX=140` / `255` | 0.477 | snow 0.37，fruit 0.66→**0.15**（**更差**） |

⇒ **两个门限都不是 binding constraint**：调松 `V_MIN` 零收益；调松 `S_MAX` **有害**
（把带色底图的大量区域纳入 ⇒ 连通域形态变了、把牌挤掉）。这与 config 里
「调低 V_MIN：底图亮部会大量入选」的既有告诫一致。

## 3. 结论：残留缺口需要**新的候选模型**，不是调参

既然亮/饱和门限不是约束，剩下 4 张卡在**下游的形状过滤**（`max_aspect` / `solidity` /
`area_ratio` / `ink`）——半透明牌在中低对比底上，其亮区既不成块也不成矩形。
放宽门限只会引入更多**形态不对**的候选，故无效甚至有害。

**已测的备选方向（本轮探针）**：局部提亮源 `lift = V − blur(V, k) > δ`
（对半透明牌天然成立：牌 = 底图的「提亮版」）。
实测**互补但非替代**——暗/彩底上 lift 覆盖约 0.5，但**纯白底上为 0.07**
（白底上牌不提亮）⇒ 若做，必须是**并集源**（whiteness 管亮底、lift 管中低对比底），
且需自带一套形状过滤 + 防误报（`k`/`δ` 标定 + 非角标区误报检查）。

## 4. 诚实边界与下一步

- 本阶段**没有**提升指标（0.562 不变）；产出是**「此路不通」的硬证据**，
  避免把时间花在无收益的调参上（项目既有教训：先归因，别调参）。
- `real_gate` 现状：recall **0.80** / precision 0.069 / mean_iou 0.535；
  红线 0.98 / 0.092 / 0.55 —— **接近但未达**。
- 下一步（择一，都需要先标定 + 双门禁）：

  - **C**：检测器稳定后重建真实基线（`--update`）。
