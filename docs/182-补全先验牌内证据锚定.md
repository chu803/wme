# 阶段 182 · 补全先验牌内证据锚定 —— 干净图误报 0.40 → 0.00（召回零回退）

> 承接 179（`plate_footprint_prior`，杠杆 ON 时 mask_recall 0.5619→0.7665）
> 与 180/181（干净图误报门禁实测 `prior_fp_rate = 2/5 = 0.40`，稳态坐实为 179 先验
> 对「右下角文字/招牌信号」干净图的确定性误发——这是杠杆默认 OFF 的唯一理由）。
> 本阶段给先验加**牌内证据锚定守卫**：把「豆包 logo 证据在牌内」的几何不变式编码为
> 可测量判据，用 n=15 实测分离面（真实 ≥0.54 / 误报源 ≤0.46）定阈 0.50。
> **双门禁结果：干净图 prior_fp_rate 0.40 → 0.00，real_gate 掩码召回 0.7665 零回退。**

## 1. 问题与思路

179 先验的触发条件是「右下角搜索区内有 translucent/edge_text 证据」——但干净图右下角的
文字/招牌同样产生这类信号（180 实测 syn_02/syn_05 稳定触发）。要翻转默认 OFF 或收紧先验，
需要一个能区分「真牌证据」与「普通右下角内容」的判据。

**探针 1（极性）被数据否决**：假设「牌体白板极性（亮低饱和占比）可分离」，实测
`benchmark_real/clean` 合成图 bright=0 但真实暗底牌（ai_logo_04/09/10）bright 仅 0.12~0.15、
ink 高达 0.83~0.87——单靠像素极性不可分（与 lift 三否同理：不能拍脑袋，须实测）。

**探针 2/3（证据几何）分离成立**：关键观察是先验看到的 `all_regions` 是**合并前**的
（合并后结果里 syn_02/syn_05 零信号区域，但 180 实测先验确实触发——观察点必须在
`_apply_plate_completion_prior` 入口）。monkey-patch 捕获入口输入后量测：

| 组 | 最大证据→足迹重叠率（fp_ov） | 说明 |
|---|---|---|
| 10 张真实豆包牌 | **≥ 0.54**（0.54~1.0，全部 translucent） | logo 证据在牌**内** |
| syn_02 / syn_05 误报源 | **≤ 0.46**（0.00 / 0.44 / 0.46） | 文字证据在足迹**外** |

「豆包 logo 证据落在牌足迹内部」是几何不变式，且 n=15 上存在干净分离带 (0.46, 0.54)
→ 取中值 **0.50** 为默认阈值。

## 2. 实现（最小改动，可逆）

- **config.py** 新增 `DETECT_PLATE_PRIOR_ANCHOR_OVERLAP`（浮点 0.0~1.0，默认 0.50，
  `WME_` 前缀环境变量可覆盖）：信号区域与牌足迹（340×128 @2048² 贴右下角）重叠
  ≥ 该比例 × 区域自身面积，才允许补发整牌；**置 0 关闭守卫 = 精确回到 179 原始行为**。
- **core/detector.py** `_apply_plate_completion_prior`：在搜索区循环前计算足迹
  `(bx,by,fw,fh)`，对 translucent/edge_text 信号区域求足迹重叠率，存在 ≥ 阈值者视为
  「锚定」，否则整体 early-return（无图像参数改动，纯几何判据）。
- **tests/test_plate_completion_prior.py** 6→9 条：修正 `test_completion_anchored_bottom_right`
  fixture 至足迹内（旧 fixture fp_ov=0.456 会被新守卫拦截——属预期语义变化）；新增
  ① 远离足迹信号被拦截 ② 足迹内信号正常补全 ③ 阈值置 0 恢复 179 行为。**9/9 全绿**。

## 4. 结论与决策含义

- **179 先验的干净图误报源已被判据级消除**：杠杆 ON + 锚定守卫的组合在「真实召回 0.7665
  不变」的前提下把合成干净图误报从 0.40 压到 0.00。
- **杠杆默认仍为 OFF**（决策不变），但留白性质变化：从「干净图误报率不可测量」变为
  「已测量且可控制（0.00 @合成集）」。默认 OFF 的剩余理由只剩**诚实披露**：
  合成样本仅 5 张且非真实照片，真实照片（含非豆包来源、右下角带招牌）的真实误报率
  仍待 `docs/180` 提示词采集后复测。
- **残留登记**：与牌足迹**几何重叠**的右下角招牌（证据落在足迹内的暗块+文字）与本判据
  同构，守卫无法区分——此类样本须依赖牌体外观级先验（未来工作，非本轮范围）。
  syn_05 的边缘信号 fp_ov=0.46 距阈值仅 0.04，真实照片采集后若出现 ≥0.50 的误报样本，
  需引入第二判据（如牌体亮度一致性）而非继续抬阈值（会杀 ai_logo_06 的 0.545）。

> ⚠ **阶段 183 修正（重要）**：183 的留出探针（`.probe183_holdout.py`）在 30 张**未标注**
> 真实 AI 图上量到：守卫先验新增整牌 **14/30**，且这些样本的锚定重叠 max_fp_ov = **0.62~1.00**
> ⇒ **锚定判据在真实照片上几乎不设限**（证据本就落在足迹内）。故本文 §3 的
> `prior_fp_rate = 0.00` **只对 5 张合成对抗样本成立**，**不可**读成「真实照片误报为 0」；
> 真实照片的 FP 率**仍未测量**（30 张无真值）。这使「杠杆保持默认 OFF」的决定**更稳**
> 而非法更松。详见 `docs/183-门禁标定锚点一致性审计.md` §5。
