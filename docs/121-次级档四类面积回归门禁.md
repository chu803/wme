# 阶段 121 · 次级档四类面积回归门禁（方案 B 落地）

> 承接 `docs/120`（收编次级档）。120 给出的「四类面积全部达标」是一条**结论**；
> 本轮把它从「只有手工脚本能产出」变成**机器可判定**——即回答那个唯一有意义的判据：
> **「把这条结论改坏，有没有任何自动化会失败？」** 120 时答案是「否」，现在答案是「有」。

---

## 1. 四件套

```
scripts/prompted_area_gate.py          # 判定逻辑（纯函数）+ 计算 + CLI
benchmark_prompted/area_baseline.json  # 基线快照（只存判定所需聚合，不存逐图明细）
tests/test_prompted_area_gate.py       # 判定逻辑 + 标定守卫 + 结构 + 集成冒烟（13 快 + 1 慢）
docs/121-*.md                          # 本文件：动机 / 方法 / 标定 / 注入验证 / 边界
```

## 2. 单一真值来源（不重写指标）

本门禁**只加「可比性元数据 + 判定 + 渲染」**，指标一律复用既有唯一实现：

| 复用什么 | 来自 | 为什么 |
|---|---|---|
| `_area_stats`（面积聚合） | `scripts/real_gate.py` | 重写一份「看起来一样」的聚合 = 第二条真值来源 |
| `REAL_AREA_CONTRACT`（四类红线） | 同上 | 红线是**结论的编码**，必须与既有门禁同源 |
| `AREA_DRIFT_TOLERANCE`（15%） | 同上 | 漂移口径同源 |

测试 `test_red_lines_and_tolerance_reused_from_real_gate` **断言这三者是同一对象**——
防止有人日后在本文件里另抄一份阈值。

## 3. 三层判定 + 退出码三分

| 层 | 内容 | 本例落点 |
|---|---|---|
| **第 0 层 数据完整性** | 实际图数 / 每类张数 / 数据集 sha 指纹 == 基线登记 | 防「静默跳过样本」与「换了素材还比大小」 |
| **第 1 层 绝对红线** | `REAL_AREA_CONTRACT`（与基线无关） | 过开火上限 |
| **第 2 层 基线漂移** | 只查「朝红线方向」（面积越大越坏）；基线≈0 时改用**绝对上浮阈值** | 抓**红线之内**的慢性劣化 |

退出码：`0` 通过 / `1` 未通过 / **`2` 跳过**（数据集或基线缺失；`images/` 已 gitignore，
新克隆时**跳过而非通过**，避免"被误删时收获一片绿"）。

## 4. 基线（实测 2026-09-25；每个预设都在**全部 20 张**上跑）

| 预设 | n | cov_mean | cov_p90 | cov_max | 红线(mean) |
|---|---|---|---|---|---|
| `ai_text_heavy` | 20 | **0.0069** | 0.0201 | 0.0324 | ≤ 0.0425 |
| `ai_grid` | 20 | **0.0359** | 0.0986 | 0.1470 | ≤ 0.125 |
| `ai_faint_tiled` | 20 | **0.0182** | 0.0408 | 0.0746 | ≤ 0.075 |
| `ai_gradient` | 20 | **0.0000** | 0.0000 | 0.0000 | ≤ 0.05 + `n_with_mask ≤ 0` |

> 语义说明：每个预设跑**整套 20 张**（而非只跑它"该管"的那 5 张）——
> 这正是面积监控的本意：量**该预设在整套图上的过开火**（与 `real_gate` 的面积监控同口径）。

## 5. 阈值标定守卫

`test_calibration_guard_baseline_under_red_line` 断言（每个预设）：

- `基线 < 红线`（否则门禁**生来就红**，必被无视）；
- `基线 < 红线 × 0.9`（否则基线贴线、**没有余量**）；
- `红线 ≤ RED_LINE_CEILING = 0.5`（否则红线**过松、形同虚设**）。

三者任一不成立即测试失败 ⇒ 门禁**不能被悄悄调哑**。

## 6. 注入式反例（强制，已完成）

注入对象 = 项目**历史上真实发生过的过开火缺陷**：阶段 100 判定的
`config.DETECT_CORNER_MSER_ENABLED`（MSER 降级通路，误报 99.4%，故默认关闭）。
该开关在 `core/detector.py:1447` 是**调用时读取**，故可运行时注入。

| 注入 | 实测 | 判定 |
|---|---|---|
| 默认（MSER 关） | `ok=True`，0 项 | ✅ 通过 |
| `DETECT_CORNER_MSER_ENABLED=True` + `enable_corner=True` | `ok=False`，**7 项漂移** | ❌ **红** |

实测漂移样例（正是要抓的"慢性劣化"）：

```
ai_text_heavy.mask_coverage_mean  0.0069 → 0.0276  (+300% > 容差 15%)
ai_text_heavy.mask_coverage_p90   0.0201 → 0.0517  (+157%)
ai_faint_tiled.mask_coverage_mean 0.0182 → 0.0311  (+71%)
ai_grid.mask_coverage_mean        0.0359 → 0.0463  (+29%)
```

且检测器自身也打出上限告警（`掩码覆盖率 15.2% 超过上限 15.0%，已裁剪`）。
**⇒ 门禁确实抓得住，且抓的正是那条历史缺陷。**

## 8. 边界（诚实登记）

1. **本门禁守的是「次级档」**（提示词渲染水印 × AI 底图），**不是** `benchmark_real` 的承诺面；
   它的红线虽与 `real_gate` 同源，但**适用对象不同**，数字**不可混用**。
2. **`ai_text_heavy` 的真实 recall 仍缺**：需人工逐张框定水印文字（`docs/120` §4）。
3. 集成冒烟**较慢**（20 图 × 4 预设 ≈ 2~4 min），已标 `slow`，可用 `-m "not slow"` 跳过。
4. 本门禁**只在检测器/相关 config 改动后需要跑**；日常文档改动无需跑。
