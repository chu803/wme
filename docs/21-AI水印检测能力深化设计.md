# 阶段 21 · AI 水印检测能力深化设计

> 项目定位：本工具为**去除 AI 生成图片上的水印**（AI 绘图平台给出的可见水印/署名标识）专用。
> 合规底线：只处理用户**自己有权处理**的 AI 生成内容；去除第三方平台署名水印通常违反其服务条款，工具不鼓励该用途。

---

## 1. 阶段定位与范围

阶段 20 已建立了「检测预设体系」（`core/detection_presets.py`）+ 检测算法增强（平铺半透明增强、底部居中搜索区）+ 四入口**服务层**透传（`auto_pipeline` / `pdf_service` / `video_service` / `cli` / `api`），并在**单图/自动页**暴露了「检测模式」下拉。

但当时「检测模式」下拉**仅接到了自动页**，批量页、PDF 页、视频页的检测调用链虽已支持 `preset` 参数，UI 上并未暴露，用户在这些入口只能用统一的默认 `general` 预设，无法一键适配不同 AI 水印样式。

**本阶段目标（用户选定方向：检测能力深化）：**
1. 把「检测模式」下拉**统一暴露到全部四个入口**（单图手动不改、自动已做、批量/PDF/视频本轮补齐）。
2. 在阶段 20 四个内置预设基础上**新增两个预设**：`ai_text_heavy`（文字密集）、`ai_faint_tiled`（极淡平铺），提升两类难检水印的召回。
3. 统一四入口体验与文案（i18n 双语）。

**分层铁律严守**：`core` / `services` / `utils` 零 gradio 依赖；本轮改动 UI 层（`tab_batch` / `tab_media`）仅调用已存在的服务层 `preset` 参数，**未改动任何检测核心数学**（`detector.py` 的 `detect_translucent` / `detect_corner_logo` / `detect_edge_text` 内部算法零改动）。

---

## 2. 新增内置预设

在 `core/detection_presets._BUILTIN_PRESETS` 中，于 `ai_corner` 之后新增两项，使内置预设数由 4 → 6。

| 预设名 | 展示名（i18n 优先） | sensitivity | enhance_tiled | search_bottom | use_ocr | 适用场景 |
|---|---|---|---|---|---|---|
| `ai_text_heavy` | AI 文字密集 | 0.52 | False | **True** | **True** | 满版图文的 AI 生成说明/提示水印；全策略 + OCR 文字识别 + 底部搜索，最大化文字召回 |
| `ai_faint_tiled` | AI 极淡平铺 | **0.72** | **True** | False | None | 透明度极低的平铺 logo；开启平铺增强并进一步提高敏感度，专治几乎看不见的 repeated 水印 |

> 其余四项（`general` / `ai_tiled` / `ai_signature` / `ai_corner`）来自阶段 20，本阶段未改动其参数。
> 预设只「覆盖非 None 字段」，`resolve_preset(name, sensitivity)` 仅把显式设置的字段透传给 `detect_watermark_mask`，未设置字段走 `config` 默认值，向后兼容。

## 3. 四入口检测模式统一

| 入口 | 检测模式下拉 | 说明 |
|---|---|---|
| 单图页（手动） | 不显示 | 设计如此：手动掩码模式由用户绘制掩码驱动，预设无意义 |
| 自动页 | ✅ 阶段 20 已做 | `tab_auto` 的 `detect_preset` 下拉 + `_preset_choice_label` 本地化 |
| **批量页** | ✅ **本轮新增** | `tab_batch` 新增 `detect_preset` 下拉；自动模式透传 `preset`，手动模式隐藏 |
| **PDF 页** | ✅ **本轮新增** | `tab_media` PDF 子页新增 `pdf_detect_preset` 下拉 |
| **视频页** | ✅ **本轮新增** | `tab_media` 视频子页新增 `video_detect_preset` 下拉 |

### 3.1 批量页（`ui/tab_batch.py`）
- `from ui.tab_auto import process_auto_repair, _preset_choice_label` 与 `from core.detection_presets import list_presets`。
- `_process_one(task, ..., preset: str = "general")`：自动模式调用 `detect_watermark_mask(...)` 时补传 `preset=str(preset or "general")`（此前漏传，本阶段补齐，使批量页与单图/自动页行为一致）。
- `run_batch(..., preset: str = config.DETECT_PRESET_DEFAULT, progress=...)`：因 Python 默认参数须后置，`preset` 置于 `compare: bool = True` 之后、`progress` 之前。
- `_processor` 闭包向 `_process_one` 透传 `preset=str(preset or config.DETECT_PRESET_DEFAULT)`。
- `build_batch_tab`：`mode` 之后新增 `detect_preset = gr.Dropdown(choices=[(_preset_choice_label(p.name, p.display), p.name) for p in list_presets()], value=config.DETECT_PRESET_DEFAULT, label=t("batch.detect_mode_label"), info=t("batch.detect_mode_info"))`，并 `reg_label_info` 注册以支持语言切换。
- 手动/自动模式联动：`_toggle_mask_folder` 改为返回 `(gr.update(visible=(m=="manual")), gr.update(visible=(m=="auto")))`，`mode.change` 的 `outputs=[mask_folder, detect_preset]` —— 自动模式显示下拉、手动模式隐藏。
- `run_btn.click` 的 `inputs` 末尾追加 `detect_preset`（位于 `compare_toggle` 之后，与 `run_batch` 签名顺序一致）。

### 3.2 媒体页（`ui/tab_media.py`）
- `from core.detection_presets import list_presets`，并新增模块级 `_preset_choice_label(name, default_display)`（与 `tab_auto` 同逻辑：优先 i18n 键 `detect.preset.<name>.title`，缺失回退 `display`）。
- `run_pdf(sensitivity, ..., preset: str = config.DETECT_PRESET_DEFAULT, progress=...)` → 调 `process_pdf(..., preset=str(preset or config.DETECT_PRESET_DEFAULT))`。
- `run_video(sensitivity, ..., preset: str = config.DETECT_PRESET_DEFAULT, progress=...)` → 调 `process_video(..., preset=...)`。
- PDF 子页在 `pdf_params` 之后新增 `pdf_detect_preset = gr.Dropdown(... list_presets() ...)`（`media.pdf.detect_mode_label/info`，`reg_label_info` 注册）。
- 视频子页在 `video_params` 之后新增 `video_detect_preset`（`media.video.detect_mode_label/info`，`reg_label_info` 注册）。
- `pdf_btn.click` inputs 末尾追加 `pdf_detect_preset`；`video_btn.click` inputs 末尾追加 `video_detect_preset`。

## 4. 调用链

```
┌─ 自动页 tab_auto.detect_btn ──────────────┐
├─ 批量页 tab_batch.run_batch → _process_one ├─► detect_watermark_mask(image, sensitivity, ..., preset)
├─ PDF 页  tab_media.run_pdf   ──────────────┤          │
└─ 视频页  tab_media.run_video ──────────────┘          ▼
                                            resolve_preset(name, sensitivity)  →  DetectPreset.resolve()
                                            （只覆盖非 None 字段 → detector 关键字参数）
                                                        │
                                                        ▼
                                          core/detector.detect_watermark_mask(..., preset=,
                                              enhance_tiled=, search_bottom=)
                                                        │
                                              ┌─────────┴─────────┐
                                       detect_translucent    detect_tiled_translucent（enhance_tiled 时取并集）
                                       detect_corner_logo（search_bottom→底部中央带）
                                       detect_edge_text（+ use_ocr）
```

服务层透传（阶段 20 已完成，本阶段**未改动**）：`services/auto_pipeline.process_image/process_file`、`services/pdf_service.process_pdf`、`services/video_service.process_video` 均已接受 `preset` 参数并向下透传；`cli --detect-preset`、`api.get_capabilities()["detect_presets"]` 此前已暴露。本阶段仅补齐 UI 层暴露。

## 9. 边界与坑点（已修复，记录防复发）

1. **Python 默认参数后置**：初版把 `preset: str = config.DETECT_PRESET_DEFAULT` 放在 `run_batch` 的 `mode` 之后、`engine` 之前，触发 `SyntaxError: parameter without a default follows parameter with a default`。修复：将 `preset` 移至签名末尾（`compare` 之后、`progress` 之前），并同步把 `run_btn.click` 的 `inputs` 中 `detect_preset` 移到 `compare_toggle` 之后，保证位置与签名一致。
2. **`get_preset_choices()` vs `list_presets()` 返回类型差异**：`get_preset_choices()` 返回 `(display, name)` 元组（无 `.name` 属性）；`list_presets()` 返回 `DetectionPreset` 对象（有 `.name`/`.display`）。初版用 `get_preset_choices()` 迭代取 `.name` 导致 `AttributeError: 'tuple' object has no attribute 'name'`。统一改用 `list_presets()` 构建下拉 choices。
3. **批量页自动模式此前漏传 `preset`**：补齐后，批量页自动模式与单图/自动页行为一致。
4. **手动/自动联动双输出**：`mode.change` 的 `outputs` 必须与回调返回值数量一致（掩码文件夹可见性 + 检测模式下拉可见性），已对齐。
