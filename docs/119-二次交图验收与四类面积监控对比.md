## 3. 与「面积监控」红线对比

项目对这四类的**既定度量不是 recall 而是「掩码面积」**
（`real_gate.py:631` 明写「面积监控预设不进有真值表，其 **recall 无意义**」；
`mask_coverage = 掩码像素 / 图面像素`，**不需真值**）。既有红线（`real_gate.py:317-320`）：

| 预设 | 本次均值 | 红线 | 判定 |
|---|---|---|---|
| `ai_text_heavy` | **0.81%** | ≤ 4.25% | ✅ 远低于 |
| `ai_grid` | **2.52%** | ≤ 12.5% | ✅ |
| `ai_faint_tiled` | **2.43%**（单张最高 `tile_03` 7.46%） | ≤ 7.5% | ✅（`tile_03` 已贴近红线） |
| `ai_gradient` | **0.00%**（5 张全零） | ≤ 5% + 静默守卫 `n_with_mask ≤ 0` | ✅ 与守卫一致 |

> ⚠ **口径提醒（诚实）**：这些红线原本是在**不含这四类的 30 张图**上标定的（度量"预设 X 在非 X 图上的过开火"）。
> 本次是在**含 X 的图**上量（更接近"召回覆盖"）。两者**同向但非同一口径**，故本表是**指示性**的，不能直接当"通过门禁"。

## 6. 顺带发现（跨模块技术债，登记）

`cv2.imread` 在 Windows 上**读不了非 ASCII（中文）路径**（本批图名含中文，探针首跑即崩）。
探针一律改用 `cv2.imdecode(np.fromfile(path, uint8), flags)`。若项目内有走 `cv2.imread` 读中文名图片的路径，需同样加固。
