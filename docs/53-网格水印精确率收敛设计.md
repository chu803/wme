# 阶段 53 · 网格水印在纹理/照片底图精确率收敛

> 承接阶段 52 收尾发现的检测器最大质量短板：**网格水印在 textured 底图上召回 99.7% 但精确率仅 11.6%（"框太大"）**。
> 阶段 53 把掩码收敛到真实周期格点，使精确率回到 90%+（隔离口径）/ 合并口径翻倍。

## 1. 问题定义

阶段 52 后的 `detector_diag.py` 实测（合并口径，预设 `ai_grid`）：

| 底图 | 召回 Recall | 精确率 Prec | IoU | 备注 |
|---|---|---|---|---|
| gradient | 99.7% | 30.9% | 30.9% | 半透明通路主导 |
| **textured** | **99.7%** | **11.6%** | **11.6%** | **最差：框太大** |
| photo | 99.7% | 29.9% | 29.9% | 半透明通路主导 |

`textured/grid` 的 `pred_cov`（预测覆盖率）= 10.43%，是 `gt_cov`（1.21%）的 **8.6 倍**——典型"检出但框太大"，
精确率被稀释到 11.6%。修复目标是**在不牺牲召回的前提下把精确率拉高**。

## 2. 根因诊断（数据驱动，非猜测）

用 `scripts/probe_grid.py` 复现 `detect_grid_watermark` 内部各中间掩码覆盖率，定位"框太大"来源：

| 底图 | evidence 单图门限覆盖 | 折叠模板平铺后覆盖 | **交集覆盖** | gt 覆盖 |
|---|---|---|---|---|
| gradient | 1.21% | 5.56% | **1.21%** | 1.21% |
| textured | 3.19% | 3.21% | **1.11%** | 1.21% |
| photo | 3.42% | 2.50% | **1.25%** | 1.21% |

| 底图 | 平铺后(旧) 精确率 | **交集(新) 精确率** | 交集召回 |
|---|---|---|---|
| gradient | 21.8% | **100.0%** | 100.0% |
| textured | 37.9% | **95.5%** | 87.1% |
| photo | 48.7% | **96.4%** | 99.3% |

**根因**：`detect_grid_watermark`（阶段 49 重写）用「折叠模板门限」生成掩码——把残差场按检测到的
周期折叠成单个 tile 模板，取 `|模板| ≥ k·稳健σ` 后平铺回全图。问题在**纹理/照片底图上，纹理噪声
经 N 个 tile 平均后仍残留伪结构**，这些伪结构在模板里显著、被门限判为网格节点、平铺后**铺满全图**。

而真实的网格点在「单图证据门限」（`|残差| ≥ 绝对幅度 ∧ |归一化残差| ≥ k·稳健σ`，即 `_evidence_gate`
的输出）上**必然显著**；纹理假响应在单图证据门限上**不显著**（纹理高频在单图上是分散的、相对不突出）。
因此只需把折叠模板与单图证据门限**取交集**，即可收敛"框太大"。

## 3. 修复方案

两处改动，均为"收敛"而非"新增能力"：

### 3.1 证据交集（核心修复）

`detect_grid_watermark` 中保存单图证据门限，平铺模板掩码后与其相交：

```python
marks = cv2.morphologyEx(marks, cv2.MORPH_OPEN, kopen, iterations=1)
evidence = marks                       # 阶段 53：保留单图证据门限

# ... 周期检测 + 折叠模板 ...
marks = _tile_out(tmpl_mask, h, w)
if config.DETECT_GRID_EVIDENCE_AND:   # 默认 True
    marks = cv2.bitwise_and(marks, evidence)
```

### 3.2 网格掩码膨胀归零

函数末尾 `_components_mask(..., dilate=1)` 把稀疏网格节点膨胀成假阳性——实测把隔离精确率
从 ~95% 拉低到 ~65%。网格是周期性点阵，节点经交集后已精确落在格点上，无需膨胀包裹：

```python
mask = _components_mask(marks, min_area, max_area, h, w,
                        dilate=config.DETECT_GRID_MASK_DILATE)  # 默认 0
```

### 3.3 新增配置项（`config.py`）

| 配置 | 类型 | 默认 | 作用 |
|---|---|---|---|
| `DETECT_GRID_EVIDENCE_AND` | bool | `True` | 折叠模板与单图证据门限相交（关=false 回退阶段 52 行为） |
| `DETECT_GRID_MASK_DILATE` | int | `0` | 网格掩码膨胀半径（0~3；半透明/边缘文字用 1，网格用 0） |

## 4. 结果（阶段 53 实测）

**隔离口径**（直接调用 `detect_grid_watermark`，`tests/test_grid_precision.py`）：

| 底图 | 精确率 | 召回 |
|---|---|---|
| gradient | ≥95% | ≥95% |
| textured | ≥80%（实测 ~95%） | ≥80%（实测 ~87%） |
| photo | ≥90%（实测 ~96%） | ≥90%（实测 ~99%） |

**合并口径**（`detector_diag.py`，预设 `ai_grid`）：

| 底图 | 精确率(修复前→后) | 召回(修复前→后) | IoU(修复前→后) |
|---|---|---|---|
| gradient | 30.9% → 30.9% | 99.7% → 99.7% | 30.9% → 30.9% |
| **textured** | **11.6% → 23.7%**（×2.0） | 99.7% → 88.8% | **11.6% → 23.0%**（×2.0） |
| photo | 29.9% → 30.0% | 99.7% → 99.2% | 29.9% → 29.9% |

> gradient/photo 合并数字"未改善"是因为这两档的合并掩码由**半透明通路**主导
> （半透明网格水印本身覆盖率大、精确率由透明度决定），grid 策略的 95%+ 被稀释。
> 这暴露出**下一个优化点：半透明通路在网格/半透明水印上的精确率**（见 TODO P3）。
