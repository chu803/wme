# 阶段 27 设计文档：媒体页逐页/逐帧智能推荐

## 背景与目标

阶段 25 把「逐图自动预设推荐」接入了自动页，阶段 26 接入了批量页。至此
「自动 / 批量」两入口都已具备逐图独立挑选检测预设的能力。但**媒体页（PDF /
视频）仍整份 / 整段共用一个下拉预设**——一份多页 PDF 里混排了平铺水印页与
文字水印页时，单一预设无法同时适配；一段视频里前段固定台标、后段滚动字幕时
同理。

本阶段目标：把阶段 25 的推荐内核延伸到**媒体页**，让：

- **PDF**：每一页独立分析并选预设（`process_image` 内部已含 `recommend_preset`）；
- **视频**：每一个「检测帧」独立选预设（复用掩码的固定水印帧除外）。

从而补全「自动 / 批量 / 媒体」三入口的智能推荐闭环。

## 设计原则（复用阶段 25/26 内核）

1. **零重复实现**：推荐逻辑只在 `core/preset_recommender.recommend_preset`
   一处实现；媒体服务通过 `auto_pipeline.process_image(..., auto_preset=True,
   preset=None)` 间接触发，不在服务层重写特征分析。
2. **开关可控、向后兼容**：UI 新增一个「🤖 智能推荐每页/每帧预设」勾选框
   （默认开）；关闭时整份 / 整段共用下拉预设，行为与旧版一致。
3. **复用场景强制关闭**：视频勾选「复用水印位置」（固定水印）时，水印位置
   固定，整段共用一个预设更合理，UI 自动禁用推荐开关、服务层 `detect_auto`
   强制 `False`。
4. **结果可复核**：逐页 / 逐检测帧推荐的预设会回传到结果对象，页面日志展示
   每页/整段分布，便于确认推荐是否靠谱。

## 改动清单

### 1. `core/detection_presets.py`（共享展示映射）
- 新增 `preset_display(name)`：把内部预设名映射成本地化标签（优先 i18n
  `detect.preset.<name>.title`，缺失回退预设内置 `display`）。供阶段 26/27
  的日志与分布汇总复用，避免各 tab 重复维护标签表。

### 2. `services/pdf_service.py`
- `PageResult` 新增字段 `recommended_preset: Optional[str]`（默认 `None`，
  向后兼容）。
- `process_pdf` 新增参数 `auto_preset: bool = True`。
- 逐页调用 `process_image` 透传 `preset=preset, auto_preset=auto_preset`；
  从返回字典回填 `pr.recommended_preset`。

### 3. `services/video_service.py`
- `VideoResult` 新增字段 `preset_counts: Dict[str, int]`（默认 `{}`）。
- `process_video` 新增参数 `auto_preset: bool = True`。
- 计算 `detect_auto = bool(auto_preset) and not reuse`：复用掩码场景下强制关闭。
- 检测帧调用 `process_image` 传 `preset=(None if detect_auto else preset),
  auto_preset=detect_auto`；**当且仅当 `detect_auto` 为真**时把
  `core.get("recommended_preset")` 累加到 `preset_counts`（避免固定预设 /
  `None` 误记入分布——修复了一个实测会泄漏的设计缺陷）。

### 4. `ui/tab_media.py`
- 新增纯函数 `_media_preset_args(auto_preset, preset)`：把开关换算成
  `{"preset": None, "auto_preset": True}` 或
  `{"preset": <共享预设>, "auto_preset": False}`。
- `run_pdf` / `run_video` 新增 `auto_preset` 参数，调用服务时展开
  `**_media_preset_args(...)`。
- `run_pdf`：逐页明细追加「· 推荐预设：<标签>」（开启推荐且有值时）；末尾汇总
  `🤖 智能推荐预设分布：<标签>×N，…`。
- `run_video`：末尾汇总 `🤖 智能推荐预设分布：…`（`preset_counts` 非空时）。
- `build_media_tab`：PDF / 视频各新增「🤖 智能推荐每页/每帧预设」勾选框
  （默认开）：
  - 开启时把 `detect_preset` 下拉置灰禁用；
  - 视频另：勾选 `reuse_mask` 时把推荐开关禁用并强制取消勾选（`interactive=False`
    + `value=False`），与服务的 `detect_auto` 取值一致。

### 5. `utils/i18n.py`
- 新增 `media.pdf.{auto_preset_label,auto_preset_info,page_preset,preset_dist}`
  与 `media.video.{auto_preset_label,auto_preset_info,preset_dist}`（中英文案
  + 自检断言）。

### 6. `tests/test_media_recommend.py`（新增，6 例）
- `_media_preset_args` 路由（开 / 关 / 关且无 preset 回退）。
- `process_pdf` 透传：开启推荐 → 每页 `preset=None + auto_preset=True`、
  `PageResult.recommended_preset` 回填；关闭 → 共享 preset、推荐为 `None`
  （真实临时 PDF + monkeypatch `process_image`）。
- `process_video` 检测帧路由 + `preset_counts` 聚合：开启推荐逐帧检测 →
  计数到 `ai_tiled`；复用掩码 → `detect_auto=False`、`preset_counts=={}`
  （真实临时 mp4 + monkeypatch `process_image`）。

## 验证结果

- `python utils/i18n.py` → 自检通过
- `pytest tests/test_media_recommend.py` → 6 passed
- `build_app()` → 返回 `Blocks`（全部标签页构建成功）
- 全量 `pytest` → **177 passed / 1 skipped**（torch），较阶段 26 持平 +6，无回归

## 已知缺陷与修复

- **视频分布计数泄漏**：最初在检测帧无条件读取 `recommended_preset` 并计数，
  导致复用掩码（固定预设、`auto_preset` 实为 `False`）场景下 `process_image`
  回 `None` 仍被错误计入。已加 `if detect_auto:` 门控，测试
  `test_video_service_detect_frame_routing` 场景 b 复现并锁定该修复。

## 与其他入口的一致性

| 入口 | 智能推荐开关 | 推荐粒度 | 复用/固定水印例外 |
|------|-------------|---------|------------------|
| 自动页（阶段 25） | 按钮「🔍 智能推荐预设」 | 单图 | 无 |
| 批量页（阶段 26） | 勾选框「🤖 智能推荐每张图预设」 | 每张图 | 无 |
| 媒体页（阶段 27） | 勾选框「🤖 智能推荐每页/每帧预设」 | 每页 / 每检测帧 | 视频复用水印时关闭 |
