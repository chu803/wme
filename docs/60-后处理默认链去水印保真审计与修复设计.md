# 阶段 60 · 后处理默认链的「去水印保真」审计与修复

> 一句话：质量门禁测的是裸 inpaint，而 UI 实际交付的是**后处理增强链**（色彩还原 + 边缘
> 融合 + 锐化）的输出——这一段从未用合成 ground truth 审过。一测即发现三个把"刚擦掉的
> 水印重新涂回去 / 把修复区拖坏"的真实缺陷：旧边缘融合把原图水印像素混回掩码边界
> （corner_logo 掩码区 PSNR 38.4 → 12.3 dB）、色彩还原用全图外部统计 + std 重缩放把渐变
> 底上的修复区拖向错误明暗（−18 dB）、锐化放大 inpaint 平滑面残留（grid/edge −6~7 dB）。
> 逐项修复并把色彩还原默认关闭后，**默认链掩码区 PSNR 零退化**（最差 Δ=0.0 dB），
> 同时保留内容区锐化等观感增强。

---

## 1. 背景：测的是"原材料"，交付的是"成品"

阶段 57 的质量门禁与 benchmark 全部评估**裸 inpaint 输出**（`make_demo_assets` /
`run_benchmark` 都是 raw inpaint）。但用户实际拿到的是 `postprocess()` 增强后的成品
（`POSTPROCESS_ENABLED=True` 默认，步骤：色彩还原 → 边缘融合 → … → 锐化）。
默认增强链从未被 ground truth 审计过——它的自检/单测只断言"形状保持、向背景收敛"这类
宽松性质。阶段 60 用合成 ground truth 第一次量化它。

## 2. 审计结果（裸 inpaint vs 默认链，掩码区 PSNR）

初版默认链（color_match 全外部+std、edge_blend 混回原图、sharpen 全图）：

| 底图·用例 | 掩码区 PSNR（裸→增强） | 性质 |
|---|---|---|
| gradient · corner_logo | 38.4 → **11.5**（−26.9 dB） | 灾难性劣化 |
| gradient · faint_tiled | 43.9 → 32.9（−11.0 dB） | 明显劣化 |
| textured/photo 各用例 | ±(0~3) dB | 侥幸中性 |

## 3. 三个根因与修复

### 3.1 边缘融合把"原图水印像素"混回掩码边界（corner_logo 主凶）

旧 `_edge_blend`：`out = result·soft + original·(1−soft)`，soft 的环带跨入掩码内
边界——掩码内侧的原图是**水印像素**，混回等于把刚擦掉的水印边缘重新涂上去
（单独该步即 38.4 → 12.3 dB）。

**修复**：`_edge_blend` 只用 **result 自身的盒式模糊**在「掩码内、距边界 ≤ band」的窄带
平滑接缝，绝不引入原图像素；薄/小掩码（无内部核：文字行、网格点、细 LOGO）直接跳过
（强抹整块掩码会把修好的内容抹糊，实测 edge_text/grid −6~7 dB 即此）。

### 3.2 色彩还原的统计口径错误（渐变底 −18 dB 主凶）

旧 `_color_match`：上下文 = **全部 mask==0 区域** + 按外部/内部 std 之比**重缩放内部对比度**。
在渐变底上，"全图外部均值"与 LOGO 处局部背景差异巨大 → 修复区被拖向错误明暗；std 重缩放
还会放大/扭曲结构。即使改成紧邻环带均值对齐，对**稀疏/条带掩码**（网格点阵、文字行）仍
系统性错位（gradient grid −7.9、edge_text −7.0 dB）——OpenCV/LaMa 修复本身是局部估计，
**不该被全局性颜色对齐二次移动**。

**修复**（双管齐下）：
- 算法语义修正：上下文只取**紧邻掩码外 4~16px 环带**、**只做均值对齐**（去掉 std 重缩放）——在
  "局部色偏"场景仍可纠正（corner_logo 局部环带均值对齐实测 38.4 → 41.7 dB）；
- **默认关闭** `POSTPROCESS_COLOR_MATCH=False`：对"去水印"默认不该动修复区颜色；
  需要时仍可显式开启（此时语义已修正）。

### 3.3 锐化放大 inpaint 平滑面的残留（grid/edge 在渐变底 −6~7 dB）

unsharp 全程施加会把修复区平滑面上的残留/接缝放大。修复：**锐化只作用于掩码外**
（掩码内保留 inpaint 原始结果，保真度最高；内容区照常锐化找回细节）。

## 4. 修复后默认链审计（全 12 用例）

| 区域 | 最差 Δ | 明细 |
|---|---|---|
| 掩码区 PSNR | **0.0 dB（零退化）** | gradient faint +0.2 / corner 0.0 / edge +0.3 / grid +0.9；textured/photo 全部 ≥0 |
| 上下文 PSNR | −0.4 ~ −4.6 dB | 来自内容区锐化（观感取舍：找回细节 vs MSE；数值在噪点合成图上偏悲观） |

色彩还原显式开启（修正后语义）仅在"局部色偏"场景有正收益，故保留为 opt-in。

## 5. 测试（tests/test_postprocess_fidelity.py，6 例）

1. edge_blend 掩码内部核与 result 逐像素一致（绝不混回原图水印）；
2. edge_blend 薄掩码跳过（输出与输入一致）；
3. postprocess 默认链不改动掩码内像素（薄掩码场景）；
4. 色彩还原默认关闭（config 断言）；
5. color_match 只向紧邻环带均值对齐（构造"亮区块 + 渐变底"，断言向环带而非全图外部收敛）；
6. 端到端红线（slow）：gradient/textured/photo × corner_logo/grid/edge_text 默认链掩码区
   PSNR 不得低于裸 inpaint（Δ ≥ −0.01 dB）。

全部通过；既有 `tests/test_postprocess.py` 17 例零回归。
