# 阶段 256 · API 异步作业端点·真实长素材端到端验收

> 收口阶段 255 的「真实长素材端到端」缺口：255 的守卫刻意用**确定性轻量 runner**（`test_ping`）
> 验证 HTTP 全链路，**不跑真实推理**。本阶段用合成带水印的 PDF（2 页）与视频（12 帧），
> 经 `POST /api/jobs` 真正派发到 worker 线程跑 `process_pdf` / `process_video`（与 GUI/CLI/库同一核心），
> 再轮询到终态、经 `GET .../file` 下载结果并校验有效性。

---

## 一、结论

- **端点管线 + 真实处理派发** 经端到端验收通过：
  - `POST /api/jobs {kind:"pdf"}` → worker 真跑 `process_pdf` → `GET /api/jobs/{id}` 终态 success → `GET /api/jobs/{id}/file` 下载合法 PDF（页数 == 输入页数）。
  - `POST /api/jobs {kind:"video"}` → worker 真跑 `process_video` → 终态 success → 下载合法 mp4（帧数 == 输入帧数）。
- 水印确实被处理（复检不恶化）：输出首页/首帧复检掩码像素 ≤ 输入（检测器命中则显著下降；漏检则 0≤0 仍过）。
- 探针确认：真实 `process_pdf`/`process_video` 在**进程内**不触发沙箱删除护栏（12 帧视频实测安全，≤50 文件删除）。
- 守卫 `tests/test_api_async_jobs_e2e256.py` **2 例全绿**；组合 `251 + 255 + 256` = **28 例全绿，零回归**。

## 四、守卫设计（tests/test_api_async_jobs_e2e256.py）

钉死五条契约：
1. **派发真实处理**：提交后 worker 真跑 `process_pdf`/`process_video`（非 dummy），结果页数/帧数 > 0、success。
2. **结果文件有效**：下载 `.../file` 是合法 PDF（页数 == 输入）/ 合法 mp4（帧数 == 输入）。
3. **水印处理不恶化**（宽松）：输出首页/首帧复检掩码 ≤ 输入复检掩码。
4. **闸门之外**：长任务在 worker 线程跑，不占推理闸门槽位（沿用 255 豁免契约）。
5. **不触发删除护栏**：真实处理 ≤50 文件删除（探针已证）。

实现要点（已踩坑并修正）：
- `fitz.open` 在 Windows 上**必须显式 `close()`/`with`**，否则 `os.remove` 报 `PermissionError [WinError 32]`（已记入 LESSONS #274）。
- 栅格化复检在 `os.remove` **之前**完成，文件句柄全部释放后再删。
- `remove_watermark_pdf`/`remove_watermark_video` **无** `allow_auto_erase` 参数（233 确认门只覆盖单图 `remove_watermark_bytes`），故提交 PDF/视频作业**不传**该键。

## 五、自反证伪（self-falsification）

- **合成素材 ≠ 用户真实 AI 图**：本验收验证「端点管线 + 真实处理派发」这一层；水印移除的**质量**由 29 图基准门禁（`real_gate` / `e2e_real_probe`）覆盖，不在本守卫范围。
- **视频输出无音轨**：`process_video` 固有约束（api 文档已声明，需 ffmpeg 合并原声），验收不校验音轨。
- **仅复检首页/首帧**：未逐页/逐帧比对；若水印位置逐帧漂移且 `reuse_mask=True` 复用失败，可能漏检——但本验收的宽松判定（≤）不会误报，仅是对「质量」不做强断言。
- **依赖 PyMuPDF/cv2**：守卫用 `pytest.importorskip` 优雅跳过（CI 若无 fitz 不红），属环境可选。

## 六、对「图片/PDF/视频全源」承诺的最终状态

- 图片：`/api/remove` `/api/detect` `/api/inpaint` `/api/batch`（同步，即时）。
- PDF/视频：`POST /api/jobs {kind:pdf|video}`（异步，长任务在闸门之外）+ 轮询 + 文件下载。
- 模型下载：`POST /api/jobs {kind:model_download}`（异步）。
- 仅剩 `POST /api/models/active`（写操作需确认+鉴权）按既有决策仍不开放。

⇒ 产品化承诺「全本地离线 + 图片/PDF/视频全源 + 免手涂 8 预设」在 API 侧**已无遗留缺口**。
