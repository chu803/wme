# 阶段 65 · 掩码膨胀/羽化的真值标定：默认值 8 → 2

> 一句话：`MASK_DILATE_DEFAULT`（掩码膨胀）是"擦不擦得干净"的直接杠杆，却从未被真值标定过。
> 扫描后发现**膨胀单调有害**——残留不随膨胀下降，而过度重绘线性上升（grid 过度像素
> 2484→38135，15 倍）；唯一边际收益在细字。根因是**检测器掩码本身已带 padding**，再叠
> 大膨胀属重复扩张。默认从 8 收敛为 **2**，质量门禁平均 ΔPSNR 由 **+9.76 → +12.12 dB
> （+2.36 dB，+24%）**，检测指标分毫未变。

---

## 1. 动机：核心链路最后一个未标定的旋钮

阶段 49~64 把检测器、推荐器、修复引擎、后处理、视频时序都过了一遍真值，但**掩码几何**
（膨胀 dilate / 羽化 feather）从未被标定——它直接决定"擦除面积"：太小 → 水印边缘残留
半透明轮廓；太大 → 白改好像素（过度重绘，画面被无谓重绘）。默认值是阶段 18 凭经验定的
`dilate=8, feather=5`。

## 2. 方法：两个代价同时量

对 benchmark 用例（textured/photo × corner_logo/edge_text/grid）扫描膨胀与羽化：

| 指标 | 定义 | 含义 |
|---|---|---|
| **残留** residual | `\|out − clean\|` 在**真值水印区**的均值 | 擦不干净的代价 |
| **过度** overpaint | `\|out − clean\|` 在**掩码扩张带**的均值 | 白改好像素的代价 |
| 过度像素 changed_px | 该带内被改动 >2 灰阶的像素数 | 破坏面积 |

（实现坑：`gt_mask()` 返回 0/255 而非布尔数组，`diff[gt]` 会退化成**花式索引**按 0/255 取
元素，指标全错；必须先 `> 0` 转布尔。第一版扫描就是被这个假象误导。）

## 3. 发现：膨胀单调有害，细字是唯一例外

残留 / 过度均值 / 过度像素（feather 固定 5）：

| 用例 | dilate 0 | dilate 2 | dilate 8 | dilate 16 | dilate 24 |
|---|---|---|---|---|---|
| textured/corner_logo | 13.44 / 0.86 / 865 | 13.81 / 2.16 / 1798 | 14.42 / 7.87 / 4711 | 18.31 / 14.09 / 6203 | 18.32 / 18.13 / 6424 |
| textured/grid | **8.75 / 0.18 / 2484** | 9.36 / 0.56 / 8294 | 12.15 / 2.77 / **38135** | 13.64 / 7.73 / 89248 | 14.28 / 11.66 / 110888 |
| photo/grid | **5.72 / 0.11 / 1667** | 6.25 / 0.38 / 6731 | 9.29 / 2.25 / **35960** | 11.02 / 6.74 / 90927 | 11.68 / 10.34 / 115273 |
| textured/edge_text | 13.02 / 1.53 / 2231 | **10.77** / 2.81 / 3835 | 12.80 / 7.98 / 8698 | 11.87 / 11.22 / 11156 | 14.11 / 14.49 / 11498 |
| photo/edge_text | 12.63 / 1.48 / 2088 | 8.81 / 2.34 / 3501 | 10.32 / 7.07 / 8518 | 10.64 / 10.32 / 11185 | 11.41 / 12.56 / 11515 |

**读数**：
1. 角落 LOGO 与网格：**dilate=0 就是最优**（残留最低、破坏最小）；加到 8 残留反而更差、
   破坏涨 5~21 倍。
2. **细字（edge_text）例外**：dilate 2~4 残留最低（8.6~10.8 vs 0 的 12.6~13.0）——细笔画
   需要轻微外扩吞掉抗锯齿边缘。
3. **羽化几乎无影响**：feather 0→15 时残留变化 <1%、过度像素变化 <6%。维持 5。

跨用例**平均残留比**（以 dilate=0 为 1.000）：

| dilate | 0 | **2** | 4 | 8 | 16 |
|---|---|---|---|---|---|
| 平均残留比 | 1.000 | **0.977（最优）** | 1.044 | 1.192 | 1.307 |

## 4. 根因：与检测器的 padding 重复叠加

检测器各策略生成的掩码**本身已带 padding**：`_components_to_regions(..., pad=4)` 之外，
还有形态学膨胀（tiled/grid 通路各有 dilate 参数）。再叠加 `MASK_DILATE_DEFAULT=8`，等于
把"已经外扩过的区域再外扩 8px"——只增加重绘面积，不改善残留。

## 5. 决策：默认 dilate 8 → 2，feather 维持 5

**两个口径会给出不同答案，必须显式取舍**（这是本阶段最值得记录的一点）：

| 口径 | dilate=0 | dilate=2 | dilate=4 | dilate=8 |
|---|---|---|---|---|
| **掩码区残留比**（越小越擦得干净） | 1.000 | **0.977（最优）** | 1.044 | 1.192 |
| **全图平均 ΔPSNR**（12 用例，越大越好） | **+12.67 dB** | +12.12 dB | +11.59 dB | +9.77 dB |
| 全图最差用例 ΔPSNR | **−1.47 dB** | −3.05 dB | −4.51 dB | −6.08 dB |
| 改善用例数 | 10/12 | 10/12 | 9/12 | 9/12 |

- **全图 ΔPSNR 偏好 0**：它按**面积**加权，非水印区（占 97%+）只要不动就得分，本质偏向
  "什么都不做"；因此它低估了稀疏水印（细字/网格）的残留观感。
- **掩码区残留偏好 2**：用户真正感知的"擦干净了没"主要体现在水印区（尤其细字边缘的半透明
  晕圈）。
- **最终取 2**：擦除优先——细字残留相对零膨胀改善 15%~31%（gradient/edge_text 的 ΔPSNR
  +18.22 → +21.18 dB）；代价是全图 ΔPSNR 仅让出 0.55 dB。用 4 及以上则全图与最差用例同时
  恶化，得不偿失。

默认值同时是 UI 滑杆初值（`ui/components.py`、`tab_auto/tab_single`）与 CLI 默认
（`cli.py --dilate`），改动一处全局生效；用户仍可按素材调整（建议 0~4）。

## 6. 影响：门禁 ΔPSNR +2.36 dB，检测指标不变

| 项目 | 前 | 后 |
|---|---|---|
| 平均 ΔPSNR | +9.76 dB | **+12.12 dB（+2.36 dB，+24%）** |
| 干净图误报 / 精确率 / 召回 / IoU | 0.83% / 47.7% / 82.3% / 46.0% | **完全相同**（掩码几何不改检测） |
| 门禁判定 | — | ✅ 通过（改善方向不报警） |

## 8. 边界（诚实声明）

- 标定基于 640² 合成图 + OpenCV 引擎；**LaMa 引擎、真实照片、手绘掩码**下的最优膨胀可能
  不同（LaMa 对掩码外扩更敏感），故该值是可配置的默认起点而非"普适最优"；
- "过度重绘"的度量带取真值外 12px，超出该带的破坏未计入（对 24px 膨胀略偏乐观）；
- 羽化的影响在合成图上微弱不等于对真实照片无意义（接缝过渡是感知问题），故保留默认而非置 0。
