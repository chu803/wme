# 阶段 346 · 门禁那 94.9% 是重编码噪声：给「改动占比」加容差，并让 `outside_diff` 名副其实

> 日期 2026-10-26 · 性质：**指标可信度修复**（欠账兑现：上一轮我说「看不懂的数字不当作通过」）

## 一、那条数字是什么

完整门禁里 `media_gate` 打出「视频 非水印区改动 **94.9%** | 全图改动 **97.5%**」。
94.9% 的画面被改了？不可能——修复只动掩码区。用 `media_gate` 自己的构件（`build_video` /
`read_video` / `diff_stats` / `load_cases`）复现同一场景，把非水印区的 |差| 直方图打出来：

| 非水印区像素差 | 占比 |
|---|---|
| 1~3 级 | **48.8%** |
| 4~8 级 | 45.6% |
| 9~16 级 | 2.7% |
| ≥17 级 | **0.3%** |
| 均值差 | **3.83 / 255**（肉眼不可见） |

⇒ 视频/PDF **必须重新编码**，压缩让几乎每个像素动 ±1~3；而门禁判「改动占比」用的是
「差 > 0 即算改动」⇒ 这个数**必然接近 100%**。那是**指标失真**，不是损伤。

## 二、顺带发现：那个名字本来也不准

`diff_stats` 里的 `outside` 是「整幅图、把 bbox 区置零」，于是 `outside_diff` 其实是
**全图均值被稀释后的值**，而不是「非水印区的均值」——名字与含义不符（稀释比例 = bbox 面积占比）。
现在改成用**掩码取真正的非水印区像素**统计：同名同义。

## 三、改法（诊断指标，红线不动）

* 新增 `DIFF_TOLERANCE = 8`：`outside_changed` / `whole_changed` 按 `> 8` 判定；
* `outside_diff` 改为非水印区像素的均值；
* 模块 docstring 的 D1/D2 说明补上容差与实测依据。

同一场景修前 vs 修后：

| 指标 | 修前 | 修后 |
|---|---|---|
| 视频 非水印区改动 | 94.9% | **3.0%** |
| 视频 全图改动 | 97.5% | **3.7%** |
| PDF 第 2 页 非水印区改动 | 61.8% | **1.5%** |

红线（R1 页数保持 / R2 水印区必须变化 / R3 可解码 / R4 帧数不塌）**一条没动** ——
本条只修「诊断数字的可信度」，因为把失真指标当真去改产品会走偏（同 #308 的教训：
先把上界量出来，再决定动什么）。

## 四、守卫（关键是「容差不许把真损伤藏起来」）

`tests/test_media_gate_metrics346.py`（4 例）：

1. 相同帧 ⇒ 改动 0；
2. **整体 ±2（压缩噪声量级）⇒ 改动占比 0**（修前是 100%）；
3. **bbox 内 ±30 ⇒ 仍被算成改动、bbox_diff > 20** ⇒ 容差没有掩盖真损伤；
4. 容差常量在 0~32 内、且 `diff_stats` 里**真的用了它**、没有 `> 0` 判定残留。

`media_gate` 修后实跑 **rc=0**，输出如上表。

## 五、写测试时踩的两个坑（都记在测试注释里）

1. `_frame(2)` 一开始返回 int16 ⇒ `cv2.absdiff` 直接拒（OpenCV 要求显式输出类型）⇒ 改回 uint8 并 clip；
2. 画布只有 64px 时，`BBOX_DILATE=48` 把整幅图都罩进 bbox 区 ⇒ **「非水印区」只剩 0 个像素**，
   `outside_diff` 恒为 0、看起来像「噪声没被算出来」⇒ 画布放大到 256px、bbox 挪到中心。
   ⇒ **测「区域类指标」时，先确认那个区域真的有像素**（否则断言会以另一种方式骗人）。

**第四次「改口径 ⇒ 旧断言变红」**（前三次：336 取消夹具、337 质量 detail、343 导出助手）：
完整入口抓到 `tests/test_media_gate.py::test_diff_stats_exposes_outside_change_as_diagnostic`
——它用 **+1** 的位移断言「改动占比 > 0.5」，正是旧 `>0` 判据的形状。
改法把位移提到 **+30**（真实幅度），**原意保留**：这条用例守的是「真实幅度的大面积改动必须被看见」，
而不是「±1 也算改动」。⇒ 这条用例本身就是**口径的活文档**，改口径时它必须一起改，
否则「指标失真」会被守成「不可改」（同 #318/#321：写死旧行为的断言要同步到新契约并写明理由）。
