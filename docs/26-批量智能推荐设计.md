# 阶段 26 设计文档 · 批量智能推荐（Batch Smart Recommendation）

- **版本**：1.0.0
- **日期**：2026-08-05
- **依赖阶段**：阶段 25（检测自动预设推荐，核心 `core/preset_recommender.py`）
- **目标**：把阶段 25 的「单图自动预设推荐」能力扩展到**批量页**，让批次中的**每张图独立**挑选最合适的检测预设，而不是整批共用一个下拉所选的预设。

---

## 1. 背景与动机

阶段 25 在「智能自动检测」标签页提供了「🔍 智能推荐预设」按钮：用户点击后，对**当前这一张**图做一次轻量特征分析，自动把 `detect_preset` 下拉填成最契合的预设（如 `ai_tiled` / `ai_text_heavy` / `ai_gradient` …），省去手动试错。

但批量页（`ui/tab_batch.py`）一直存在一个体验断层：

- 批量页的 `detect_preset` 下拉是**整批共享**的——无论 100 张图里有多少种不同的水印样式，它们全部被强制套用同一个预设。
- 这违背了「智能推荐」的初衷：一批混合素材（有的平铺、有的带签名栏、有的是纯文字），用单一预设必然顾此失彼，检测命中率下降。

阶段 26 在**不改动核心推荐算法**的前提下，把「逐图独立推荐」接入批量处理管线：

- 每个任务线程在处理前，对自己这张图单独跑一次 `recommend_preset`；
- 各自拿到 `recommended_preset`，传入 `detect_watermark_mask`；
- 处理结果里记录 `recommended_preset` / `recommendation`，并在日志与汇总中展示分布。

---

## 2. 设计原则

1. **复用核心，不做重复算法**：直接调用阶段 25 的 `core.preset_recommender.recommend_preset`，批量页只负责「逐任务调用 + 结果透传 + 展示」。
2. **零 gradio / torch 依赖**：推荐逻辑在 `ui/tab_batch.py` 的纯函数 `_resolve_batch_preset` 里完成，不涉及任何 UI 框架或重模型。
3. **开关可控、向后兼容**：
   - 新增「智能推荐每张图预设」勾选框（默认开启）；
   - 关闭时，整批回到「共用 `detect_preset` 下拉」的旧行为，`recommendation`/`recommended_preset` 为 `None`；
   - 推荐失败时安全回退到共享预设，不影响批次。
4. **CLI / API 已天然支持**：阶段 25 已让 `auto_pipeline.process_file` 支持 `auto_preset=True`（逐文件推荐），`cli.py` 与 `api.py` 的批量入口均已透传 `auto_preset`。因此阶段 26 的**唯一代码缺口是批量 UI 页**。

#### `_resolve_batch_preset` 返回值语义

```python
(preset_to_use, recommendation, recommended_preset)
```

- `preset_to_use`：实际传给 `detect_watermark_mask` 的预设名。
- `recommendation`：`Recommendation.to_dict()`（仅 `auto_preset` 成功时非空），供未来展示推荐理由。
- `recommended_preset`：推荐出的预设名（仅成功时非空；推荐回默认 `general` 时也非空，值为 `"general"`）。

决策细节（与阶段 25 一致）：

- `auto_preset=False` → 直接返回 `(fallback, None, None)`。
- `auto_preset=True` → 调 `recommend_preset`：
  - 推荐到**具体**预设（非 `general`）→ 覆盖共享预设；
  - 推荐回 `general`（无强信号）→ 回退到下拉所选（`fallback`，默认 `general`）；
  - 推荐器抛异常 → 记录 warning，回退 `(fallback, None, None)`。

## 4. 用户可见行为

1. 批量页「检测模式」下拉下方新增 **「🤖 智能推荐每张图预设」** 勾选框（默认勾选）。

4. 处理日志中，每张成功图后追加一行：`　　🤖 智能推荐预设：<展示标签>`。
5. 批次结束时汇总追加一行：`🤖 智能推荐预设分布：AI 平铺水印×2，AI 文字密集×1，通用检测×1`。

## 5. 已知边界 / 坑

- **推荐回 `general` 也计入分布**：常规图（无强信号）的 `recommended_preset` 为 `"general"`，因此分布里会出现「通用检测×N」。这是有意为之——如实反映「这些图走了默认综合策略」。
- **`detect_preset` 初始 `interactive=False`**：因为默认勾选智能推荐。若用代码直接调用 `run_batch` 而忘记传 `auto_preset=False`，下拉状态不影响逻辑（逻辑只看 `auto_preset` 参数）。
- **与 `mode.change` 互不冲突**：`auto_preset_toggle.change` 只改 `interactive`，`mode.change` 只改 `visible`，二者状态独立，手动模式下下拉隐藏、自动模式且关推荐时下拉可见且可用。
- **性能**：每张图多一次 `recommend_preset`（轻量，纯 numpy+cv2，无 OCR/无 torch），相对「检测+修复」本身开销可忽略；且推荐失败不影响主流程。
