# 阶段 20 —— AI 水印专项检测（检测预设 + 平铺增强 + 底部搜索）

> 文档日期：2026-08-04
> 定位：规划外新增阶段（原规划 19 阶段已全部完成，19/19）。用户明确本工具为「**去 AI 水印**」专用工具，本阶段针对 AI 生成图特有的水印样式做专项检测增强。

---

## 1. 背景与目标

原智能检测（`core/detector.detect_watermark_mask`）已覆盖「半透明 / 角落 LOGO / 边缘小字」三类通用策略，但对 **AI 生成图最常见的几类水印样式** 召回率不足：

1. **半透明平铺 logo**：单个 tile 单元极小、整体透明度低，常规阈值易漏检。
2. **底部居中署名栏**：AI 平台（如各类生图平台）常把署名/提示文字放在图片底部中央或边角，落在常规角落搜索区之外。
3. **固定角落 AI 标识**：图标 + 文字组合的角落标记。

目标：把上述样式固化为**一键可切的检测预设（preset）**，并新增**平铺增强算法**与**底部搜索区**，覆盖四入口（单图 / 批量 / PDF / 视频 / CLI / API / UI）一键适配，提升去 AI 水印的检测成功率。

**约束（项目铁律）**：
- 分层 `ui → services → core → utils → config`，严禁反向依赖。
- `core` / `services` / `utils` 零 gradio 依赖。
- 向后兼容：不传预设时，行为与旧版完全一致（预设仅覆盖其显式设置的字段）。

## 3. 核心设计

### 3.1 检测预设体系（`core/detection_presets.py`，新建，纯算法层）

`DetectionPreset` 数据类打包一组检测参数，便于「一键切模式」而非逐项调滑块：

| 字段 | 含义 | None 语义 |
|------|------|-----------|
| `name` | 唯一标识（CLI/API 引用） | — |
| `display` | 界面向用户展示名（i18n 兜底） | — |
| `description` | 用途简述 | — |
| `sensitivity` | 半透明检测敏感度 0~1 | 沿用 config 默认 |
| `enable_translucent/corner/edge` | 三类策略开关 | 沿用默认 |
| `enhance_tiled` | 平铺半透明增强 | 沿用默认 |
| `search_bottom` | 底部居中搜索区 | 沿用默认 |
| `use_ocr` | 是否启用 OCR 增强 | 沿用默认 |

`resolve(base_sensitivity)` 只输出**非 None 字段**，未设置字段不出现，由 `detect_watermark_mask` 用自身默认值补齐 → **向后兼容**。

内置预设（`_BUILTIN_PRESETS`，惰性加载）：

| 预设 | 适用 | 关键覆盖 |
|------|------|----------|
| `general` | 通用（默认） | 全 None，仅透传 sensitivity |
| `ai_tiled` | AI 平铺半透明水印 | `enhance_tiled=True`、`sensitivity=0.62`、corner/edge 全开 |
| `ai_signature` | AI 署名栏 | `search_bottom=True`、`use_ocr=True`、translucent 开 |
| `ai_corner` | AI 角落标识 | `enable_edge=False`、`sensitivity=0.55` |

对外 API：`list_presets` / `get_preset` / `get_preset_choices`（返回 `(display, name)`）/ `get_preset_names`（CLI choices）/ `resolve_preset(name, base_sensitivity)`（未知名安全回退到 base_sensitivity）/ `register_preset`（动态扩展，与 `core.plugins` 风格一致）。

### 3.2 平铺半透明增强（`core/detector.detect_tiled_translucent`，第 4.5 节新增）

与 `detect_translucent` 同接口，但参数更激进，专治低透明平铺水印：
- 分位阈值提到 `0.95`（保留更多候选像素）；
- 单 tile `min_area` 取基础的 `1/4`（小 tile 也能保留）；
- 输出掩码做椭圆核闭运算（2 次迭代）把相邻 tile 连成片，避免修复后零散残留点。

在 `detect_watermark_mask` 中，当 `enhance_tiled=True` 时与基础 `detect_translucent` 结果取**并集**。

### 3.3 底部居中搜索区（`core/detector._corner_patches`，`search_bottom` 参数）

`_corner_patches(h, w, ratio, search_bottom=False)` 原返回四角 + 中心 5 个搜索区；`search_bottom=True` 时额外追加**底部中央条带**（宽 `side*2.2`、高 `side`、水平居中），覆盖 AI 平台署名栏位置。该参数透传至 `detect_corner_logo(...)`，作用于 OCR / MSER / Otsu 的搜索范围。

### 3.4 总入口透传（`detect_watermark_mask`）

签名新增 `preset=None, enhance_tiled=config.DETECT_ENHANCE_TILED, search_bottom=config.DETECT_SEARCH_BOTTOM`。函数体开头若 `preset` 有效，先用 `get_preset(preset).resolve(...)` 覆盖 `sensitivity / enable_* / enhance_tiled / search_bottom / use_ocr` 的**非 None** 字段；未知预设仅告警并回退默认，绝不抛异常。

| 入口 | 改动点 | 透传方式 |

## 5. 配置项（`config.py`）

新增第 8.x 节检测配置段：

| 常量 | 默认 | 含义 |
|------|------|------|
| `DETECT_SEARCH_BOTTOM` | `True` | 底部居中搜索区开关 |
| `DETECT_ENHANCE_TILED` | `False` | 平铺半透明增强开关（默认关，由 ai_tiled 预设开启） |
| `DETECT_PRESET_DEFAULT` | `"general"` | 默认检测预设（CLI/UI 下拉初值） |

均支持 `.env` 覆盖；`get_config_snapshot()` 追加「底部居中搜索区 / 平铺半透明增强 / 默认检测预设」三字段。

## 9. 边界与注意事项

- 平铺增强默认关闭，仅 `ai_tiled` 预设开启；它作为补充并集，**不破坏**基础检测。
- 底部搜索区仅在 `search_bottom=True` 时扩大角落搜索范围，不影响其他策略。
- 预设「只覆盖非 None 字段」是向后兼容的关键：旧调用方（不传 preset）行为零变化。
- 检测核心数学（`detect_translucent` / `detect_corner_logo` / `detect_edge_text` 内部算法）本阶段未改动，仅新增增强分支与搜索区扩展。
- 沙箱未装 EasyOCR 时，`use_ocr=True` 的预设（ai_signature）实际仍走 OpenCV 原生检测，OCR 为「有则增强」，不影响可用性。
