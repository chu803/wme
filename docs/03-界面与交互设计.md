# 阶段 3 交付文档：Gradio 交互界面（单图处理）

> 项目名称：AI 智能水印擦除工作台
> 阶段目标：搭建 Gradio 网页界面，实现「单张图片上传 + 画笔/矩形涂抹 + 手动修复 + 左右对比预览」。

---

## 一、本阶段交付文件

| 文件 | 层级 | 职责 |
| --- | --- | --- |
| `core/mask_generator.py` | 算法层 | 把 ImageEditor 的涂抹结果标准化为单通道 0/255 掩码；兼容 Gradio 4.x 元组与 6.x dict 两种返回格式 |
| `services/validators.py` | 服务层 | 图片上传校验：格式白名单、体积上限、解码校验、像素上限 |
| `services/file_service.py` | 服务层 | 上传落盘、读取、缩略图生成、结果保存（outputs 目录） |
| `ui/tab_single.py` | 界面层 | 单图处理标签页：ImageEditor + 参数面板 + 对比预览 + 下载 |
| `ui/app.py` | 界面层 | 应用骨架 `build_app()` 与启动 `launch_app()`（端口探测、主题、异常捕获） |
| `utils/exceptions.py`（补） | 基础 | 新增 `InvalidMaskError(ImageError)` 异常类 |

## 三、⚠️ 关键兼容性发现（Gradio 6.x vs 4.x）

本项目沙箱实测的 Gradio 版本为 **6.22.0**，与常见教程的 4.x 存在破坏性 API 变更，已逐一修正：

| 差异点 | Gradio 4.x | Gradio 6.x（本项目实测） | 修正方式 |
| --- | --- | --- | --- |
| ImageEditor 返回值 | `(image, mask)` 元组 | `dict`：`{background, layers, composite}` | `mask_generator` 改为读取 `layers` 的 alpha 通道合并掩码 |
| ImageEditor 工具 | `tools=["brush","rect"]` | `tools` 参数已移除；画笔/橡皮为内置工具 | 改用 `brush=gr.Brush(...)` 自定义画笔；矩形框选以「画笔覆盖矩形范围」等效达成 |
| Brush 参数 | `color=`, `color_mode=` | `colors=`（列表）、`default_color=` | `gr.Brush(colors=["#ff3b30"], color_mode="fixed")` |
| 主题 theme | `gr.Blocks(theme=...)` | theme 移到 `launch(theme=...)` | `build_app` 不再传 theme，`launch_app` 传 |
| show_api | `launch(show_api=...)` | 参数已移除 | 改用 `launch(footer_links=[...])` 控制底部「API」链接显隐 |
| torch 依赖 | — | `device_manager` 全部延迟 import torch | 无 torch 也能启动 UI（auto 引擎自动降级 OpenCV），更符合阶段 7 的 CPU/GPU 自适应目标 |

> 矩形框选说明：Gradio 6.x 的 ImageEditor 不再提供独立「矩形框选」工具。当前用画笔涂抹即可完整覆盖矩形区域；若后续阶段需严格矩形框选组件，可在阶段 6 评估引入 `gr.AnnotatedImage` 或自定义 Canvas。

## 四、掩码提取方案（核心）

`core/mask_generator.build_mask_from_editor(editor_value, brush_threshold, target_size)`：

- **Gradio 6.x dict**：`background`=原图，`layers`=用户绘制的所有图层（RGBA，alpha 表示绘制区）。合并所有图层的 alpha 通道（阈值二值化）→ 标准掩码。
- **Gradio 4.x 元组**：直接取第二项 `mask`。
- 始终按 `target_size`（=原图尺寸）做最近邻对齐，保证掩码与 `inpaint` 输入同尺寸。
- 返回 `(H,W) uint8`，255=水印区，0=保留区。

## 五、验证结果

在隔离 venv（numpy + opencv + gradio 6.22）中实测：

1. 全量语法编译通过。
2. `mask_generator` 自检：RGBA/空掩码/Gradio 6.x dict/Gradio 4.x 元组 4 类用例全部通过。
3. `validators` 自检：合法图通过、损坏文件拦截、numpy 校验通过。
4. `file_service` 自检：落盘、缩略图、结果保存通过。
5. **`build_app()` 实测**：Gradio 6.x 组件（ImageEditor + Brush + 各滑块 + Tabs）构造无报错。
6. **端到端单图链路**：模拟用户涂抹 → `process_single` 自动降级 OpenCV 引擎 → CPU 推理 → 结果保存 → 对比回传，水印区被正确修复，空涂抹被正确拦截。

> 注：LaMa 真实推理路径需 `torch` + `big-lama.pt`（沙箱未装 torch），代码按标准约定编写，待本地 `pip install -r requirements.txt` 并 `python download_model.py` 后在阶段 4/6 接入时一并验证。
