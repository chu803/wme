# ① 功能介绍：去掉 AI 图片上的角标水印

## 1.1 它做什么

把**你自己生成的 AI 图片**上那个角落里的平台角标（如右下角「豆包AI」白色圆角小牌）去掉，
让画面里看不出原来挂过标。

**承诺范围只有一类：角标 LOGO**（`ai_logo`）——就是图片角落里的平台标识/徽标。
界面首屏就写明了这一点：

> 适用范围：本工具承诺处理 **角标 LOGO（ai_logo）**；**明确不承诺** 平铺文字（ai_faint_tiled）、
> 全局渐变（ai_gradient）、网格点阵（ai_grid）、边缘小字（ai_text_heavy）等样式
> —— 后者对应预设仍可选用，但效果不保证，也不计入质量门禁的结论。

不承诺的两种原因（界面上也写了）：
- 一种我们**实测过上限**——定位全对也几乎没有净收益（例：极淡平铺文字，收益中位仅 0.026）；
- 一种只是**缺真实标注样本**，尚未定论。

## 1.2 怎么用（三步）

| 步骤 | 界面 | 说明 |
| --- | --- | --- |
| ① 上传 | 「智能自动检测」页的左栏 | 拖拽或点选图片；也可以点「没有图？试一张示例」 |
| ② 检测 | 蓝色大按钮「② 自动检测水印」 | 自动找出疑似水印区域：红色=水印区，彩色框=类别<br>（橙=半透明 / 青=角落LOGO / 紫=边缘小字 / 绿=OCR文字） |
| ③ 修复 | 蓝色大按钮「④ 一键修复」 | 处理完给出 原图 / 处理后 / Before\|After 拼接 三种对比，并可「⑥ 下载处理结果」 |

**能自己微调**：检测后点「检测区域」里的区域可取消勾选（误报不修）；
漏检的地方用画笔在编辑框补涂，再点修复。参数区（修复引擎 / 力度 / 降噪 /
掩码膨胀 / 边缘平滑 / 阈值 / 后处理）都能实时调。
（阶段 405：Gradio 6.31 对预填图层的编辑会错位，橡皮擦越擦越多 ⇒ 误报改为区域勾选。）

**修复后会告诉你代价**：状态栏会写「· 本次实际改动约 x% 的画面（与原图逐像素比较；
若这些不是水印，请在「检测区域」取消勾选对应项后重试）」——不是默默改你的图。

## 1.3 效果（真实图实测，非宣传语）

| 指标 | 数字 | 口径 |
| --- | --- | --- |
| 真实 AI 角标图：**检出率** | **94.2%** | 50 张真实标注角标图，走推荐器（用户默认路径） |
| 真实 AI 角标图：**完全擦净率** | **98.0%** | 同上；擦净 = 修复后角标可见度降到路由阈值以下 |
| 几何挑战集：**检出 / 擦净** | **4/4 / 4/4** | 4 种角标形态（左下小板 / 358×67 大板 / 半透明板 / 无底板纯文字），逐张目视核过 |
| **干净图误伤** | 中位 **0.0000%**、最大 0.055% | 16 张**无水印**图走默认路径，被改动像素占比 |
| 修复区外溢（框外足迹） | 中位 **1.9%** | 承诺类真实图，红线 ≤3% |
| 角标可见度中位数 | **0.813 → 0.161** | 修复前 → 修复后（越小越干净） |

## 1.4 诚实的边界（别被上面好看）

- **"不承诺"的四类**：平铺文字、网格点阵、全局渐变、边缘小字——能选，但效果不保证。
- **角标形态敏感**：上面 98% 来自豆包系角标（右下角、白底板 + 小字）；
  换成别的形态已覆盖 4/4，但**没有覆盖的是"真实生成器的其它形态"**——挑战集是按参数复刻的合成样本。
- **角落有一块亮底招牌（不是水印）会被多擦一圈**：实测边际改动 0.457%（改前只擦文字）。
  像素上"招牌"与"角标"不可分，这是承诺类的固有歧义，已用守卫钉住上限。
- **没装 LaMa 权重时**角标位置会留一小块涂抹痕（OpenCV 引擎）；界面里选 `lama` 更干净。
- **合规**：界面首屏写明只用于去除**您本人生成**的 AI 图片上的水印，
  且检测与修复**都在本机完成**（图片不上传；唯一联网是首次下载模型权重约 205 MB，匿名统计默认关闭）。

# ② 测试要求（可直接交给外部测试者）

> 口径说明：**"完全擦净"**＝修复后角标可见度降到与路由同一阈值以下（不是"看着差不多"）；
> **"干净图误伤"**＝无水印图走默认路径后**被改动**的像素占比。
> 每个用例都要**截图 + 逐字抄下状态栏原文**，不要复述。

## 2.1 功能用例（必测）

| # | 用例 | 操作 | 期望 | 判定 |
| --- | --- | --- | --- | --- |
| F1 | 角标能被检出 | 上传带角标图 → ② 自动检测水印 | 预览里角标位置出现红色水印区 + 类别框（青=角落LOGO） | 目视 |

| F6 | 可补涂 | 用画笔补一块漏检区域 → 修复 | 该区域被擦掉 | 目视 |

## 2.3 边界与异常用例

| # | 用例 | 期望 |
