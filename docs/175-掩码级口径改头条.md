# 阶段 175 · 对外头条口径改为掩码级（172-B）

## 1. 动机

区域级逐项 IoU 在**本任务**上有两处系统性失真（172 实测）：
1. **形态不匹配**：检测器会把「一块水印」拆成多个区域（实测角标被拆成 3~17 个），
   而真值是 1 个框 ⇒ 「1 真值 vs N 预测碎片」在 IoU≥0.3 的逐项口径下天然吃亏；
2. **与真值大小强耦合**：预测 ⊂ 真值时 `IoU ≈ 预测面积/真值面积`，
   真值框一变（172-A 从 317 宽改到实测 340 宽），同一套预测的 IoU 就整体变一个档
   （mean_iou 0.2952 → 0.2078）。

这与项目 101 契约「对外打分用掩码级指标，禁 bbox-IoU」一致。

## 2. 改动

`mask_recall` **此前根本没被计算**（只有 mask_iou / mask_coverage）。

- `scripts/run_real_benchmark.py`
  - 新增 `_mask_px(pred, truth) -> (交集像素, 真值像素)`；
  - `evaluate_one` 增 `mask_recall`（= 交集/真值）+ `mask_inter_px` / `truth_px`；
  - `_aggregate` 增 `mask_recall_micro`（Σ交集/Σ真值，**头条**）与 `mask_recall_mean`（次级）；
  - `_print_markdown` 把 `mask_recall(micro)` 提到首列并标明「头条口径」。
- `scripts/real_gate.py`
  - `run_real_gate.per_preset` 增 `mask_recall`（micro）；
  - `to_markdown` 表头增 **「掩码召回(头条)」** 列（置于 n 之后），区域级三列降为次级；
  - `REAL_TOLERANCES` 增 `mask_recall: 0.10`（与 `recall` 同容差，漂移层监控；
    旧基线无此键时漂移层自动跳过，**不会误报**）。

## 3. 验证

```
| 预设 | n | **掩码召回(头条)** | 精确率 | 召回(区域) | 区域IoU | 掩码IoU | 掩码覆盖率 | 过检倍率 | 契约 |
| general | 10 | **0.5619** | 0.0690 | 0.8000 | 0.5347 | 0.2975 | 0.0291 | 2.80× | 红线 |
```

- **交叉校验**：门禁算出的 `mask_recall = 0.5619` 与 174 阶段**独立探针**（自定义
  `detect_watermark_mask` 调用）算出的 **0.562 逐位一致** ⇒ 两处实现同源、无口径漂移。
- `real_gate` EXIT=1（**红线仍是区域级** recall 0.80 / precision 0.069 / iou 0.535）；
  本阶段只改**报告口径与监控**，不改判定 ⇒ 无行为回归。
- 面积监控四类不变（红线内）。

## 4. 诚实边界

- 红线**仍挂在区域级三指标**（`REAL_PRESET_CONTRACT`）——本阶段只是把**头条展示 +
  漂移监控**切到掩码级。红线的迁移/重标属 172-C（需等检测器稳定后标定），**未做**。
- 因此 `real_gate` 仍 EXIT=1，且原因（区域级三项未达）与改前完全一致。
