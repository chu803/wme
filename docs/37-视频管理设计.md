# 阶段 37 · 视频管理设计文档

> 目标：把「视频去水印」的结果从「只给一个视频文件 + 单帧对比」升级为**可浏览、可逐帧对比、可导出、可进历史回访**的完整管理闭环。
> 范围：结果浏览画廊 + 逐帧对比面板联动、结果导出（对比帧图 / 帧拼图）、历史页视频记录管理。
> 约束：纯服务层逻辑零 torch 依赖、可完整测试；分层铁律不变（`ui → services → core → utils → config`，`core/services/utils` 零 gradio）。

---

## 1. 背景与缺口

阶段 33 已接入视频真实超分并在视频页新增「抽帧对比查看」（单帧序号滑块 + 拼接/滑块/热图）。
但仍有明显短板：

1. **结果不直观**：处理完只返回一个视频文件，不播放就无法快速判断整体修复效果；
2. **逐帧对比割裂**：对比面板依赖用户手动拖「抽帧序号」滑块，无法从「整段修复效果」一眼定位到某帧；
3. **无导出**：想把某一帧的对比图或整段缩略拼图发给别人 / 存档，没有现成入口；
4. **历史页无视频**：`HistoryRecord` 只有图片字段，视频结果不进历史，无法回访/下载。

## 2. 改动清单

### 2.1 `config.py`
- 新增 `VIDEO_COMPARE_FRAMES: Final[int]`（默认 6，范围 1–48）：视频结果浏览时抽取的样帧数（阶段 33 已有 `VIDEO_MAX_FRAMES` 等，此处补齐浏览专用参数）。

### 2.2 `services/video_service.py`
- 新增 `extract_sampled_frames(path, n=None, *, return_indices=True)`：
  - 先算目标帧序号集合（**强制含首帧与末帧**，其余均匀铺开）；
  - 顺序遍历视频，命中目标即抽，抽到齐或到末尾即收尾（任何长度只顺序读一遍，不反复 seek）；
  - 返回 `list[{"idx": int, "image": np.ndarray(RGB)}]`；文件缺失/读不到安全返回已抽部分（甚至空列表）。

### 2.3 `services/export_service.py`
- 新增 `make_contact_sheet(frames, cols=4, thumb_size=160, bg=深蓝灰)`：多张帧图拼成网格「联系表」，
  每格等比缩放到 `thumb_size` 居中铺底；空列表返回 1×1 灰块兜底。

### 2.4 新增 `services/video_export.py`（纯服务层，零 gradio）
- `export_frame_compare(src_video, out_video, idx, out_dir=None)`：
  从源/结果各抽第 `idx` 帧，结果若被真实超分放大则**缩回源尺寸对齐**，调 `make_compare_array` 拼图，存 PNG 返回路径；缺资源返回 `None`。
- `export_contact_sheet(video_path, n=None, cols=4, out_dir=None)`：
  调 `extract_sampled_frames` 抽帧 → `make_contact_sheet` → 存 PNG 返回路径；缺资源返回 `None`。
- `__main__` 自检：合成带水印小视频 → `process_video` → 两导出函数均产出文件。

### 2.5 `services/cache_service.py`
- `HistoryRecord` 扩展字段（图片记录保持默认，旧数据兼容）：
  `kind`（image/video）、`video_path`、`duration`、`fps`、`frames`、`width`、`height`、`upscaled`，
  并同步进 `to_dict()` / `from_dict()`。
- 新增 `add_video_record(src_path, out_path, *, original_name, params, duration, fps, frames, width, height, upscaled)`：
  抽结果视频**首帧**作缩略图（`make_thumbnail` + `save_thumbnail`），登记 `kind="video"` 记录（缓存关闭时返回 `None`）。

### 2.6 `ui/tab_media.py`（视频页）
- 模块级 `_CACHE = get_cache()`；导入 `export_frame_compare` / `export_contact_sheet`。
- 辅助函数：
  - `_build_video_browse_gallery(out_path)`：处理后从结果视频抽样帧，组装 `gr.Gallery` 值（图片数组 + 标题）。
  - `_store_video_record(res, src_path)`：成功后调 `_CACHE.add_video_record` 登记历史（异常静默）。
  - `on_frame_gallery_select(evt, src, out, mode)`：点击浏览画廊某帧 → 写抽帧序号滑块 + 立即渲染对比图（**注解 `evt: gr.SelectData`** 以消除 Gradio 参数计数警告）。
  - `export_frame_file(...)` / `export_sheet_file(...)`：薄封装导出函数，返回文件路径供 `gr.File` 下载。
- `run_video` 返回由 4 元组扩为 **6 元组**：`(video_log, video_out, ffmpeg_cmd, video_detect_stats, v_frame_gallery, v_export_file)`；成功时填充浏览画廊并登记历史。
- 结果区新增组件：
  - 「🎞️ 结果帧浏览」`gr.Gallery`（列数=`VIDEO_COMPARE_FRAMES`，点击联动对比面板）；
  - 导出按钮「⑦ 导出对比帧图」「⑧ 导出帧拼图」+ `gr.File` 下载出口。
- 事件绑定：
  - `v_frame_gallery.select → on_frame_gallery_select`（输出 `v_compare_frame` + `v_compare_html`）；
  - `v_export_frame_btn.click → export_frame_file`；`v_export_sheet_btn.click → export_sheet_file`（输出 `v_export_file`）。

### 2.7 `ui/tab_history.py`（历史页 · 视频记录管理）
- `load_gallery`：视频记录画廊标题加 `🎬` 徽章（`{name}｜视频`）。
- `_record_detail`：视频记录追加「视频信息」（分辨率/帧率/帧数/时长/是否超分）+ 提示「仅预览下载，重新处理请回视频页」。
- `on_select`：返回由 2 元组扩为 **3 元组**，第三项对视频记录返回 `video_path`、图片记录返回 `None`。
- 详情列新增 `gr.Video`（视频预览，仅视频记录有值）。
- `reprocess`：视频记录直接返回提示，不进入图片重处理流程。
- `gallery.select` 输出追加 `video_preview`。

### 2.8 `utils/i18n.py`
- `media.video` 新增：`browse_title` / `browse_info` / `browse_empty` / `export_frame_label` / `export_sheet_label` / `export_no_video` / `export_done`（中英双语）。
- `history` 新增：`video_preview_label`、`detail.video`、`detail.video_hint`（中英双语）。

## 3. 数据流（视频结果闭环）

```
run_video 成功
  ├─ _build_video_browse_gallery(res.out_path)  →  v_frame_gallery（样帧画廊）
  ├─ _store_video_record(res, src)              →  CacheService.add_video_record（首帧缩略图 + 元信息）
  └─ (用户交互)
        ├─ 点击画廊帧  → on_frame_gallery_select → v_compare_frame + v_compare_html（抽帧对比）
        ├─ 导出对比帧图 → export_frame_file  → v_export_file（PNG）
        └─ 导出帧拼图   → export_sheet_file → v_export_file（PNG）

历史页
  load_gallery（视频首帧缩略图入画廊，🎬 徽章）
  └─ on_select → 详情(视频元信息) + download_file + video_preview(结果视频)
```

## 5. 兼容性 & 风险

- **旧数据兼容**：`HistoryRecord.from_dict` 对缺失视频字段给默认值，旧图片记录照常工作；缓存 `_load` 仍按 `result_path` 存在性过滤，失效视频记录自动忽略。
- **性能**：`extract_sampled_frames` 顺序只读一遍视频，开销极小；浏览画廊用内存数组交给 `gr.Gallery`（与历史页对比缩略图同机制）。
- **零 torch**：抽帧/拼图/导出均走 OpenCV + NumPy，沙箱无 torch 完全可测；真实超分仅影响结果尺寸（导出时已对齐缩回）。
- **不破坏分层**：`video_export.py` 仅依赖 `core`/`utils`/`config`/`video_service`/`export_service`，无 gradio 依赖。
