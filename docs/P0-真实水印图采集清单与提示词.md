# P0 · 真实水印图采集清单与提示词（交给你出图，我负责收编/标注/打分）

> 目的：解除 `real_gate` 的 **`ai_logo` 红灯**（承诺处理角标 LOGO，却 0 条真实真值）。
> 分工：**你**用豆包/即梦出图 → **我**收编（`collect_real_assets`）→ 人工量取 bbox 写真值
> （`manual:measured`，**不用 auto**）→ 跑 `real_gate` 转绿。

## 一、我需要什么图（硬性要求）

| 项 | 要求 | 原因 |
|---|---|---|
| **水印位置** | **平台自带的角落水印**（即梦/豆包一般在**右下角**），**不要裁剪、不要去除、不要压缩** | 承诺类型 `ai_logo` 的真值 style = `corner_logo`（角标文字/平台签名，Midjourney 风）。裁掉水印的图对本门禁无用。 |
| **数量** | **≥3 张**（下限），**建议 8 张** | `MIN_IMAGES_FOR_COMMIT = 3`；8 张才能让红线+漂移层有信号。 |
| **分辨率** | **长边 ≥1024**，**1:1 正方形**最佳 | 现有基准集是 1024²，口径一致才可比。 |
| **格式** | JPG / PNG（**原图导出**，别再转存/压缩） | 二次压缩会改变水印像素，真值随之失真。 |
| **内容** | **尽量多样**（见下方提示词）：亮底/暗底/高纹理/纯净底都要有 | 门禁要压测「角落通路」在**不同角落背景**上会不会过检/漏检。 |
| **来源** | **平台真实水印**（豆包/即梦自带），**不要**自己 P 一个 logo 上去 | 「合成水印 ≠ 平台真水印」是本项目写明的诚实边界。 |

> ✅ 先发 **1 张**给我，我确认「水印位置/是否属于 corner_logo/清晰度」合格后，你再批量出 8 张，避免白做。

## 二、提示词（逐条粘进豆包，**每条生成 1 张**，共 10 条）

> 通用后缀（每条都加上）：**「写实摄影风格，正方形 1:1，最高分辨率，保留平台水印」**
> 提示词刻意让「画面右下区域」的明暗/纹理各不相同——这正是压测角落通路的变量。

1. 特写照片：一只橘色虎斑猫趴在深色胡桃木桌上，柔和侧窗光，浅景深，**画面右下区域为深色木纹**。
2. 广角风光：清晨雪山与平静湖面倒影，冷蓝调，**画面右下区域为亮白积雪/水面**。
3. 极简产品：白色陶瓷咖啡杯放在纯白背景，影棚柔光箱，**画面右下区域为大面积纯净白**。
4. 城市夜景：雨后霓虹街道，橱窗灯光在地面反光，**画面右下区域为深色沥青路面**。
5. 美食俯拍：木质桌面上的时令水果拼盘，暖色自然光，**画面右下区域为高纹理木质**。
6. 人像：戴草帽的年轻女性在夏日花田中侧身回望，逆光轮廓，背景虚化，**画面右下区域为虚化花海**。
7. 建筑摄影：现代玻璃幕墙大楼仰视视角，蓝天白云映在玻璃上，**画面右下区域为玻璃反射**。
8. 抽象艺术：流动颜料在液体中扩散，蓝紫渐变，微距质感，**画面右下区域为中等明度渐变**。
9. 静物：复古机械打字机特写，金属键面反光，暖色台灯，**画面右下区域为金属反光**。
10. 自然风光：薰衣草花田与远处热气球，紫色调晴朗天空，**画面右下区域为紫色花丛**。

（若你想省事：把上面 10 条里挑 **8 条**跑一遍即可，覆盖「亮/暗/纹理/纯净」四类角落背景就够。）

## 三、交付方式（二选一）

- **方式 A（推荐）**：把 8 张图放进一个文件夹，把文件夹路径发我，我用
  `python scripts/collect_real_assets.py add <文件> --ai-source other --style corner_logo --copy`
  收编。
- **方式 B**：直接丢进 `benchmark_real/inbox/`（我已建好该目录 + 忽略了入库），告诉我一声即可。

## 四、我接手后会做什么（你不用管）
1. 收编入库（查重 sha256、填元数据、入库 manifest）。
2. **人工量取**每张图角落水印的 bbox → 写进 `ground_truth.json`（`labeled_by="manual:measured"`）。
3. `build_real_ground_truth.py validate` 校验 → `real_gate.py` 跑门禁 → `ai_logo` 由红转绿。
4. 若某张水印实际是「底部居中文字」而非角落，我会把它登记为 `edge_text`（走另一类承诺），不会硬塞进 corner_logo。

## 五、如果豆包出不了角落水印怎么办
- 换 **即梦 / Midjourney / Adobe Firefly** 等会加**角落**水印的平台；
- 或告诉我你实际能拿到的是哪种水印（底部文字 / 网格 / 渐变），我按对应 `style` 收编——但**承诺面**当前只承诺 `ai_logo`，其他类型需要另行决定是否升格为承诺类型。
