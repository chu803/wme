# 阶段 318b · 把「只动水印区」抬到用户能用（CLI / api / REST）

> 日期 2026-10-23 · 产物 `api.py`、`services/{auto_pipeline,pdf_service,video_service}.py`、
> `server.py`、`cli.py`、`tests/test_preserve_untouched_facades318b.py`（13 例）

## 一、为什么还要一个 318b

318 把能力做进了引擎，但入口只有环境变量 `WME_POSTPROCESS_PRESERVE_UNTOUCHED=true`。
这正好是我自己在 315 写在 LESSONS #298 的那句话——**能力存在但对调用方不可达**：
文件级/docker/服务端的部署者能开，普通用户与脚本作者开不了。

所以本阶段只做一件事：**把同一个开关接到四个门面上**，默认值不动。

## 二、接了什么

| 层 | 改动 |
|---|---|
| `services/postprocess_service.py` | `postprocess(..., preserve_untouched=None)`：`None` ⇒ 取 config，显式 `True/False` ⇒ 覆盖单次请求 |
| `services/auto_pipeline.py` | `process_image` / `process_file` 各加一个参数并下传 |
| `services/pdf_service.py` / `video_service.py` | `process_pdf` / `process_video` 加参数，下传到逐页/逐帧的 `process_image`（3 处调用） |
| `api.py` | 6 个入口全部加参数并转发：`remove_watermark` / `_bytes` / `_array` / `batch_remove` / `_pdf` / `_video`；`get_capabilities()` 暴露 `postprocess_preserve_untouched` / `postprocess_preserve_band_px` |
| `server.py` | REST 白名单 `_collect_params` 收 `preserve_untouched` 并做 `"true"/"1"/"yes"/"on"` 归一 |
| `cli.py` | `--preserve-untouched / --no-preserve-untouched`（**三态**：不传=None 跟随配置），三处处理分支（图/PDF/视频）都转发 |

**语义边界（写清楚，避免误解）**：

- `None`（不传）⇒ 跟随服务端 `config.POSTPROCESS_PRESERVE_UNTOUCHED`（当前 False）。
- 显式 `False` ⇒ **逐请求强制关**，即使服务端配置为开。REST 客户端传 `"preserve_untouched": false`
  就是这个语义——它是"覆盖"，不是"没意见"。
- 逐页/逐帧生效：PDF 的每一页、视频的每一帧各自按自己的掩码还原带外像素。
  页与页之间没有共享像素，所以不存在跨页污染；但**每页内**都会保留 8px 保护带。

## 三、守卫（13 例）——签名存在不算接上

全部用「替换下游函数 + 捕获实参」的方式，证明值**真的走到了下一层**：

| 门面 | 用例 |
|---|---|
| api 6 入口 | 6 例各自 monkeypatch 下一层并断言 `preserve_untouched is True`（array 那例用 `False`，防止被 `None` 吞掉） |
| PDF / 视频服务层 | 2 例真造 1 页 PDF / 3 帧 MP4，monkeypatch `process_image`，断言逐页/逐帧调用收到 `True` |
| REST | 1 例：白名单收键 + 字符串归一 + 缺省不出现 |
| CLI | 2 例：`--preserve-untouched` 三态解析 + `_run_one` 转发到 `process_file` |
| 端到端有效性 | 1 例：数组门面在「关闭时带外确实变、开启时带外逐字节不变、两种取值结果不同」三条同时成立才算过 |
| 反向钩子 | 端到端那例**先断言关闭态带外确有变化**，否则"开启后相同"是空断言（LESSONS #304） |

全部纯 CPU/毫秒级（PDF/video 那两例只有 64×64）。

## 四、诚实边界

- **UI 设置页还没做**（318c）：目前用户只能通过 CLI 开关或环境变量使用。设置页要做的话，
  得同时改「保存为默认」的 `user_overrides` 白名单，属独立阶段。
- **`preserve_untouched=True` 不是"完全不动其它像素"**：保护带（默认 8px）内仍会走后处理，
  这是刻意留的（否则边界会出现 1px 硬接缝）。契约的准确表述是「**带外**逐字节不变」。
- **视频逐帧还原会带来帧间稳定性风险**：每帧的检测掩码不同 ⇒ 还原边界逐帧变化。
  静止水印（掩码稳定）下无影响；运动水印场景需要单独跑一次视频基准才能下结论（未做）。
- REST 的"覆盖"语义可能让客户端无意中关掉服务端开着的保护——这是设计选择（显式优先），
  但要在客户端文档里写明白。
