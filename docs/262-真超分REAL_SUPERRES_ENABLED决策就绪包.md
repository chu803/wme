# 阶段 262 · 真·超分 `REAL_SUPERRES_ENABLED` 决策就绪包（待决项① 收口）

> 把「待决项① `REAL_SUPERRES_ENABLED` 取值」从模糊 worry 变成**可一键拍板的量化包**。
> **本阶段不擅自改配置**——改产品默认属用户决策；此处只提供实测依据 + 守卫固化。

## 一、事实起点（一个此前被忽略的事实）

仓库内 **`config.user_overrides.json`（已 git 追踪、非忽略）** 把超分打开：

```json
{ "REAL_SUPERRES_ENABLED": true, "REAL_SUPERRES_SCALE": 2, "REAL_SUPERRES_BACKEND": "esrgan" }
```

这与项目代码默认值（`False` / `4` / `auto`，见 `config.py`）**全部相反**，且是**入库配置**
⇒ 待决项① 的真正问题不是「要不要开」，而是「**这个开启（无权重 + esrgan + 2×）是否正确**」。

> 附带影响：该配置对本机**所有**运行生效——包括此前257/260/256 的 GPU 探针
> （其日志均出现「真实超分已应用：…退化为纯双三次放大（2×）」）。

## 二、探针实测（真实postprocess 链路，合成图300×400）

`.scratch/probe_superres262.py`（已清理）：

| 配置 | 输出尺寸 | 耗时(s) | 掩码区 PSNR |
|---|---|---|---|
| **关** | 300×400（原尺寸） | 0.028 | **7.71 dB** |
| 开 scale=2（= 当前入库配置） | 600×800（2×） | 2.633 | 7.68 dB |
| 开 scale=4 | 1200×1600（4×） | 0.146 | 7.65 dB |

> 注：scale=4 耗时反低源于后端缓存/复用，**不作依据**；PSNR 的单调微降才是可靠信号。

## 三、结论：当前开启是**净负收益**（无质量增益 + 显著增耗时）

结合阶段 115 已证：**无训练权重时 esrgan 退化为纯双三次**（`used_real=False`）。因此：

- **质量**：开启后掩码区 PSNR **不升反微降**（7.71 → 7.68 → 7.65 dB）⇒ **无学习式增强收益**；
- **代价**：耗时显著上升（0.028s → 2.633s，约 94×；后端首次构建含权重探测开销）；
- **净结论**：当前开启只带来「输出尺寸放大」，却付出质量不升 + 耗时暴涨 ⇒ **净负**。

> 决策含义：若要真正获得超分质量收益，需**提供 ESRGAN 训练权重**
> （配 `REAL_SUPERRES_MODEL_PATH`，使 `used_real=True`）；否则应**关闭**该开关。

## 四、决策选项（**待用户拍板，本阶段不执行**）

| 选项 | 动作 | 优点 | 代价 |
|---|---|---|---|
| **A. 关闭**（我的技术建议） | `config.user_overrides.json` 设 `REAL_SUPERRES_ENABLED=false` | 恢复同尺寸、快~94×、质量不降 | 失去 2× 放大输出（若前端/用户依赖大图） |
| **B. 维持开启** | 保持现状 | 输出尺寸放大 | 质量不增、耗时暴涨；且依赖「无权重退化」这一不理想路径 |
| **C. 配权重后再开** | 提供 ESRGAN 权重 → `used_real=True` | 真正获得学习式增强 | 需获取/训练权重（网络受限环境，见下） |

> 技术建议：**先 A**（当前无权重，开着无益）；若产品确需大图输出，则走 **C**（配权重），
> 而非维持B 这条「无权重却开着」的最差组合。
> **B 不会被我执行**——它是「无学习式增强却付代价」的配置。

## 五、守卫（`tests/test_superres_decision262.py`，3 例，固化决策依据）

1. `test_esrgan_without_weights_reports_bicubic_not_real`：无权重 ⇒ `used_real=False` 且
   note 含「双三次」（防115 同类「声明≠实现」复发）。
2. `test_bicubic_fallback_does_not_improve_mask_quality`：退化双三次放大**不得显著提升**
   掩码区质量（容差 0.5 dB）⇒ 把「无质量增益」钉成机器判定。
3. `test_no_claim_of_quality_gain_without_weights`：note 模板须同时含「已退化为纯双三次」
   与「可启用学习式增强」，不得反向宣称已增强。
