## 1. 本阶段目标

在不触碰核心修复算法（core 层既有逻辑零改动）的前提下，补齐三块"拓展能力"：

1. **脚本化 CLI**：让用户无需打开浏览器，直接在终端 / 服务器批量擦除水印。
2. **结果质量评估**：批量处理完后给每张结果打"质量分"，快速筛出"没修干净"或"修过头"的图。
3. **导出格式扩展**：在原有 PNG/JPG/WebP 基础上支持 TIFF（专业归档）与 AVIF（高压缩比）。

## 2. 架构与分层铁律

严格遵守既有分层：`ui → services → core → utils → config`，严禁反向依赖。

| 模块 | 层级 | 依赖 | 是否碰 gradio |
| --- | --- | --- | --- |
| `services/auto_pipeline.py` | 服务层（新） | core / utils / config / file_service | 否 |
| `services/quality_service.py` | 服务层（新） | core / utils / config | 否 |
| `cli.py` | 顶层脚本（新） | services / config | 否 |
| `core/image_utils.py` | 核心层（改） | cv2 / numpy / config | 否 |
| `config.py` | 配置（改） | 无 | 否 |

GUI 与命令行因此永远走同一套"检测 → 修复 → 保存"逻辑，行为不会分叉。

```

        │           │                             │
        └───────────┼─────────────────────────────┘
                    ▼
          services.quality_service.evaluate_quality(original, result)
                    │
                    ▼
            质量分 / 级别(good|warn|review)
```

## 3. 自动处理管线 `services/auto_pipeline.py`

### 3.1 函数签名

```python
process_file(
    input_path, *, mode="auto", engine=None,
    strength=None, dilate=None, feather=None, threshold=None,
    denoise=None, sensitivity=None, mask_path=None,
    out_fmt=None, quality=None, out_dir=None, on_progress=None,
) -> dict
```

### 3.2 处理流程

| 步骤 | 动作 | 说明 |
| --- | --- | --- |
| ① | 读取图片 | `core.image_utils.load_image_with_alpha`，中文路径 / 透明通道友好 |
| ② | 生成掩码 | `auto`：调 `detect_watermark_mask`（三类策略）；`manual`：读同名 `.mask.png` 或指定 `mask_path`，把"黑底+涂抹"转单通道 |
| ③ | 核心修复 | `core.inpainter.inpaint(image, mask, ...)` |
| ④ | 保存结果 | 指定 `out_dir` 时用 `save_image` 落用户目录；否则 `save_result` 落 `outputs/日期/` |

### 3.3 进度回调

`on_progress(p, msg)` 把 0~1 进度平滑映射到整条链路：
- 检测阶段映射到 `[0.10, 0.40]`
- 修复阶段映射到 `[0.45, 0.90]`
- 保证界面进度条与 CLI 进度单调不回弹。

### 3.4 返回字典

```python
{
  "status": "success" | "skipped" | "failed",
  "input_path": ..., "original_name": ...,
  "out_path": ...,            # 仅 success
  "mask_pixels": int, "regions": int, "used_ocr": bool, "engine": str,
  "error": str,               # 仅 failed / skipped
}
```

`skipped` 表示"没检测到水印区域"（不是错误，不计入失败）。

## 4. 质量评估 `services/quality_service.py`

### 4.1 指标

**(1) SSIM（结构相似度，0~1）** —— 自实现高斯加权版，无需 scikit-image：

对每个通道 c：
```
μx, μy        = 高斯模糊(原图c), 高斯模糊(结果c)
σx², σy², σxy = 局部方差 / 协方差
SSIM_c = (2μxμy + C1)(2σxy + C2) / ((μx²+μy²+C1)(σx²+σy²+C2))
```
其中 C1=(0.01·255)²、C2=(0.03·255)²，高斯核 11×11，σ=1.5。
最终 SSIM 取三通道均值。

**(2) changed_ratio（变化像素比例，0~1）**：
```
changed = (|原图 - 结果| > 12).any(axis=2)   # 阈值 12 过滤压缩噪声
changed_ratio = changed.mean()
```

### 4.2 综合判定

| 条件 | 级别 | 含义 |
| --- | --- | --- |
| `changed_ratio < QUALITY_REVIEW_CHANGED_MIN` | **review** | 几乎没改动 → 水印大概率还在 |
| `changed_ratio > QUALITY_WARN_CHANGED_MAX` 且 `ssim < QUALITY_SSIM_WARN` | **warn** | 改动巨大 + 结构差异 → 可能修过头 |
| `ssim < QUALITY_SSIM_WARN` | **warn** | 结构差异偏大 → 留意边缘 |
| 其余 | **good** | 衔接良好 |

综合分 `score` 由 SSIM 线性映射（good 区间 72~100，warn 55~95，review 45~80），
最终若 `score < QUALITY_SCORE_REVIEW` 强制标记 review。

### 4.3 配置项（config.py，均支持 `.env` 覆盖）

| 常量 | 默认 | 说明 |
| --- | --- | --- |
| `QUALITY_REVIEW_CHANGED_MIN` | 0.0008 | 变化比例低于此值 → review |
| `QUALITY_WARN_CHANGED_MAX` | 0.25 | 变化比例高于此值且 SSIM 低 → warn |
| `QUALITY_SSIM_WARN` | 0.85 | SSIM 低于此值 → warn |
| `QUALITY_SCORE_REVIEW` | 60.0 | 综合分低于此值 → review |

> 启发式说明：极淡水印修复后 changed_ratio 本就偏小，可能误标 review。
> 这是"软提示"而非硬判定——真实业务里"结果与原图完全一致"几乎只会发生在
> 「没检测到 / 没修掉」，而此类图在 `auto_pipeline` 阶段已被 `skipped`，
> 根本不会进入评估，所以误报影响可控。

## 5. 命令行入口 `cli.py`

### 5.1 常用命令

```bash
# 单文件
python cli.py -i 照片.jpg -o 结果

# 整个文件夹（自动检测 + 质量评估）
python cli.py -i 原图目录 -o 结果目录 --evaluate

# 递归 + OpenCV 引擎 + WebP 输出
python cli.py -i 原图目录 -o 结果目录 -r -f WEBP --engine opencv

# 手动模式（同名 .mask.png 作掩码）
python cli.py -i 原图目录 --mode manual -o 结果目录

# 并发处理（CPU 安全，默认 1）
python cli.py -i 原图目录 -o 结果目录 --workers 4
```

### 5.2 参数一览

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-i/--input`（必填） | — | 文件或文件夹 |
| `-o/--output` | `outputs/cli` | 输出目录 |
| `--mode` | `auto` | `auto` / `manual` |
| `--engine` | `auto` | `auto` / `lama` / `opencv` |
| `-f/--format` | 配置值 | PNG/JPG/WEBP/TIFF/AVIF |
| `-q/--quality` | 配置值 | 1~100（仅 JPG/WebP） |
| `-s/--sensitivity` | 配置值 | 检测敏感度 0~1 |
| `-r/--recursive` | 关 | 递归子目录 |
| `-e/--evaluate` | 关 | 处理后评估质量并告警 |
| `--mask-dir` | 同输入 | 手动模式掩码目录 |
| `--strength/--dilate/--feather/--threshold/--denoise` | 配置值 | 修复参数 |
| `--workers` | 1 | 并发线程数 |

### 5.3 容错设计

- 文件夹模式按扩展名过滤图像，非图像自动跳过。
- 单张失败 / 异常被捕获，**不中断整批**，仅计入失败汇总。
- `--workers > 1` 走 `ThreadPoolExecutor`，进度不打 stderr（避免交错），完成统一打印。

## 6. 导出格式扩展（`core/image_utils.py` / `config.py`）

`SUPPORTED_OUTPUT_FORMATS` 由 `("PNG","JPG","WEBP")` 扩展为
`("PNG","JPG","WEBP","TIFF","AVIF")`。

### 6.1 TIFF

```python
elif out_fmt == "TIFF":
    comp = getattr(cv2, "IMWRITE_TIFF_COMPRESSION", None)
    if comp is not None:
        params = [comp, int(config.TIFF_COMPRESSION)]   # 默认 LZW=5
```
`TIFF_COMPRESSION` 可经 `.env` 调整（1=不压缩 / 5=LZW / 34892=无损WebP）。

### 6.2 AVIF（三级安全回退）

```python
def _save_avif(path, arr, alpha, quality):
    ① 先试 cv2.imencode(".avif", ...)          # 少数新版 OpenCV 支持
    ② 回退 Pillow 的 AVIF 插件                  # 需 pillow-avif-plugin
    ③ 再失败 → 降级为 PNG 并告警                # 绝不因格式崩溃
```
AVIF 是"尽力而为"格式：环境支持就出 AVIF，不支持自动降级 PNG，
保证任何环境下导出都不会因格式问题报错。

## 9. 遗留说明 / 后续可优化

- **质量评估为启发式**：基于 SSIM + 变化比例的"软提示"，不是像素级水印残留检测。
  若需更准的"残留水印检测"，可后续训练轻量分类器或在 `quality_service` 增加
  "修复区域高频纹理异常检测"。
- **AVIF 依赖环境**：若环境既无 OpenCV AVIF 编码器又无 Pillow AVIF 插件，
  会自动降级 PNG（已在日志告警）。需要 AVIF 时安装 `pip install pillow-avif-plugin`。
- **CLI 进度显示**：串行模式进度用 `\r` 单行刷新，在真实终端表现良好；
  在管道（如 `| tail`）下日志与进度会交错，属正常表现，不影响结果。
- 阶段 9~11 待后续指令推进（如：更多输入源 PDF/视频帧、自定义模型接入、脚本化 API 增强等）。
