## 3. 轻量超分 pass 设计

### 3.1 为什么不实现「真·超分」

真·超分（2×/4× 放大）需要 AI 模型（EDSR/ESPCN 等）或 `cv2.dnn_superres` 加载权重，
而当前环境 torch 缺失（`pytest` 1 skipped 即 torch），引入模型权重会破坏「零新依赖 /
离线可用」的铁律，且会改变输出画布尺寸——这会破坏 `evaluate_improvement`（优化前后同尺寸
对比）与批量报告「原图|修复后」对比图的契约。

因此本阶段实现 **同分辨率的「细节超分辨率」近似**：在**不改变画布尺寸**前提下，把原图
外部区域的高频细节注入修复区并强化锐度，抵消 inpaint 造成的模糊 / 细节损失。它对用户
的直观价值是「修复区不再发糊、有纹理」，与「超分找回细节」目标一致，且完全离线。

> 真正的像素放大超分列为后续候选（需模型 + torch，属独立大模块），不在本阶段。

### 3.2 算法（`_superres`）

```
1) 高频细节（仅原图外部，避免把水印本身高频注回）：
   lap  = Laplacian(original, ksize=3)          # 比高斯差更细的高频
   lap  = lap * (mask == 0)                      # 仅外部
   w    = (mask/255)[:,:,None] * (amount * 0.6)  # 修复区软权重
   out  = result + lap * w
2) 整体 unsharp 强化（拿回高频）：
   blurred = GaussianBlur(out, sigma = max(0.4, 1.6 - amount))
   sharp   = out + amount * (out - blurred)
   out     = out*(1 - 0.5*amount) + sharp*(0.5*amount)
3) clip → uint8
```

与 `_texture_transfer`（高斯差细节）的区别：取更细的高频（拉普拉斯）并再叠一次整体
unsharp，细节恢复更强。`amount=0` 时直接返回原图（透传）。

### 3.3 流水线顺序

```
色彩还原 → 边缘融合 → 伪影抑制 → 纹理重建 → Poisson 融合 → 轻量超分 → 锐化
```

超分放在 Poisson 之后、锐化之前：先完成几何级融合，再做细节级重建，最后统一锐化收尾。

## 8. 已知边界

- 轻量超分是**同分辨率细节重建**，不是像素放大；真·超分（模型）列为后续独立模块。

  拉普拉斯 / 无缝克隆），大图批次时留意耗时。
