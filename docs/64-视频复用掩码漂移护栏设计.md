# 阶段 64 · 视频「复用掩码」漂移护栏：从"拍脑袋阈值"到"标定阈值"

> 一句话：视频管线的「抽帧 + 复用掩码」提速模式在水印缓慢漂移（平台滚动角标、镜头推拉）
> 时会用旧掩码盖错位置、留下肉眼可见的残留。本阶段先量化"漂移多少才真的有害"，再据此
> **标定**护栏阈值——过程中推翻了自己最初凭直觉设的 0.9（它会在无害区误触发、白白拖慢
> 视频），最终定为 0.70（恰好区分无害区 0.74 与危险区 0.64）。

---

## 1. 背景与第一个审计结论：逐帧检测本身是**时间稳定**的

在动手加护栏前，先回答"逐帧独立检测会不会闪烁"：

合成序列（静态水印 + 内容抖动 / 静止内容 + 噪声），逐帧独立跑「检测 → 修复」，测：

| 指标 | textured | photo |
|---|---|---|
| 相邻帧掩码 IoU（均值 / 最小） | 0.945 / 0.895 | 0.945 / 0.895 |
| 掩码"有/无"翻转次数 | 0 | 0 |
| 边界带相邻帧输出差（逐帧 vs 复用掩码） | 0.372 vs 0.370 | 0.482 vs 0.434 |
| 边界带逐像素时间 std（逐帧 vs 复用） | 0.514 vs 0.512 | 0.597 vs 0.557 |

**结论：静止水印场景下逐帧检测不产生闪烁**，其时间稳定性与"检测一次+复用掩码"几乎一致。
（首轮我在内容带平移的序列上测，内容位移把指标掩盖了——改为**静止内容 + 仅噪声**后
才能隔离"检测抖动"。）

## 2. 真正的风险：漂移时旧掩码会残留

用「水印差值补丁整体平移」的干净合成法（避免 warp 边框反射产生第二份水印，这是第一版
合成的坑），逐帧 1px 漂移，比较两种模式在真值水印区的残留（越低越干净）：

| 漂移量 | 新旧掩码 IoU | 陈旧掩码残留 | 新掩码残留 | 倍数 |
|---|---|---|---|---|
| 0px | 1.00 | 15.7 | 15.7 | 1.00× |
| 4px | 0.86 | 15.5 | 15.4 | 1.01× |
| 8px | 0.74 | 15.9 | 18.8 | 0.85× |
| **12px** | **0.64** | **56.7** | 19.3 | **2.94×** |
| **16px** | **0.56** | **70.3** | 18.4 | **3.83×** |
| 20px | 0.28 | 73.7 | 87.7 | 0.84× |
| 32px | 0.13 | 82.1 | 89.8 | 0.91× |

（textured 底图；photo 同形：12px → 2.51×、16px → 3.29×。）

**两处关键认知**：
1. **小漂移无害**（0~8px 残留与新掩码相当）——掩码自带 padding，位移被吸收；
2. **漂移 ≥20px 时逐帧检测本身也跟不住**（角标已移出可检区域，两者都差）——那不是
   "旧掩码 vs 新掩码"的问题，而是检测能力边界。

## 3. 阈值必须标定，不能拍脑袋

我最初的实现用了直觉阈值 **0.9**。按上表，0.86（4px，无害）和 0.74（8px，无害）都会
**误触发**——护栏把视频从"抽帧复用"降级成"逐帧检测"，白白变慢却没有任何收益。

据表标定：无害区上限 IoU ≈ 0.74，危险区上限 ≈ 0.64 → 阈值取 **0.70** 恰好区分两区。
静止水印相邻帧 IoU ≈ 0.99，余量充足。配置项：`VIDEO_REUSE_MIN_IOU`（默认 0.70）。

## 4. 实现

`services/video_service.py`：
- 新增 `_mask_iou(a, b)`（含 None/尺寸不一致的容错）；
- 在**每次重新检测**后比较新旧掩码 IoU：仅当 `step > 1`（真正在复用）且低于阈值时，
  自动把 `step` 改回 1（等价逐帧检测）并写入用户可见告警：
  「检测到水印位置漂移（掩码重合度 xx% < 70%），已自动改为逐帧检测，避免旧掩码残留水印。」
- 静止水印/小漂移不受影响（不误触发）；`step=1`（默认）时逻辑路径不变。

## 5. 测试（tests/test_video_reuse_drift_guard.py，6 例）

1. `_mask_iou` 语义（相同=1、无交集=0、None/尺寸不一致=0、部分重叠∈(0,1)）；
2. 边界：IoU 恰等于阈值 → **保持复用**（判定用严格小于）；
3. 静止水印（+σ=1 噪声）相邻帧 IoU ≥ 阈值、**不触发**（防误触发护栏）；
4. **小漂移（4px，IoU 0.86）不触发**——直接锁住"无害区不得降级"这条性能护栏；
5. 危险区漂移（12px，IoU 0.64）**必须触发**，且回退后残留 ≤ 未回退的一半
   （textured、photo 参数化；评估点取 12px 那一帧，因为 ≥20px 是检测能力边界）；
6. 审计档位/阈值常量语义。

全部通过（6.16s）。

## 7. 边界（诚实声明）

- 护栏解决的是"**旧掩码盖错位置**"；水印漂移 ≥20px 时**逐帧检测也跟不住**（角标移出可检
  区域，preset 锚定策略的固有限制）——本阶段不改检测策略，只把它如实记录为能力边界。
- 标定基于合成序列（640×360、角落 LOGO、1px/帧）；真实视频的漂移速度/掩码 padding 不同，
  阈值 0.70 是"无害/危险"分界的保守取值，可用环境变量调整。
