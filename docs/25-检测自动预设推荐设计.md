# 阶段 25 设计文档：检测自动预设推荐

> 模块路径：`core/preset_recommender.py`（核心） · `services/auto_pipeline.py`（服务透传）
> · `cli.py` / `api.py` / `server.py`（入口开关） · `ui/tab_auto.py`（推荐按钮）
> · `utils/i18n.py`（本地化文案）
> 版本：1.0.0 · 日期：2026-08-05

---

## 1. 背景与痛点

阶段 20 已提供 9 个检测预设（`general` / `ai_tiled` / `ai_signature` / `ai_corner` /
`ai_text_heavy` / `ai_faint_tiled` / `ai_grid` / `ai_gradient` / `ai_logo`），让用户针对
AI 生成图常见的水印样式一键适配。但普通用户面对 9 个选项往往不知道选哪个，只能逐个试错，
体验差。

本阶段新增**轻量图像特征分析**：用户上传图后点一下「🔍 智能推荐预设」，工具自动分析
图像特征，挑出最契合的检测预设并填进下拉框，同时用 Markdown 给出「为什么这么选」的理由。

## 2. 核心设计原则

1. **纯算法层，零重型依赖**：核心层 `core/preset_recommender.py` 仅依赖
   `numpy + OpenCV + config`，**不调用 OCR、不依赖 torch**。无模型环境也能跑（与本项目
   沙箱无 torch 的现实一致）。
2. **只评分，不检测**：推荐过程**不调用 `detect_watermark_mask`**（那是「用预设去检测」），
   只做特征评分。评分公式复用 detector 各策略的成熟思路（中值背景残差 / 投影自相关 /
   平面拟合 / Canny 轮廓实心率 / Sobel 笔画密度），但**独立实现**，避免与 detector 私有
   函数耦合。
3. **机器可读 + 翻译分离**：核心层只产出 `Recommendation(preset, scores, triggered,
   confidence)`，本地化文案由 `utils/i18n.py` 与 UI 层负责，核心层不碰翻译。
4. **向后兼容**：显式传 `preset` 或 `auto_preset=False` 时，推荐完全不触发，行为与旧版一致。
5. **总开关**：`config.RECOMMEND_ENABLED=False` 时回退默认预设，分数为空。

## 3. 提取的 8 类特征（含频域规则性）

| 特征键 | 含义 | 计算方法 | 命中 → 推荐预设 |
|--------|------|----------|----------------|
| `gradient` | 全局平滑渐变 | 灰度图降采样后最小二乘平面拟合，解释方差占比 + 平面幅度 | `ai_gradient` |
| `grid` | 规则网格/点阵 | 行列投影自相关强度 + 标记占比带 | `ai_grid` |
| `tiled` | 填充式平铺 | 周期 + 频域规则性 + 覆盖占比 | `ai_tiled` / `ai_faint_tiled` |
| `translucent` | 半透明散点覆盖 | 标记占比归一化（兜底展示用） | —（general 兜底信号） |
| `solid_logo` | 角落实心 LOGO | Canny 轮廓 + 凸包实心率，限定四角区域 | `ai_logo` |
| `text` | 满图文字笔画 | Sobel 边缘密度（整图） | `ai_text_heavy` |
| `signature` | 底部署名栏 | Sobel 边缘密度（底部 18% 带） | `ai_signature` |
| `regularity` | 频域平铺规则性 | 2D FFT 屏蔽直流后 Top-24 谐波能量占比 | 辅助 `tiled` 判定 |

### 3.1 关键难点：平铺 vs 文字的区分

填充式平铺方块的**边缘密度也高**，直接用「笔画密度」会把平铺图误判成文字。解决：
引入 **频域规则性 `regularity`**（2D FFT 峰集中度）——真正的平铺在频域呈尖锐晶格峰
（`regularity` 高），满图随机文字笔画频域能量弥散（`regularity` 低）。实测合成图：
平铺 `regularity≈0.128`，文字 `regularity≈0.0035`，阈值 `RECOMMEND_REGULARITY_MIN=0.05`
可干净分离。

## 4. 决策优先级（最具体 → 最通用）

```
gradient → solid_logo → tiled/faint_tiled(需 regular) → grid → text → signature → general
```

平铺分支必须排在文字之前（填充方块边缘密度高会触发 text），但用 `regular` 把关：
只有规则晶格才进平铺分支，不规则随机文字被放过，由文字分支接住。

## 6. 服务层透传（services/auto_pipeline.py）

`process_image` / `process_file` 新增参数 `auto_preset: bool = True`：

- `preset is None and mode != "manual" and auto_preset` → 调 `recommend_preset`，
  得到 `recommended_preset` 与 `recommendation`（机器可读 dict）。
- 检测分支：显式 `preset` 优先 → 推荐 preset（且非默认 general）→ 裸 `{"sensitivity"}`
  （保持与旧行为一致）。
- 返回字典新增 `recommended_preset`、`recommendation` 两键（success / skipped 均有）。
- 推荐失败仅告警，不影响主流程（回退默认检测）。

## 10. 已知边界 / 坑位

1. **文字 vs 平铺**：依赖 `regularity`，阈值 0.05 在合成图上干净分离，但极淡/噪声更大的
   真实平铺可能 regularity 偏低被误判为文字——属启发式局限，用户可手动覆盖。
2. **推荐 ≠ 检测**：推荐只挑预设，最终是否命中水印仍由 detector 决定；推荐错预设只是
   「策略不对口」，不会让程序崩溃。
3. **`--detect-preset` 默认改 None**：旧默认 `general` 现已由「自动推荐（含 general 兜底）」
   取代；若需严格旧行为，可显式 `--detect-preset general` 或 `--no-auto-preset`。
