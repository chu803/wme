> 用途：把**验收测试**外包给另一个 agent（豆包 / Claude Code / 其它 coding agent）时，

════════════════ 一、产品事实（先读，别自己猜）════════════════
- 它做什么：把**用户本人生成的 AI 图片**上那个角落的平台角标（如右下角「豆包AI」白色圆角小牌）擦掉。
- **承诺范围只有一类：角标 LOGO（预设 ai_logo）**。平铺文字(ai_faint_tiled)、网格点阵(ai_grid)、
  全局渐变(ai_gradient)、边缘小字(ai_text_heavy) **明确不承诺**——这几类"能选但效果不保证"
  属于**预期行为，不是缺陷**；但这几类若**崩溃/报错/悄悄改图**，那是缺陷。
- 开发方自测数字（供你对照，不是你的结论）：50 张真实标注角标图 ⇒ 检出 94.2%、完全擦净 98.0%、
  修复区外溢中位 1.9%；几何挑战集 4 种形态 ⇒ 检出/擦净 4/4；16 张干净图默认路径改动中位 0.0000%、最大 0.055%。
- 已知边界（**不是缺陷，但要在报告里核对是否仍成立**）：
  ① 角落一块"亮底招牌"（照片里的招牌，不是水印）会被多擦一圈，实测边际改动 0.457%（改前只擦文字）；
  ② 没装 LaMa 权重时角标位置会留一小块涂抹痕（OpenCV 引擎），选 lama 更干净；
  ③ 几何覆盖 4/4 是在**合成挑战集**上验的，真实生成器的其它形态未覆盖。
- 合规：只用于去除用户自己的 AI 图上的水印；检测与修复**在本机完成**，图片不上传。

## 三、怎么测：从进来到出结论的四步

1. **进**：cd 仓库 → 选对解释器 → 设编码 → 起实例（或直接跑门禁脚本）。
2. **测**：界面走 F1~F10（每条：操作 → 截图 → 逐字抄状态栏）；质量走四条门禁（读 JSON 取数）。
3. **核**：把测到的数字与文档里的承诺对账（检出率/擦净率/干净图误伤/几何覆盖），
   **不一致就报不一致**，不许替开发方找理由。
4. **报**：按第七节格式写 `docs/验收报告-YYYYMMDD.md`（新建、不覆盖），
   末尾 4 句结论 + 2 行声明（用了哪条驱动路径、是否改过仓库）。

## 四、验收之外：外部 agent 容易踩的三个坑（已踩过的）

1. **给了公网地址但那台隧道早断了** ⇒ 外部 agent 全程 502 `no tunnel`，功能项一个没测成
   （2026-11-07 实测）。⇒ **给地址前自己先打开确认能出界面**；更稳的是走本机 + 上面这套
   （agent 有 shell 就直接在本机跑）。
2. **用系统 python** ⇒ 依赖缺失，报错看起来像"脚本坏了"。
3. **没设编码** ⇒ 中文 stdout 报 UnicodeEncodeError，agent 会误判成"代码有 bug"。
