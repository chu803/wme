# 阶段 2 交付文档：基础核心代码

> 本文件记录阶段 2 产出的核心模块及其对外接口，供后续阶段（界面、队列、打包）直接复用。

## 一、模块清单与职责

| 文件 | 层级 | 职责 | 关键对外接口 |
|---|---|---|---|
| `utils/exceptions.py` | 基础 | 全项目异常体系（26 个异常类） | `WatermarkEraserError` 及其子类；`to_dict()` |
| `utils/path_helper.py` | 基础 | 路径/文件名处理，兼容中文与 EXE 路径 | `load_image` 路径定位、`sanitize_filename`、`build_output_filename`、`make_unique_path` |
| `utils/logger.py` | 基础 | 双通道日志（控制台彩色 + 文件轮转） | `get_logger(name)`、`print_banner(text)` |
| `core/device_manager.py` | 算法 | 硬件探测与设备选择 | `select_device(mode)`、`apply_cpu_threads()`、`empty_cache()`、`use_fp16()` |
| `core/image_utils.py` | 算法 | 图像读写、通道转换、掩码后处理、分块拼接 | `load_image`、`save_image`、`dilate_mask`、`feather_mask`、`split_into_tiles`、`merge_tiles` |
| `core/model_loader.py` | 算法 | LaMa 模型加载与单例缓存 | `load_lama_model(device)`、`is_model_available()`、`get_model_info()` |
| `core/inpainter.py` | 算法 | 修复引擎总调度（LaMa + OpenCV 双方案） | `inpaint(image, mask, **params)` |
| `download_model.py` | 脚本 | 模型多源下载（断点续传 + 校验） | `download_model()`（可独立运行） |
| `main.py` | 入口 | 启动编排：合规声明→自检→模型→界面/自测 | `main()`、`run_selftest()` |

## 二、分层依赖关系（再次确认铁律）

```
main.py / ui/  →  services/  →  core/  →  utils/  →  config.py
```

- `core/` 不依赖 `ui/`、`services/`，保证算法可独立测试。
- 所有模块通过顶部「路径加固」片段把项目根加入 `sys.path`，`import config` 在任何调用方式下均可用。

## 三、核心修复流程（`inpaint` 内部顺序）

1. **参数回填**：未传的参数从 `config.py` 取默认值。
2. **掩码预处理**：`膨胀(dilate) → 二值化(threshold) → 羽化(feather)`，得到 `proc_mask`（含渐变，用于最终融合）与 `bin_mask`（二值，供算法使用）。
3. **引擎选择**：`auto` 模式下若模型可用走 LaMa，否则降级 OpenCV。
4. **推理**：
   - LaMa：整体或分块（长边 > `INFER_MAX_SIDE` 且 `ENABLE_TILING`）→ 补边到 8 的倍数 → 归一化到 `[-1,1]` → 模型 → 反归一化回 `[0,1]` → 裁边。
   - OpenCV：TELEA / NS 传统修复。
5. **降噪**：可选非局部均值降噪（可仅作用于掩码区）。
6. **力度融合**：在掩码区按 `strength` 混合原图与修复结果。
7. **进度回调**：`progress(0~1, message)` 贯穿全程，供 UI 进度条接入。

## 四、关键设计决策

1. **中文路径**：读写一律走「读字节 → `cv2.imdecode` / `cv2.imencode`」，彻底规避 `cv2.imread` 中文路径静默失败。
2. **模型归一化约定**：输入 `(image*2-1)` 到 `[-1,1]`、输出 `out*0.5+0.5` 回 `[0,1]`，与 lama_cleaner 的 LaMa 约定一致。
3. **分块拼接**：重叠区用余弦权重窗融合，消除接缝；`TILE_SKIP_EMPTY` 跳过无水印块提速。
4. **降级链**：`auto` 引擎 + 模型缺失 → OpenCV；GPU 显存不足 → CPU；下载失败 → 友好提示而非崩溃。
