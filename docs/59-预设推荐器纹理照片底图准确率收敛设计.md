# 阶段 59 · 预设推荐器在纹理/照片底图上的准确率收敛

> 一句话：预设推荐器（决定"自动模式该用哪个预设去检测"，即阶段 49~58 检测器成果在真实
> UI 流程里的**入口**）此前只在纯色合成图自检过——在纹理/照片底图上一测便知三个系统性
> 缺陷：标记层百分位恒定选 ~46.75% 像素导致 grid 点阵被推成 general（召回 0）、字形被误判
> 为角标 LOGO 导致底部文字漏检、全局渐变优先级过高吞掉局部信号。逐一修复后，真实场景
> 代表（textured/photo）上 grid/corner/edge 在推荐预设下召回 88.7~100%。

---

## 1. 背景：检测器成果在自动流程的"入口"从未被验证

阶段 49~58 把检测器的每条策略都修到了有 benchmark 证据支撑的状态。但用户实际使用
"自动模式"时，先由 `core/preset_recommender.recommend_preset` 挑一个预设，再按该预设的
策略组合去检测。若推荐器挑错预设（如把网格点阵推成 general），**后面再好的检测策略
也不会被启用**——阶段 53~58 的网格成果在自动路径上等于不可达。

推荐器自检（模块内 `__main__`）只在**纯色合成图**上构造信号，从没在纹理/照片底图上
验证过。用 benchmark 的三种底图（gradient/textured/photo）实测，问题立刻暴露：

| 底图 | 用例 | 修复前推荐 | 后果 |
|---|---|---|---|
| textured/photo | grid 网格 | **general** | grid 策略不启用 → 召回 0 |
| textured/photo | edge_text 底部文字 | **ai_logo** | logo 预设无 edge 策略 → 召回 25.8% |
| textured/photo | faint_tiled 极淡平铺 | ai_text_heavy / general | 误导向 |
| gradient(纯渐变) | 任意（含 corner_logo） | **ai_gradient** | 渐变分支吞掉局部信号 → 漏检角标 |

## 2. 根因（三个）

### 2.1 标记层是"百分位恒定选比例"（阶段 49 消灭过的反模式）

`_marks_at` 用 `percentile(100 − 0.85×敏感度)` 选标记像素 → 在任何图上**恒定选出
46.75%**（实测 textured/photo 上 clean/grid/faint/corner/edge 全部 cov=0.4675）。后续
覆盖率/周期/频域规则性等特征全部由背景纹理决定，与有没有水印无关——这正是 detector
阶段 49 用绝对证据门限消灭的同一病理在推荐器里的残留。

### 2.2 角落实心判据把"字形"当 LOGO

`_corner_solid_count` 用 Canny+实心率+面积下限（0.1% 图面积）。底部文字小字的**单个字形**
（44×18、面积 ~580、实心率 0.87）满足全部判据且中心落在左下角区 → 文字水印被推给
ai_logo（该预设不启用 edge 策略）→ 功能漏检（召回 25.8%）。

### 2.3 全局渐变优先级过高

决策链把 ai_gradient 放最前：光滑渐变内容（纯色底/天空等）直接吞掉所有局部信号——
corner_logo 落在渐变底上也推荐 ai_gradient，角标因此漏检。

## 3. 修复（收敛而非新增策略）

1. **标记层改稳健统计门限**（`_marks_at` 重写，与 detector 绝对证据门限同思路）：
   `marks = (residual ≥ RECOMMEND_MARKS_ABS_MIN) ∧ (score > median + k·1.4826·MAD(score))`
   ——新增 `RECOMMEND_MARKS_ABS_MIN`（3.0）与 `RECOMMEND_MARKS_SIGMA_K`（4.5）。
   实测 640² 干净 textured/photo 覆盖率 ~0.1%（修复前 46.75%），grid 点阵 0.6~1.1%
   （分离度 6~12×）。
2. **角标最小实体边长**：新增 `RECOMMEND_LOGO_MIN_SIDE_FRACTION`（0.04）——
   轮廓最小边须 ≥ 4% × min(图宽,图高)。字形（最小边 ~2.8%）被排除，品牌级角标
   （corner_logo 73px/11%）保留。
3. **决策顺序重排**：logo → 平铺(faint/普通) → 稀疏网格 → 文字 → 签名 → **全局渐变**
   → 兜底。局部强结构优先；纯渐变内容在没有局部信号时才落入渐变分支（自检 `_gradient_img`
   仍通过）。

## 4. 结果（修复后）

| 底图 | 用例 | 推荐 | 推荐预设下召回 | 修复前 |
|---|---|---|---|---|
| textured | grid | ai_grid | **88.7%** | general / 0% |
| photo | grid | ai_grid | **99.2%** | general / 0% |
| textured | corner_logo | ai_logo | **100%** | 命中 |
| photo | corner_logo | ai_logo | **100%** | 命中 |
| textured | edge_text | ai_signature | **98.2%** | ai_logo / 25.8% |
| photo | edge_text | ai_signature | **98.2%** | ai_logo / 25.8% |
| textured/photo | clean | **general** | 空掩码 | general |

说明：`ai_signature` 与 `ai_text_heavy` 都启用 translucent+corner+edge+底部搜索+OCR，
落到两者任一即功能正确（推荐器语义上把"底部说明小字"归为署名带）。

## 5. 测试（tests/test_preset_recommend_accuracy.py，11 例）

- 功能双红线（slow）：textured/photo 上 grid→ai_grid 召回≥85%、corner→ai_logo 召回≥90%、
  edge_text→启用 edge 的预设召回≥90%（修复前 0/25.8% 场景全部反转）；
- clean textured/photo → general；
- marks 层分离度（快）：干净 <1% 且 grid > 3×clean（防百分位反模式复发）；
- 字形守卫：44×18 字形不计角标、181×72 品牌级角标计 1。

全部 11 例通过（5.8s）。既有推荐器测试 37 例（含模块纯色自检）零回归。

## 6. 已知边界（诚实声明）

1. **纯渐变内容的歧义**：无任何局部结构的光滑渐变图仍会被推荐 ai_gradient（语义上无法
   区分"渐变内容"与"渐变叠加水印"，自检用例亦如此）。真实 AI 图通常带纹理，风险有限；
   渐变预设本身需用户确认后才整图修复（预设描述已注明）。
2. **faint_tiled 极淡平铺**：稳健标记层下其覆盖率与干净图同量级（信息论极限，detector
   召回本就 ≤7.4%），推荐器无法可靠识别——这是检测能力的极限而非推荐器回归。
