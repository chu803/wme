**读法（这是四类未承诺类型的首份真实探针数据）**：

1. **`ai_grid` / `ai_faint_tiled` / `ai_text_heavy` 三类都能触发**——检测器不是"对这些类型完全无反应"，
   这与 `docs/107` 里 `ai_gradient` "恒零触发" 形成鲜明对比。
2. **`ai_gradient` 三张全部 0 命中**——与既有结论一致（该通路在真实图上恒零）。
   但**本次不能作为证据**：因为这三张图里根本没有渐变（是 LOGO），所以"0 命中"是**输入不对**，不是"通路失灵"。
3. **覆盖率与命中形状**（见 `docs/img/118_detect_overlay.png`）显示**命中偏"散、偏多"**（如 `grid_03` 321 个区域、
   `tile_03` 7.46% 覆盖），提示**过检**问题在这三类上同样存在——但没有真值就算不出 precision/recall。

> ⚠ 冒烟测试**只回答"有没有反应"**，不能替代真值门禁出的 precision/recall。**要出真指标，必须先有真值标注。**

## 4. 下一步（三选一，我已备好动手）

- **方案 A（最严谨）**：不把这批计入 `benchmark_real`；改为去"导出时带原生网格/平铺水印"的平台找素材

- **方案 B（务实·推荐）**：把这批作为**独立的次级档**（如 `benchmark_prompted`，或在本档内给每条打
  `provenance="prompt-rendered"` 标签）用于**类型覆盖冒烟**；`benchmark_real` 的承诺面**不动**。既用上你的图，又不稀释严格口径。
- **方案 C（最省事）**：接受为本档正式素材，收编 → 标注 → 翻 `committed` → 出四类真实指标。
  代价：真实指标会**偏乐观**（提示词水印比真实平台水印"干净"）。

**无论走哪个方案，`grad_*` 三张都要重做**，并建议把扩展名/编码统一。

## 5. 改进的「全局渐变」提示词（重做 grad 用）

```
请生成一张写实摄影风格的图片，主题：<场景>。1024×1024 或更大，画面干净。
生成后，请在整张图上叠加一层【纯线性渐变遮罩】：
- 从画面左上角到右下角，由「半透明青色」平滑过渡到「半透明品红」，整体不透明度约 12%；
- 只允许是平滑的颜色渐变（像给整张图盖了一层彩色玻璃），
  不要出现任何文字、字母、圆圈、LOGO、图案或边框；
- 渐变要覆盖整张画面（四个角都要受影响），保持平滑、无肉眼可见的分界线。
必须真正把它画进图片像素里。
```

> 要点：**明确禁止出现文字/圆形/LOGO/图案**——上一版就是因为没禁，豆包画成了大号 LOGO。
