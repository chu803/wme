# 阶段 75 · 处理偏好设置页与双跑全链路接线设计

> 日期：2026-09-12 · 前置：阶段 70/71/73/74 · 性质：模块深化（UI 与持久化收口）

## 1. 动机：把「只能靠环境变量」的能力变成可配置产品功能

阶段 70~74 交付了四个能力开关与一个核心参数，但入口形态割裂：

| 能力 | 此前入口 | 缺口 |
|---|---|---|
| 双跑择优（74） | 环境变量 / CLI / **仅单图页**复选框 | 批量页、自动页无开关；不可持久化 |
| 透明通道保留（71） | 仅环境变量 `WME_PNG_KEEP_ALPHA` | 无界面、不可持久化 |
| EXIF 方向校正（70） | 仅环境变量 | 无界面、不可持久化 |
| 位深规范化（70） | 仅环境变量 | 无界面、不可持久化 |

本阶段按既有「设置页 + `config.user_overrides.json` 白名单」机制（阶段 35/46/47
三次验证）把这四项收口为**产品级配置**，并把双跑择优补进批量/自动页。

## 2. user_overrides 白名单扩容（config.py）

新增 5 键 + 校验器（合并式写入、环境变量优先语义与既有键一致）：

| 键 | 校验 | 非法回退 |
|---|---|---|
| `INPAINT_DUAL_RUN` | bool(v) | —（truthy 语义） |
| `INPAINT_DUAL_SECONDARY` | str ∈ {lama, opencv}（小写化） | `lama` |
| `PNG_KEEP_ALPHA` | bool(v) | — |
| `IMAGE_APPLY_EXIF_ORIENTATION` | bool(v) | — |
| `IMAGE_NORMALIZE_BIT_DEPTH` | bool(v) | — |

优先级不变：`WME_*` 环境变量 > 覆盖 JSON > 代码默认值；非法值一律回退安全默认。

## 3. 设置页「处理偏好」区（ui/tab_settings.py）

- 新 Accordion「⚙️ 处理偏好」：4 个复选框（双跑择优 / 导出保留透明通道 /
  应用 EXIF 方向校正 / 非 8 位位深规范化）+「保存为默认」+ 应用按钮；
- `apply_processing_prefs(...)`：实时写运行时配置 → 可选合并式持久化 →
  返回 (快照 Markdown, 信息文案)（与 sr/cp 两区同构）；
- i18n：`settings.prefs.*` 中英双键 12 个。

### 工程插曲（i18n 点号键陷阱）

初版信息键命名为 `msg.applied`（键名里含点）——`t()` 按 `.` 分层遍历查找，
`prefs["msg"]["applied"]` 不存在 → 静默回退键名本身，**双语测试当场抓住**。
修正为 `msg_applied`。教训与阶段 73 的「静默吞异常」同族：**点号是 i18n 键的
路径分隔符，键名里不得再含点**；这类错误只有「逐键双语存在性测试」能拦住。

## 4. 双跑全链路接线（补 74 的边界）

| 层 | 改动 |
|---|---|
| `services/auto_pipeline.process_image` | 新增 `dual_run` 参数 → `inpaint(dual_run=)`（CLI 场景由 main() 的 `--dual-run` 覆写 config 生效） |
| `ui/tab_auto.process_auto_repair` | 新增 `dual_run` 参数 → `inpaint(dual_run=)`；自动页新增复选框（默认取 `config.INPAINT_DUAL_RUN`，即设置页持久化值） |
| `ui/tab_batch` | `_process_one` / `run_batch` / `_processor` 三层透传 + 批量页复选框 |

显式覆盖优先级保持不变：**每次调用显式参数 > 设置页/持久化配置 > 代码默认**。

## 5. 测试（`tests/test_processing_prefs.py`，22 例）

- 白名单往返（5 新键）+ 非法副引擎回退 lama + 非白名单键拒收 + bool 校验器语义锁定；
- 环境变量优先（`WME_INPAINT_DUAL_RUN` 存在时语义确认）；
- `apply_processing_prefs`：运行时写入 + 持久化落盘内容 / 不勾保存不落盘 /
  全关恢复默认；
- i18n：`settings.prefs.*` 12 键 × 双语存在性（参数化 12 例）；
- **接线完整性**：`process_image` / `process_auto_repair` / `process_single` /
  `run_batch` / `_process_one` / `inpaint` 六层签名均含 `dual_run`（防后续重构断链）。

## 6. 剩余边界

- 视频页/PDF 页共享参数面板未接入双跑复选框（其逐帧修复走 `video_service` 自有
  调用链；环境变量/设置页配置仍全局生效，仅无逐任务覆盖）；
- `INPAINT_DUAL_SECONDARY` 未进设置页（进阶项，环境变量可调）；
- 双跑耗时约翻倍（阶段 74 已明示），设置页 info 文案已提示「较慢」。
