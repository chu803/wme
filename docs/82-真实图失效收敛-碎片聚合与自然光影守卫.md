## 2. P0-1 · 同 kind 相邻碎片聚合（F2）

### 2.1 量化（探针 → `%TEMP%/p0_probe/`）

对 30 张真实图 general 检测的 translucent 区域做合并模拟（真值框两处固定）：

| 变体 | 真实召回 | 说明 |
|---|---|---|
| 不合并（原基线） | 71.7% | 17/30 图右下角标碎成 29~43px 碎片，IoU≈0.10 < 0.3 全计 FN |
| 仅合并 gap=0（相触） | 91.7% | 大量碎片本就「相触而断」 |
| gap≤24 无约束 | **85.0%** ↓ | **链式拖拽**：真值区域通过与它相触的误报区传递合并，bbox 被拖大后 IoU 掉破 0.3（15/23/24 号图反例） |
| gap≤24 + 最长边≤160 + 填充率≥2.2 | **93.3%** | 约束挡住拖拽，还多救回 28 号图 |

### 2.2 实现（`core/detector.py`）

- `DetectionRegion` 增加 `merged_from` / `anchors` 字段（默认 1/None，向后兼容）。
- `_merge_adjacent_fragments()`：同 kind（默认仅 translucent）+ 贪心按间隙升序 + 双约束
  （**MAX_SIDE** 挡链式拖拽、**FILL** 挡跨空合并——缺一不可，均有真实图反例）。
- **位置 = 全部过滤（二次过滤 + 覆盖率闸）之后**。第一版放在过滤前，
  「本该被过滤掉的死区域」参与聚合并把 07 号图的真匹配碎片拖变形
  （IoU 0.47 → 0.234，整图召回 1.0 → 0.5）——探针模拟（过滤后合并，93.3%）
  与实现（过滤前合并，91.7%）的差值就是这么来的，移到出口后逐位对齐。
- 掩码按聚合后区域重建：聚合框内保留原候选像素（形状感知语义不丢），空隙不填充。
- 阈值锚定 640（`DETECT_FRAGMENT_MERGE_GAP=15` / `MAX_SIDE=100` / `FILL=2.2`），
  随 `max(h,w)/640` 缩放。

### 2.3 效果

| 指标 | 前 → 后 |
|---|---|
| 真实图召回 | 71.7% → **93.3%** |
| 真实图 mean IoU | 0.596 → **0.649** |
| 真实图 FP/图 | 156 → ~112 |
| 合成门禁 | 逐位零回归 |

## 3. P0-2 · 自然光影守卫（F1）

### 3.1 特征搜索（特征探针，守卫关闭状态下测原始区域）

对 30 图 translucent 区域按真值标注 TP(47)/FP(2779)，测 6 个特征：
density、solidity 无区分度；stroke 弱；**edge_sharp（残差场 Sobel 梯度分位）强**——
与 A2 的机理推测一致：**人工叠加边缘锐利、自然光影过渡平滑**。

### 3.2 两个统计量缺陷（都是单元测试抓的）

1. **v1（bbox 全域 P90）**：依赖「边缘像素占比」——跃变像素 <10% 时 P90 恒为 0
   （手造单边块实测 P90=0.0）。对大而稀疏的框式水印结构性失效。
2. **v2 = 「候选像素 ∪ 膨胀 2px」上的梯度 P90**：结构稳健，保留为最终定义。

### 3.3 相对锐度通路与它的分母陷阱

绝对锐度随振幅走——合成极淡平铺振幅仅 ~9 灰阶（edge 32~46），任何能杀真实 FP
（edge P50=110）的绝对阈值都会把门禁 gradient/faint_tiled（召回 0.993）全灭。
解法：**相对锐度 ratio = edge / bbox 均值|residual|**，与振幅解耦：

| | ratio 分布 |
|---|---|
| 合成极淡平铺 TP | P10 = **9.8**（锐利边缘 / 稀疏振幅） |
| 真实 FP | P90 = **8.3**（平滑） |

**分母必须是 bbox 全域均值**：若用候选像素均值，极淡平铺 ratio 掉到 4.5
（候选集中在笔画上、均值抬升），落进光影区间被误杀——该反转在标定中实测过。

### 3.4 守卫的适用范围（tiled 路径豁免）

守卫最初同时挂在两条路径上，实测门禁 gradient/faint_tiled 召回 0.993 → 0.772。
根因：tiled 路径 k=2.2 更严，候选集中在最强像素 → bbox 均值抬高 → ratio 跌破 8 →
闭运算补隙组件被误杀（门禁召回是像素口径，补隙丢失直接掉召回）。
处置：**守卫只挂基础通路**——F1 误报来自基础路径（真实图 general 预设
enhance_tiled=False，tiled 路径根本不激活）；tiled 路径是显式 opt-in 的召回增强器。

### 3.5 最终规则与标定

```
保留 if edge_sharp ≥ 94×scale OR edge_sharp / bbox_mean ≥ 8.0
（94@640 = 150@1024；scale = max(h,w)/640）
```

| 口径 | 真实 TP | 真实 FP | 合成 TP |
|---|---|---|---|
| 保留率 | **100%** | **38.4%**（砍 61.6%） | 100%（含极淡） |

### 3.6 效果（双口径终值）

| 指标 | 改动前 | 改动后 | 变化 |
|---|---|---|---|
| 真实图精确率 | 1.29% | **3.08%** | ×2.4 |
| 真实图召回 | 71.7% | **93.3%** | +21.7pp |
| 真实图 mean IoU | 0.596 | **0.652** | +0.056 |
| 合成门禁（聚合） | 0.79 / 51.3 / 82.3 / 49.4 / +12.60 | 0.78 / 51.4 / 82.3 / 49.4 / +12.61 | **零回归**（faint_tiled 召回恢复） |

> 注：v1 统计量（bbox 全域 P90、阈值 153@640、双路径挂载）曾带来合成侧额外收益
> （误报 0.32%、grid 精确率 ×1.9、ΔPSNR +15.67），但那批数字伴随两个结构性缺陷
> （稀疏框式水印失效 + tiled 路径误杀），修正后合成侧回到基线。当前收益全部来自
> 真实图侧——这正是双口径标定的本意：合成图本来就没有 F1/F2 问题。

## 5. 本阶段经验

29. **「聚合/合并」类后处理必须放在全部过滤之后**：过滤前的区域集合包含「注定被
    丢弃的死区域」，它们参与聚合会把好区域拖变形（07 号图反例：IoU 0.47 → 0.234）。
    判据：凡是「改变区域几何」的步骤，其输入必须是「确认存活」的区域。
30. **链式传递合并必须有几何约束**：真值区域与误报区相触时（真实照片上极常见），
    传递合并会把 bbox 拖到 IoU 掉破匹配阈值——「合并救召回」与「合并毁匹配」是
    同一个机制的两面，靠 MAX_SIDE + FILL 双约束切开。
31. **分位统计量要看「目标像素占比」**：对梯度取 bbox 全域 P90，跃变像素 <10% 时
    统计量恒为 0——分位数隐含假设了「目标事件占比高于分位」。修正方向是收窄
    统计域（候选像素∪邻域），而不是调分位数。
32. **特征与保护对象要同口径标定**：ratio 的分母换成候选像素均值后，极淡平铺的
    ratio 从 10.8 掉到 4.5 被误杀——「更精确的振幅估计」反而破坏了「稀释效应」
    承担的保护机制。改变统计定义时，所有依赖它的阈值必须重新标定。
33. **增强通路豁免守卫要写明结构性理由**：tiled 路径的严格门限（k=2.2）使候选
    集中于最强像素、bbox 均值系统性抬高，任何按基础通路标定的 ratio 阈值都会
    结构性误杀它——这不是阈值调参问题，是两条通路证据语义不同（与经验 8
    「信号族互斥」同源）。
