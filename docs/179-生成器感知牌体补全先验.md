# 阶段 179 · 生成器感知牌体补全先验（plate_footprint_prior）

> 承接 178（低对比底根因重定位 → "生成器感知先验缺失"；lift 三否闭合）。
> 本阶段**实现** 178 §3 登记的 `plate_footprint_prior`：信号锚定的右下角牌体补全，
> 默认关闭、门禁验证 4 张低对比底召回提升且 6 张对照无回归；并修复一处补全污染
> 非承诺预设面积监控的回归。

## 1. 设计：信号锚定 + 右下角不变式 + 实心掩码块直写

178 §2 的探针已确证：4 张低对比底 `corner_logo`（白牌）通路**零输出**，
召回 100% 来自 `translucent`/`edge_text` 在右下角的**碎片命中**（文字/描边的半透明叠加，
非整牌实心填充）。根因是"没有任何通路在右下角重构出完整 340×128 牌体"。

178 §3 登记的不变式（172-A 亮度剖面客观实测）：豆包角标 = 固定 **340×128 圆角板**、
**恒在右下角**、随图尺寸等比缩放（2048² 上即 340×128）。本阶段据此实现补全先验：

`core/detector._apply_plate_completion_prior`（在策略 6 LOGO 之后、合并之前调用）：

1. **信号锚定（不盲猜位置）**：只在某角搜索区内**存在** `translucent`/`edge_text`
   证据、且**无** `corner_logo` 命中时，才补发牌体。杜绝"无证据强行铺牌"。
2. **右下角不变式**：仅处理 `px+pw≥w and py+ph≥h` 的右下角搜索区（豆包客观不变式），
   避免在他角因招牌/纹理的 translucent/edge_text 信号误发整牌（会膨胀预测面积、拉低 precision）。
3. **实心掩码块直写**：直接把 `np.zeros((h,w))` 中 `[by:by+fh, bx:bx+fw]=255` 的实心块并入
   `mask_parts`，并同步追加一个 `corner_logo` 区域（供可视化）。**为什么绕开证据二次确认**：
   合并阶段对"只产框"的策略会跑"框内证据二次确认"（阶段 103），而低对比牌内部恰恰
   **没有可被证据场捕获的强信号**——若只加框，会被裁空甚至整框丢弃，补全失效。
4. **规范化足迹**：`fw=340×min(h,w)/2048`、`fh=128×min(h,w)/2048`，`(bx,by)=(w-fw,h-fh)`。
5. **防重复**：右下角已有 `corner_logo` 命中时不补（避免与既通路叠加回归）。
6. **可逆杠杆** `config.DETECT_PLATE_COMPLETE_FROM_SIGNAL`（默认 `False`）+ 守卫测试 +
   注入式反例。env 前缀 `WME_`（即 `WME_DETECT_PLATE_COMPLETE_FROM_SIGNAL`）。

## 3. 闭环修复：补全污染非承诺预设面积监控（纯 bug）

首轮 `real_gate --strict-scope` 杠杆 ON 曾 **EXIT=1**，唯一失败项：

```
[面积漂移] ai_text_heavy/mask_coverage_p90 0.0557 → 0.0646（上升 16.0%，容差 15%）
```

补全逻辑（即便按右下角不变式收口）在 `ai_text_heavy` 等**未承诺预设**上仍会触发——
因为它读的是 `all_regions` 内任何 `translucent`/`edge_text` 信号，与预设无关。
面积监控守的是"该通路在真实照片上不得突然变胖"，补全不该改动**非承诺预设**的覆盖基线。

**修复**：在函数体杠杆检查后追加预设闸门——

```python
if preset not in (None, "general"):
    return
```

调用点同步传 `preset=preset`（`detect_watermark_mask` 已有该参数）。效果：
补全**只在 committed 预设（general 或不指定）生效**，未承诺预设的面积监控零污染。
复跑 `real_gate --strict-scope` 杠杆 ON → **EXIT=0**，ai_text_heavy P90 回到 5.57%。

> 注：此闸门是**纯 bug 修复**，与"杠杆默认 OFF"正交——即便未来默认开启，补全也只
> 在承诺面内活动，不会污染未承诺预设的漂移护栏。

## 4. 诚实边界：默认 OFF + 干净图精度留白

**杠杆保持默认 OFF**，依据两条铁律 + 一项不可测量风险：

1. **"宁可漏检不可滥杀"**（项目铁律）：补全是**生成器专属先验**（仅豆包牌布局），
   用在非豆包图/干净图上属"无证据强铺牌"，精度代价未知。
2. **精度留白不可测量**：当前基准 **10 张全为带水印豆包图、无干净图**，故
   "干净图上误发整牌"的误报率**不可测量**。在补齐干净图基准、标定清晰红线前，
   默认关闭是对用户资产最保守的选择。
3. 可逆：env `WME_DETECT_PLATE_COMPLETE_FROM_SIGNAL=true` 即可开；默认关闭时函数首行
   即 `return`，零副作用（守卫测试 `test_lever_off_is_silent` 钉死）。
