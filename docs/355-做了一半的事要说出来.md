# 阶段 355 · 「做了一半」的事必须在界面上说出来（第三轮审计收尾两条）

> 日期 2026-10-27 · 性质：**产品缺陷修复**（第三轮审计 7 条中的最后两条）

## 一、对比图导出丢失败项不报告

`ui/tab_settings.on_export_compares` 逐条 `except → continue`，失败只写日志，
而消息只报**成功数**（「已生成 N 张对比图并打包」）⇒ ZIP 里比历史页少几张，
用户**无从知道少了什么**。修法：统计失败条目，消息改用新键
`settings.snap.msg.compare_zip_partial`（成功数 + 失败数 + 前几个失败的文件名）。

## 二、「保存为默认」写盘失败不可见

`config.save_user_overrides` 在无写权限/值非法时**返回 False 且不抛异常**；
而界面文案承诺「保存为默认…下次启动自动生效」、仍显示「✅ 已应用」
⇒ 用户以为存上了，下次启动发现没生效。修法：失败时把
`settings.snap.msg.save_default_failed` 追加进返回信息（**仍然不阻断实时生效**，只是说实话）。

## 三、守卫（`tests/test_audit_fixes355.py`，4 例）

* 写盘返回 False ⇒ 信息里必须出现失败提示；返回 True ⇒ **不得**出现（别把每次都变成告警）；
* 导出时一条成功一条失败 ⇒ 消息必须同时给出成功数与失败数；
* 全部成功 ⇒ 不得出现 partial 文案。
