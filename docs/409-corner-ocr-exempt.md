# 409 · 角标检测召回：角落高置信 OCR 豁免证据二次确认（#42）

- 日期：2026-11-15
- 样本：用户即梦/豆包生成 8 张带"豆包"文字角标真实图（先验真带水印再测）。
- 实测召回 **3/8**（远低于基准 98%）：漏的集中在暗底/低对比/纹理底。基准集没覆盖这类 ⇒ 98% 是基准内数字。

## 根因（systematic-debugging + A/B）

`detect_corner_logo` 在全分辨率与 1280 都能高置信（0.988）定位角标 OCR 框，但 `_collect` 的
「框内证据二次确认」（`DETECT_BOX_EVIDENCE_REFINE`）在暗底/低对比上证据场不响应 ⇒ 整框丢弃真水印。
A/B：关掉 refine，02/04/07 召回立即恢复（BR 0→3600）。

## 修复

新增 `DETECT_OCR_CORNER_EXEMPT`（默认开）：中心落在角搜索区内的高置信 OCR 框豁免证据二次确认、
直接保留框掩码（角落是强水印先验）；非角落 OCR 仍走证据确认守干净图红线。

## 验证

- 真实 8 张召回 **3/8→7/8**（仅 08 针织低对比仍漏，另案 #73）。
- 干净图 16 张误报 0/16 不变；real_gate 承诺红线（召回≥0.8078/precision/面积）绿；160 条检测守卫绿。
- 新增 `tests/test_corner_ocr_exempt409.py`（开保留/关复现漏检）。
