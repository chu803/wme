## 2. C2 · 打包元数据（已完成）

新增 **`pyproject.toml`**：
- `[project]`：名称 `wme-watermark-eraser`、版本 **1.0.0**、描述、`requires-python = ">=3.11"`
  （与 CI / Dockerfile 的 3.11 一致）、许可（指向 `LICENSE` 文件）、分类器。
- `[tool.setuptools] py-modules`：`api / cli / config / download_model / main / server`
  （与仓库现状一一对应；`conftest.py` 是测试夹具，不发布）。
- `[tool.setuptools.packages.find] include = ["core*","services*","ui*","utils*"]`。
- **刻意不做**：① 不复制一份 `dependencies`（依赖真值来源仍是 `requirements*.txt`）；
  ② 不用 setuptools 的 `dynamic = {attr = "config.APP_VERSION"}`（那会在**构建时导入
  config.py**，而它在导入期读环境变量并解析目录 ⇒ 构建副作用）；
  ③ 不写 `[tool.coverage.*]`（覆盖率真值来源是 `.coveragerc`，coverage 只读第一个找到的
  配置文件，两处都写会造成「改一处不生效」的静默陷阱）；
  ④ 暂不设 `[project.scripts]` 控制台入口（需先定命令名/入口模块，已登记为待决策）。

**版本号单一真值来源**：`config.APP_VERSION = "1.0.0"`，由 `tests/test_packaging_meta.py`
断言与 `pyproject.toml` 一致（两处改一处就会红）。

> ⚠ **自我纠正**：`docs/185` 的 C2 写着「无版本号单一来源」——**不成立**，
> `config.APP_VERSION` 一直是唯一来源（我当初只查了 pyproject/py3 常见位置）。
