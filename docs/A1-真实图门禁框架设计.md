# 方向 A1 · 真实图门禁框架设计

> 本阶段是**方向 A（真实图真值审计）的基础设施搭建**。
> 不涉及真实图数据采集与真值标注本身（那是 A2/A3 的工作）；
> 本阶段产出**可重入、可测试**的脚本 + 文档 + 烟雾测试 + gitignore 约定。

---

## 1. 为什么需要这个框架

项目 80 个阶段的量化指标（误报 0.79%、精确率 51.3%、召回 82.3%、ΔPSNR +12.60 dB）**全部
基于 640² 合成图**。真实 AI 平台（Midjourney / Stable Diffusion / DALL-E / Adobe Firefly /
v0 / Lepton 等）输出图的水印风格（弧形文字、装饰花纹、半透明叠加、凹凸纹理）**合成图未覆盖**。

阶段 50 得出「LaMa vs OpenCV 8/8 OpenCV 占优」是合成图结论，**真实图上是否成立完全未知**。
这是 MEMORY 中反复标注的「前置前提」却从未落地。

框架本身不解决问题；它把「一旦有真实图，立刻能跑门禁」的能力就位：
- 数据采集脚本（`collect_real_assets.py`）
- 真值标注脚本（`build_real_ground_truth.py`）
- 门禁脚本（`run_real_benchmark.py`）
- 引擎对决脚本（`real_benchmark_decision.py`）
- 烟雾测试（`test_real_benchmark_smoke.py`）

## 3. manifest.json schema

```json
{
  "version": 1,
  "images": [
    {
      "id": "mj_001",
      "filename": "foo.png",
      "path": "images/foo.png",
      "ai_source": "midjourney",              // 枚举
      "watermark_style_hint": "corner_logo",  // 提示值；真值以 ground_truth.json 为准
      "original_size": [1920, 1080],
      "sha256": "...",
      "added_at": "2026-09-13T14:30:00Z",
      "source": "local"  // local / url
    }
  ]
}
```

**合并语义**：同 `sha256` 视为同一张图，跳过；同 `path` 但 `sha256` 变 → 拒绝（防文件被覆盖）。

## 4. ground_truth.json schema

```json
{
  "version": 1,
  "entries": [
    {
      "image_id": "mj_001",
      "watermarks": [
        {
          "bbox": [1830, 1040, 80, 30],  // [x, y, w, h]，像素
          "style": "corner_logo",         // 见 STYLE_ENUM
          "note": "右下角 MJ 签名"
        }
      ],
      "labeled_at": "2026-09-13T14:30:00Z",
      "labeled_by": "auto:general"  // auto:<preset> / manual
    }
  ]
}
```

**STYLE_ENUM**（与 `core.detector.KIND_*` 对齐）：
- `corner_logo` / `edge_text` / `grid_watermark` / `logo_watermark` / `gradient_watermark`
- `translucent` / `ocr_text`
- 额外补充：`overlay`（整图半透明叠加，Firefly 风）、`mixed`（多风格并存）、`unknown`

**auto 预填策略**：调用 `detect_watermark_mask(arr, preset="general", use_ocr=False)`，
把命中的 `regions` 转成 bbox；用户用任何文本编辑器打开 JSON 微调。
**不覆盖**已有 entries；如需重生成先手工删除。

## 5. 门禁指标（run_real_benchmark.py）

每张图 × 每个预设：

| 指标 | 计算 |
|---|---|
| **Recall**（区域级） | TP 区域数 / 真值区域总数 |
| **Precision**（区域级） | TP 区域数 / 预测区域总数 |
| **Mean IoU** | TP 区域的 IoU 均值 |
| **Mask IoU** | 预测掩码 ∩ 真值掩码 / 预测掩码 ∪ 真值掩码 |
| **Mask coverage** | 预测掩码像素 / 全图像素 |

**匹配规则**：predicted bbox 与 truth bbox IoU >= 0.3 视为同一区域；贪心匹配（按 IoU 降序）；
未匹配的 predicted → FP；未匹配的 truth → FN。

**预设**：默认 10 个（general / ai_tiled / ai_signature / ai_corner / ai_text_heavy /
ai_faint_tiled / ai_grid / ai_gradient / ai_logo / ai_multi）；可通过 `--presets` 限定。

## 6. 引擎对决指标（real_benchmark_decision.py）

| 指标 | 含义 | 期望方向 |
|---|---|---|
| 掩码区修复前后 PSNR | 修复对原图的改写量（越高越没改坏） | 高 |
| NIQE（无参考） | 自然度（越低越接近真实图像） | 低 |

**注意**：**无 GT 修复质量**（没有「未加水印的原图」可比）；本脚本衡量的是：
- 引擎的「保守性」（PSNR 高 = 没动不该动的地方）
- 引擎的「自然度」（NIQE 低 = 修复得自然）

**真要判定 LaMa vs OpenCV 谁更适合真实图**，需要 P0 真实图真值（用户自己有权处理的 AI 图）；
本脚本是「**基础设施就绪**」：数据到位立刻能跑。

## 7. 烟雾测试（test_real_benchmark_smoke.py）

四个测试（注入式反例 + 端到端正例）：

1. **空 manifest 必须显式报错** —— 防「假绿」；CLI 应返回非零退出码且 stderr 含明确错误。
2. **1 张合成图 + 真值 → 全链路跑通** —— 用 PIL 画 256×256 + 80×80 黑矩形做水印，验证 detector
   至少 recall>0（实际是矩形的 logo_watermark 命中率，应≥0.5）。
3. **validate 应捕获越界 bbox + 非法 style** —— 故意制造两种错误，validate 应非零退出且报数。
4. **scan 不破坏手工元数据** —— 已有手工写的 manifest 条目（id=special_id），scan 后必须保留。

每个测试都通过 `WME_BENCH_DIR` 环境变量把 `BENCH_DIR` 重定向到 tmp_path，**不污染项目内**。

## 8. 设计约束

- **不依赖网络**：采集以本地扫描为主；`download` 仅依赖 urllib（标准库），失败时给出原因但不抛错。
- **不修改已有图**：`scan` 是只读的；`add --copy` 才复制；`download` 才落地。
- **可重入**：所有脚本允许多次运行；manifest/truth 是合并语义。
- **空集必须显式报错**：防「假绿」；`run_real_benchmark` 与 `real_benchmark_decision` 在
  没有图+真值时抛 RuntimeError 并非零退出。
- **真值 JSON 可手工编辑**：bbox 用像素 [x, y, w, h]；style 枚举固定；任何文本编辑器可用。
- **核心链路依赖不变**：4 个脚本只依赖 `core.detector` / `core.inpainter` /
  `services.quality_service`，**不引入新依赖**。

## 9. 与已有边界的关系

- 与 `make_demo_assets.py --input-dir`（无 GT 真实图批量对比）**互补**：本框架加上 GT 后能
  算 recall/precision/IoU，而 `--input-dir` 只算两引擎差异（无真值）。
- 与 `scripts/run_benchmark.py`（合成图 LaMa vs OpenCV 对决）**对应**：本框架同样跑
  LaMa vs OpenCV，但基于真值集。
- 与 `scripts/quality_gate.py`（合成图门禁基线）**互证**：本框架产出真实图基线后，可
  在 `quality_gate.py` 中加入「真实图子集」分支。
