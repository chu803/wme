## 一、首屏写明「本地处理、图片不上传」

- 事实：这是产品最核心的信任点（离线 / 本地），但改前 `grep 不上传|本地处理` 在 UI 文案里
  **一处都没有** —— 用户只能从 README 推断。
- 改法：`app.compliance` 中英双语各加一行（🔒 本地处理、图片不上传；唯一联网是首次模型下载），
  随合规声明一起显示在首屏顶部。
- 守卫：`tests/test_compliance_statement.py::test_ui_brief_states_local_processing_and_no_upload`
  —— 中文必须含「不上传」+「本地」，英文必须含「never uploaded」+「locally」
  （防止被改成含糊的"隐私友好"而丢掉承诺本身）。
- 实测：真浏览器快照里首屏可见该行（`uid=1_9/1_10`：本地处理、图片不上传 / 检测与修复都在本机完成…）。

## 二、Python 版本口径：从"声称"变成"测过"

- 事实：`pyproject` 的 classifiers 声称 3.11 / 3.12 / 3.13，但 CI 矩阵只有 **3.11** ⇒ 后两条没有证据。
- 改法：CI 矩阵扩到 `["3.11", "3.12", "3.13"]`（三作业并行，墙钟不变）。
  首个包含该改动的 push 由 CI 判定：任一版本红，就把对应 classifier 收窄——**声明服从证据**。
- 守卫：`test_requirements_ci_installable.py` 的说明同步（"矩阵从 3.11 起，375 起扩到 3.11/3.12/3.13"）。
