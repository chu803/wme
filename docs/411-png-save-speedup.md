# 411 · 大图 PNG 保存提速：压缩级 6→1（#72）

- 日期：2026-11-15
- 瓶颈：大图耗时主要在 PNG 保存（检测 ~5s/64% 之外）。

## 实测（2720×1520，cv2.imencode）

| lvl | 时间 | 体积 |
| --- | --- | --- |
| 0 | 0.120s | 12.42MB |
| 1 | 0.290s | 5.33MB |
| 3 | 0.513s | 5.04MB |
| 6（旧默认） | 1.560s | 4.79MB |
| 9 | 8.564s | 4.64MB |

## 修复

`PNG_COMPRESS_LEVEL` 默认 **6→1**（用户拍板）：保存 **5.1×**（save_image 实测 1.61s→0.32s），体积 +11%。
PNG 无损 ⇒ 逐像素验证 lvl1 与 lvl6 输出**完全一致**（画质/红线不受影响）；要更小文件 env 调高。

## 验证

- 64 条保存/导出/alpha/ICC 测试绿。
- 新增 `tests/test_png_save411.py`：锁定默认 lvl1 + 跨级别解码像素逐位一致（无损回归守卫）。
